# 상품 옵션 식별 체계 개선 (품목코드)

메이크샵 상품의 판매·재고 단위(품목)마다 바뀌지 않는 식별자 **품목코드**를 새로 붙이는 기획 프로젝트입니다. 현재 단계는 정책 확정 후 기획 리뷰 전이며, 이 저장소에는 사내 정보를 뺀 정책서, 와이어프레임, 리뷰용 설명 자료를 공개합니다.

## 배경

조합옵션(예: 블랙/S)을 식별하는 기존 번호는 옵션을 수정·재조합할 때 다시 만들어지거나, 지운 번호가 다른 조합에 다시 쓰일 수 있었습니다. 그래서 재고·재입고 알림·외부 연동이 같은 품목을 꾸준히 가리키지 못했습니다.

## 핵심 정책

| 항목 | 내용 |
|---|---|
| 형식 | `{상품번호}-{순번}` (예: `123456789-0001`). 순번은 최소 4자리, 9999 다음은 10000으로 늘어납니다. |
| 발급 대상 | 조합 1개당 1개. 옵션 없는 상품·노조합 상품은 기본 품목 1개. 옵션 항목·옵션값에는 발급하지 않습니다. |
| 채번 | 상품마다 0001부터 발급 순서대로 매기고, 종료된 번호는 다시 쓰지 않습니다. 표시 순서와는 관계없습니다. |
| 유지 | 가격·재고·품절·순서·관리코드 변경, 관리자 화면에서의 이름 변경 |
| 새 번호 | 새 조합 추가, 삭제 후 재등록, 옵션 항목 구성 변경, 상품 엑셀로 이름 변경(이름으로만 대응하는 경로) |
| 삭제·복구 | 복구할 수 있는 삭제는 유지, 복구하면 기존 번호 그대로, 완전 삭제하면 종료 |
| 기존 상품 | 적용 시점에 있는 상품·조합에 한 번에 부여(조합은 기존 재고 행 순서대로 0001부터) |
| 노출 | 옵션 등록/수정 팝업, 상품 수정 요약 박스, 상품 엑셀 다운로드에 읽기 전용으로 추가(신규 화면 없음) |

## 진행 상태

| 단계 | 상태 |
|---|---|
| 현행 분석 · 방향성 정의 · 기존 상품 적용 기준 | 완료 |
| 정책 수립 | 완료 (기획 리뷰 예정) |
| 와이어프레임 | 초안 완료 (기존 관리자 화면에 품목코드 항목만 추가) |
| CS 운영·응대 가이드 · TC | 예정 |

## 2. 화면별 구조

### WF-001 상품옵션 등록/수정 팝업(기본옵션)

- 목적: 조합옵션 상품의 조합마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 기본옵션설정 > [옵션등록/수정]
- 완료 후 이동: [저 장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, FR-008, POL-030, POL-031, POL-034, POL-036, POL-038, POL-040

![WF-001 상품옵션 등록/수정 팝업(기본옵션)](../04_와이어프레임/wf-001.png)

- 옵션코드 열은 옵션 조합 확인 및 관리 목록의 맨 앞(선택 칸 다음)에 둡니다. 관리코드는 기존 위치 그대로입니다.
- 목록은 순번 오름차순(숫자 기준)입니다. 코드가 없는 새 조합은 맨 뒤에 둡니다.
- 옵션 설정 안내 목록의 "옵션값과 옵션가격의 구분자는 콤마(,)입니다." 다음 줄에 "옵션값 이름을 바꾸거나 지우면 해당 옵션은 새 옵션코드가 부여됩니다."를 추가합니다.
- 미조합(조합 없이 옵션 적용) 상품은 조합 목록이 없으므로 옵션코드를 WF-004에서 확인합니다.

### WF-002 상품옵션 등록/수정 팝업(하이브리드)

- 목적: 하이브리드 옵션의 옵션값마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 기본옵션설정(하이브리드 옵션 사용함) > [옵션등록/수정]
- 완료 후 이동: [저장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, POL-031, POL-034, POL-037

![WF-002 상품옵션 등록/수정 팝업(하이브리드)](../04_와이어프레임/wf-002.png)

- 옵션코드 열은 옵션값 표의 맨 앞(삭제 버튼 다음)에 둡니다. 옵션재고 설정이 "사용안함"이어도 표시합니다.
- 표시 순서는 운영자가 이동(▲▼)으로 정한 순서입니다. 하이브리드는 옵션값 이름을 바꿔도 코드를 유지하므로 이름 변경 안내 문구를 넣지 않습니다.

### WF-003 개별옵션 등록/수정 팝업

- 목적: 개별옵션의 옵션값마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 개별옵션설정 > [옵션등록/수정]
- 완료 후 이동: [저 장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, FR-008, POL-031, POL-034, POL-036, POL-040

![WF-003 개별옵션 등록/수정 팝업](../04_와이어프레임/wf-003.png)

- 옵션코드 열은 옵션 조합 확인 및 관리 목록의 맨 앞(선택 칸 다음)에 둡니다. 개별옵션 관리코드를 노출하는 상점도 같습니다.
- 목록은 순번 오름차순입니다. 옵션 설정 안내에 기본옵션과 같은 문구를 추가합니다.

### WF-004 상품 수정 > 등록상품 수정 요약 박스

- 목적: 조합 목록이 없는 상품(미조합 옵션, 옵션 사용 안 함)의 옵션코드를 확인합니다.
- 진입점·이전 화면: 전체 상품 관리 > 상품명 > 상품 수정(기본정보)
- 완료 후 이동: 해당 없음(조회)
- 관련 요구사항·정책: REQ-004, FR-006, POL-032, POL-035

![WF-004 상품 수정 > 등록상품 수정 요약 박스](../04_와이어프레임/wf-004.png)

- 옵션코드 줄은 미조합 옵션 상품과 옵션 사용 안 함 상품에만 표시합니다. 조합옵션·하이브리드 상품은 팝업에서 확인합니다.
- 상품 등록 화면에는 요약 박스가 없습니다. 신규 상품은 상품등록 후 상품 수정 화면에서 확인합니다.

### WF-005 전체 상품 관리·삭제 상품 조회 > 상품리스트 검색

- 목적: 옵션코드로 상품을 찾습니다.
- 관련 요구사항·정책: REQ-005, FR-009, POL-041, POL-042, POL-043

![WF-005 전체 상품 관리·삭제 상품 조회 > 상품리스트 검색](../04_와이어프레임/wf-005.png)

- "옵션코드"는 상품번호 다음에 둡니다.
- 부분 일치로 찾고 결과는 상품 단위입니다. 상품번호만 넣어도, 코드 전체를 넣어도 같은 상품이 나옵니다.
- 전체 상품 관리는 사용 중 코드로, 삭제 상품 조회는 삭제 상품이 보관 중인 코드로 찾습니다. 결과 목록은 기존과 같습니다.

### WF-006 재고 일괄 관리 > 검색, 옵션별 재고 수정 팝업

- 목적: 옵션코드로 재고를 수정할 상품을 찾고, 옵션별 재고 수정 팝업에서 판매 단위별 옵션코드를 확인합니다.
- 진입점·이전 화면: 재고 일괄 관리 검색 결과 > [옵션별 재고]
- 관련 요구사항·정책: REQ-004, REQ-005, FR-007, FR-009, POL-033, POL-041, POL-042

![WF-006 재고 일괄 관리 > 옵션별 재고 수정 팝업](../04_와이어프레임/wf-006.png)

- 상품검색 선택 항목의 상품번호 다음에 "옵션코드"를 둡니다. 결과는 입력한 옵션코드가 있는 상품 리스트입니다.
- 옵션별 재고 수정 팝업은 옵션코드를 맨 앞 열에 둡니다. 조합 이후의 목록이라 재조합·코드 변경이 없습니다.

### WF-007 재조합 확인창(레이어 팝업)

- 목적: 재조합할 때 옵션값이 같은 조합의 기존 데이터를 유지할지 고릅니다.
- 진입점·이전 화면: WF-001에 조합 목록이 있는 상태에서 [옵션 재조합]
- 완료 후 이동: 선택 후 WF-001(조합 목록 갱신, 저장 전)
- 관련 요구사항·정책: REQ-006, FR-003, POL-022, POL-023, POL-024, POL-025, POL-047

![WF-007 재조합 확인창](../04_와이어프레임/wf-007.png)

- 제목 없이 문구 1줄 "재조합 시 기존 데이터를 유지할까요?"와 버튼 [기존 데이터 유지]·[초기화]·[취소]입니다.
- 옵션 팝업 창 안의 레이어로 띄웁니다. 기존 브라우저 확인창(초기화 안내)을 대신합니다. 특별처리 상점은 기존 확인창을 그대로 띄우고 이 레이어를 띄우지 않습니다.
- 처음 조합할 때([선택된 옵션 조합하기])는 기존 조합이 없으므로 띄우지 않습니다.

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 기존 관리자 화면과 같습니다(PC 기준).
- 키보드·초점 순서: 옵션코드 칸은 읽기 전용이라 입력 초점 순서에서 건너뛰며, 도움말(?)은 초점으로도 열립니다. 재조합 확인창이 열리면 초점이 확인창 안으로 들어가고 Esc로 닫힙니다.
- 오류와 필수값 전달 방식: 기존 저장 오류 방식 그대로입니다.
- 긴 문구: 순번이 10자리 이상으로 늘어나도(예: `M1100006930-1000000000`) 한 줄로 표시하고 자르지 않습니다.
- 법적 고지·동의 노출: 해당 없음

## 2. 화면별 구조

### WF-001 상품옵션 등록/수정 팝업(기본옵션)

- 목적: 조합옵션 상품의 조합마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 기본옵션설정 > [옵션등록/수정]
- 완료 후 이동: [저 장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, POL-031, POL-033, POL-034, POL-036, POL-038

![WF-001 상품옵션 등록/수정 팝업(기본옵션)](../03_Wireframe/wf-001.png)

- 옵션코드 열은 관리코드 바로 앞에 둡니다.
- 목록은 옵션코드 순번 오름차순입니다. 코드가 없는 새 조합은 맨 뒤에 둡니다.
- 미조합(조합 없이 옵션 적용) 상품은 조합 목록이 없으므로 옵션코드를 WF-004에서 확인합니다.

### WF-002 상품옵션 등록/수정 팝업(하이브리드)

- 목적: 하이브리드 옵션의 옵션값마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 기본옵션설정(하이브리드 옵션 사용함) > [옵션등록/수정]
- 완료 후 이동: [저장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, POL-031, POL-033, POL-037

![WF-002 상품옵션 등록/수정 팝업(하이브리드)](../03_Wireframe/wf-002.png)

- 옵션코드 열은 비고 바로 앞에 둡니다. 옵션재고 설정이 "사용안함"이어도 옵션코드 열은 표시합니다.
- 표시 순서는 운영자가 이동(▲▼)으로 정한 순서입니다. 코드 순번과 관계없습니다.

### WF-003 개별옵션 등록/수정 팝업

- 목적: 개별옵션의 옵션값마다 옵션코드를 확인합니다.
- 진입점·이전 화면: 상품 등록·수정 > 개별옵션설정 > [옵션등록/수정]
- 완료 후 이동: [저 장] 후 상품 등록·수정 화면
- 관련 요구사항·정책: REQ-004, FR-005, POL-031, POL-033, POL-036

![WF-003 개별옵션 등록/수정 팝업](../03_Wireframe/wf-003.png)

- 기존 목록에 관리코드·비고 열이 없으므로 옵션코드 열은 상태 뒤(맨 끝)에 둡니다.
- 목록은 옵션코드 순번 오름차순입니다.

### WF-004 상품 수정 > 등록상품 수정 요약 박스

- 목적: 조합 목록이 없는 상품(미조합 옵션, 옵션 사용 안 함)의 옵션코드를 확인합니다.
- 진입점·이전 화면: 전체 상품 관리 > 상품명 > 상품 수정(기본정보)
- 완료 후 이동: 해당 없음(조회)
- 관련 요구사항·정책: REQ-004, FR-006, POL-032, POL-034

![WF-004 상품 수정 > 등록상품 수정 요약 박스](../03_Wireframe/wf-004.png)

- 옵션코드 줄은 미조합 옵션 상품과 옵션 사용 안 함 상품에만 표시합니다. 조합옵션·하이브리드 상품은 팝업에서 확인합니다.
- 상품 등록 화면에는 요약 박스가 없습니다. 신규 상품은 상품등록 후 상품 수정 화면에서 확인합니다.

### WF-005 전체 상품 관리·삭제 상품 조회 > 상품리스트 검색

- 목적: 옵션코드로 상품을 찾습니다.
- 관련 요구사항·정책: REQ-005, FR-007, POL-039, POL-040, POL-041

![WF-005 전체 상품 관리·삭제 상품 조회 > 상품리스트 검색](../03_Wireframe/wf-005.png)

- "옵션코드"는 상품번호 다음에 둡니다.
- 전체 상품 관리는 사용 중 코드로, 삭제 상품 조회는 삭제 상품이 보관 중인 코드로 찾습니다. 결과 목록은 기존과 같습니다.

### WF-006 재고 일괄 관리 > 상품/옵션 재고 수량 검색

- 목적: 옵션코드로 재고를 수정할 상품을 찾습니다.
- 관련 요구사항·정책: REQ-005, FR-007, POL-039, POL-042

![WF-006 재고 일괄 관리 > 상품/옵션 재고 수량 검색](../03_Wireframe/wf-006.png)

- 검색 결과는 입력한 옵션코드가 있는 상품 리스트입니다.

### WF-007 재입고 알림 관리 > 상품검색

- 목적: 옵션코드로 특정 옵션의 재입고 알림 내역을 찾습니다.
- 관련 요구사항·정책: REQ-005, FR-007, POL-039, POL-043

![WF-007 재입고 알림 관리 > 상품검색](../03_Wireframe/wf-007.png)

- 검색 결과는 입력한 코드에 해당하는 옵션의 알림 내역만입니다. 같은 상품의 다른 옵션 내역은 나오지 않습니다.

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 기존 관리자 화면과 같습니다(PC 기준).
- 키보드·초점 순서: 옵션코드 칸은 읽기 전용이라 입력 초점 순서에서 건너뛰며, 도움말(?)은 초점으로도 열립니다.
- 오류와 필수값 전달 방식: 기존 저장 오류 방식 그대로입니다.
- 긴 문구: 순번이 5자리로 늘어나도 한 줄로 표시합니다.
- 법적 고지·동의 노출: 해당 없음

# [CS 운영·응대 가이드] 원본 요청 상품 옵션 식별 체계 개선

상점 운영자 문의에 응대하기 위한 가이드입니다. 판단 기준은 사양 정의서 14장 정책 원장(POL)이며, 이 문서는 새로운 조건을 만들지 않습니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
|---|---|
| 변경 목적 | 판매 단위(옵션 조합 등)마다 이미 있는 번호를 옵션코드로 보여 주고, 옵션을 수정해도 같은 옵션을 계속 정확하게 가리키게 합니다. |
| 적용 대상 | 메이크샵 프리미엄·코어의 모든 상품(신규·기존) |
| 적용 시점 | 배포 일정 확정 후 공지 |
| 고객 영향 | 관리자 옵션 화면에 "옵션코드"가 추가되고, 상품 메뉴 3곳에서 옵션코드로 검색할 수 있습니다. 재조합 확인창이 버튼 3개로 바뀝니다(특별처리 상점은 기존 확인창 유지). 구매자 화면은 바뀌지 않습니다. |
| 기존 고객 처리 | 배포하면 기존 상품에도 바로 옵션코드가 보입니다. |
| 상담 핵심 포인트 | 옵션코드는 시스템이 붙이며 수정할 수 없습니다. 운영자가 입력하는 관리코드와는 다릅니다. 기본옵션·개별옵션은 옵션값 이름을 바꾸면 새 코드를 받습니다. |

## 2. 필수 정책·고지 및 상담 범위

| CON·POL ID | 적용 대상 | 고객에게 안내할 내용 | 필수 확인·고지 시점 | 상담원이 판단하면 안 되는 내용 | 이관 부서 |
|---|---|---|---|---|---|
| POL-002 | 옵션코드 | 옵션코드는 시스템이 자동으로 붙이며 수정·삭제할 수 없습니다. | 수정 요청 시 | 코드 변경·재부여 약속 | 해당 없음 |
| POL-014 | 기본옵션 옵션값 이름 변경 | 옵션값 이름을 바꾸면 그 옵션은 새 코드를 받습니다. 이전 코드로 되돌릴 수 없습니다. | 코드 변경 문의 시 | 이전 코드 복원 약속 | 해당 없음 |
| POL-017 | 삭제 후 다시 추가한 옵션 | 지우고 저장한 뒤 다시 추가한 옵션은 새 코드를 받습니다. | 코드 변경 문의 시 | 이전 코드 복원 약속 | 해당 없음 |
| POL-024 | 재조합 [초기화](특별처리 상점 제외) | [초기화]를 고르면 같은 조합도 재고 0, 판매상태 '판매'가 되며 관리코드·비고도 지워집니다. 옵션코드는 유지됩니다. | 재조합 후 재고 문의 시 | 지워진 재고 값 복구 약속 | 해당 없음 |
| POL-047 | 특별처리 상점 재조합 | 특별처리 상점은 재조합 확인창·관리코드 자동 입력이 기존과 같습니다. 새 확인창은 뜨지 않으며, 옵션코드는 기존 확인창에서 고른 결과에 따라 처리됩니다. | 특별처리 상점 재조합 문의 시 | 새 확인창 버튼 안내, 코드 유지 약속 | 해당 없음 |
| POL-035 | 옵션코드가 비어 있는 기존 상품 | 데이터 확인이 필요한 상품일 수 있습니다. 판매·수정은 평소처럼 됩니다. | 코드 빈 값 문의 시(개발 확인 후) | 빈 값 원인 단정, 표시 시점 약속 | 개발 |

| 옵션 조합 목록 순서 | 조합 순서 | 옵션코드 순서. 나중에 추가한 옵션의 조합은 뒤에 표시 | 없음(구매자 화면 순서는 그대로) | POL-036 |
| 옵션 재조합(특별처리 상점 제외) | "초기화됩니다" 확인 후 재고·상태 초기화 | "재조합 시 기존 데이터를 유지할까요?"에서 [기존 데이터 유지]·[초기화]·[취소] 선택 | 원하는 처리 선택 | POL-022 부터 POL-025 |

| 재고 일괄 관리 > 옵션별 재고 | 옵션코드 없음 | 팝업 맨 앞에 옵션코드 표시 | 없음 | POL-033 |
| 상품 검색 | 옵션코드 검색 없음 | 전체 상품 관리·삭제 상품 조회·재고 일괄 관리에서 "옵션코드"로 검색 | 코드 일부(예: 상품번호)만 입력해도 됨 | POL-041, POL-042 |

## 4. 문의 유형별 응대 가이드

| 문의 유형·증상 | 먼저 확인할 정보 | 확인 경로 | 처리 절차 | 고객 안내 문구 | 관련 POL |
|---|---|---|---|---|---|
| 옵션코드를 고치고 싶다 | 상품번호, 옵션 | 옵션 팝업 | 수정 불가 안내. 기본옵션 조합 상품이면 관리코드 칸 안내(하이브리드·개별옵션은 관리코드 칸이 없으므로 안내하지 않음) | "옵션코드는 시스템이 자동으로 붙이는 값이라 수정하실 수 없습니다." 기본옵션 조합 상품: "직접 관리하실 코드는 옵션 조합 목록의 관리코드 칸을 이용해 주세요." | POL-002 |
| 옵션을 바꿨더니 코드가 달라졌다 | 옵션 유형, 어떤 변경을 했는지(옵션값 이름 변경, 옵션값 추가·삭제와 그 저장 여부, 옵션명 추가·삭제, 옵션 사용 방식 변경) | 옵션 팝업 | 옵션 유형과 변경 종류로 새 코드 여부 설명 | "옵션값 이름을 바꾸시면 그 옵션은 새 코드를 받습니다. 조합 옵션에서 옵션명(예: 소재)을 추가·삭제하시면 조합 코드가 모두 새로 붙습니다. 옵션 삭제를 저장하신 뒤 다시 추가하신 옵션과 옵션 사용 방식을 바꾸신 경우에도 새 코드가 붙습니다." 하이브리드 상품: "하이브리드 옵션은 옵션값 이름을 바꾸셔도 코드가 유지됩니다." | POL-014 부터 POL-021 |
| 재조합했더니 재고가 0이 됐다(특별처리 상점 제외) | 특별처리 상점 여부, 재조합 확인창에서 고른 버튼 | 옵션 팝업 | [초기화]를 고르면 재고가 초기화됨을 설명 | "재조합 확인창에서 [초기화]를 고르시면 재고와 판매상태가 처음 값으로 돌아갑니다. 재고를 유지하시려면 [기존 데이터 유지]를 골라 주세요. 저장하기 전이라면 [닫 기]로 취소하실 수 있습니다." | POL-023, POL-024 |
| 재조합했는데 새 옵션 재고가 0이다 | 새로 추가한 조합인지 | 옵션 팝업 | 새 조합은 초기값임을 설명 | "새로 추가된 조합은 어느 버튼을 고르셔도 재고 0으로 시작합니다. 재고를 입력하신 뒤 저장해 주세요." | POL-025 |
| 특별처리 상점: 재조합 확인창이 다른 상점과 다르다, 재조합 후 재고·코드 문의 | 특별처리 상점 상점인지 | 옵션 팝업 | 기존 특별처리 유지 설명 | "특별처리 상점 쇼핑몰은 재조합 확인창과 관리코드 자동 입력이 기존과 같습니다. 기존처럼 확인창에서 고르신 대로 처리되며, 옵션코드도 그 결과에 따라 표시됩니다." | POL-047 |
| 새로 추가한 옵션 코드가 "자동생성"으로 보인다 | 상품 저장 여부 | 상품 수정 화면 | 저장 후 다시 확인 안내 | "옵션코드는 저장이 완료되면 붙습니다. 신규 상품은 상품등록까지 완료하신 뒤 상품 수정 화면에서 확인해 주세요." | POL-011, POL-012, POL-034 |
| 기존 상품 옵션코드가 비어 있다 | 상품번호 | 옵션 팝업 | 데이터 확인이 필요한 상품인지 개발에 확인 요청. 확인 전에는 원인을 단정하지 않음 | "확인 후 안내드리겠습니다. 판매와 상품 수정은 평소처럼 하실 수 있습니다." | POL-035 |
| 코드 번호가 띄엄띄엄이다 | 옵션 추가·삭제 이력 | 옵션 팝업 | 지운 번호는 다시 쓰지 않음을 설명 | "옵션코드 번호는 만들어진 순서대로 붙고, 지운 옵션의 번호는 다시 쓰지 않아 중간 번호가 비어 보일 수 있습니다. 쇼핑몰에 보이는 옵션 순서는 바뀌지 않습니다." | POL-010, POL-028, POL-036 |
| 옵션코드로 검색이 안 된다 | 입력한 값, 검색한 메뉴 | 해당 메뉴 | 사용 중 코드인지, 검색 가능한 메뉴인지 확인 | "옵션코드는 전체 상품 관리, 삭제 상품 조회, 재고 일괄 관리에서 검색하실 수 있습니다. 삭제한 상품의 코드는 삭제 상품 조회에서 검색해 주세요. 이름을 바꾸거나 지운 옵션의 이전 코드로는 검색되지 않습니다." | POL-041, POL-043 |
| 재입고 알림 관리에서 옵션코드로 찾고 싶다 | 사용 메뉴 | 해당 없음 | 범위 밖 안내 | "재입고 알림 관리의 옵션코드 검색은 이번 업데이트에 포함되지 않았습니다." | CON-003 |
| 엑셀·관리자앱에서 옵션코드를 보고 싶다 | 사용 메뉴 | 해당 없음 | 범위 밖 안내 | "상품 엑셀과 관리자앱의 옵션코드는 이번 업데이트에 포함되지 않았습니다." | CON-002, CON-004 |

|---|---|---|---|---|---|

## 6. 상담원 확인 체크리스트

- [ ] 상점과 상품번호 확인
- [ ] 문의 화면(옵션 팝업·상품 수정·재고 일괄 관리·검색 메뉴) 확인
- [ ] 옵션 유형(기본옵션 조합·미조합, 하이브리드, 개별옵션, 옵션 없음) 확인
- [ ] 최근에 한 옵션 변경(이름 변경·추가·삭제·옵션명 추가·유형 변경·재조합 시 고른 버튼) 확인
- [ ] 저장 완료 여부 확인

## 10. 공지 및 운영 준비

- 고객 공지 필요 여부와 시점: 필요. 배포 전 관리자 공지로 옵션코드 추가·수정 불가·검색 메뉴, 재조합 확인창 변경, 옵션값 이름 변경 시 새 코드를 안내합니다.
- 도움말·매뉴얼 수정: 옵션 등록 매뉴얼에 옵션코드 열, 도움말 문구, 재조합 확인창을 추가합니다.
- 상담 도구·관리자 조회 기능: 상담원은 상점 관리자 화면과 같은 옵션 팝업·검색으로 확인합니다. 종료된 코드는 개발 내부 조회로만 확인할 수 있습니다.
- 장애·대량 문의 발생 시 공지 기준: 같은 옵션의 코드가 바뀌거나 다른 옵션과 겹치는 사례가 여러 상점에서 확인되면 공지합니다.
- 알려진 제한사항: 상품 엑셀·재입고 알림 관리·관리자앱·주문 메뉴에서는 옵션코드를 제공하지 않습니다. Open API는 조회만 됩니다.

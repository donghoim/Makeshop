## 2. 배경과 문제

| 항목 | 내용 |
|---|---|
| 배경 | 운영 상점(VIP)이 전체 상품 관리처럼 재고 일괄 관리에서도 상품번호를 쉼표로 여러 개 넣어 검색하기를 요청했습니다. 상품번호 복수 검색은 전체 상품 관리·가상분류 상품관리·분류 검색필터 일괄 관리 등 다른 메뉴에서 이미 제공합니다. |
| 해결할 문제 | ① 상품번호 검색은 한 번에 한 상품만 찾습니다. 쉼표로 여러 번호를 넣으면 오류 없이 첫 번째 번호의 상품만 나와, 운영자가 나머지가 없는 것으로 오해할 수 있습니다. ② '검색된 상품 엑셀다운'에 상품번호 조건이 빠져, 상품번호로 검색해도 다른 조건에 맞는 상품 전체가 내려받아집니다. |
| 사용자·운영 영향 | 여러 상품의 옵션 재고를 고칠 때 상품번호마다 검색을 반복합니다. 엑셀다운 파일에 검색하지 않은 상품이 섞여, 파일을 고쳐 다시 올릴 때 다른 상품 재고를 잘못 바꿀 위험이 있습니다. |
| 확인 근거 | 관련 Task 본문·댓글(2026-10-27·28), 요구사항·AS-IS 분석서 v2, 테스트 상점 화면 확인(2026-11-04): 상품번호 1개 검색 시 화면 1건·엑셀 11건(검색 조건의 전체 상품), '번호A,번호B' 검색 시 번호A 1건만 표시 |

## 3. 목표와 범위

### 3.1 목표

- 재고 일괄 관리에서 쉼표로 구분한 여러 상품번호로 상품과 옵션 재고를 한 번에 조회합니다.
- '검색된 상품 엑셀다운' 결과가 화면 검색 결과와 같습니다.
- 재고 화면과 엑셀다운이 전체 상품 관리와 같은 상품번호 검색 처리를 사용합니다.

### 3.2 포함 범위

- 재고 일괄 관리 상품검색 '상품번호'의 쉼표 복수 검색(통합옵션 재고 화면, 구 재고 화면)
- '검색된 상품 엑셀다운'에 화면 검색 조건 전체 적용(상품번호 조건 누락 수정 포함)
- 화면 하단 안내 목록에 복수 검색 안내 한 줄 추가

### 3.3 제외 범위

- 상품번호 외 검색 항목(상품명·키워드·상품코드·상품 바코드)의 화면 검색 방식 변경
- 줄바꿈·공백만으로 구분한 입력. 구분자는 반각 쉼표(,)와 전각 쉼표(，)입니다.
- 재고 수정, 옵션재고 수정, 엑셀로 등록, 엑셀 샘플 양식 다운
- 엑셀다운 파일의 형식(xml)·열·정렬 변경
- 다른 메뉴(가상분류 상품관리·분류 검색필터 일괄 관리·아이콘 일괄관리)의 복수 검색을 공통 처리로 통일하는 작업(후속 과제)
- 모바일 관리자(해당 화면 없음)

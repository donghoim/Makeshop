# [요구사항 정의서] 원본 요청 재고 일괄 관리 상품번호 복수 검색

## 1. 문서 목적

재고 일괄 관리에서 상품번호를 여러 개 넣어 검색해야 하는 이유와, 무엇을 만족해야 하는지 정리합니다. 상세 정책은 정책서, 기능·수용 조건은 사양 정의서에서 관리합니다.

## 2. 요청 배경 및 목표

### 2.1. 요청 배경

- 운영 상점(VIP, 1:1 문의)는 전체 상품 관리에서 상품번호를 쉼표로 구분해 여러 상품을 한 번에 검색하고 있습니다.
- 재고 일괄 관리에서는 상품번호를 한 개씩 검색해야 해서, 여러 상품의 재고를 확인·수정할 때 같은 검색을 반복합니다.
- 운영팀은 여러 상품 메뉴에서 이미 복수 검색을 제공하고 있고, 재고 일괄 관리는 수시로 엑셀을 내려받고 올려 상품을 고치는 화면이라 개선이 필요하다고 판단했습니다(관련 Task 댓글, 2026-10-27).

### 2.2. 운영자가 필요한 결과

- 상품번호 여러 개로 상품과 옵션 재고를 한 번에 조회할 수 있어야 합니다.
- 화면에서 찾은 상품만 엑셀로 내려받아, 고친 파일을 올렸을 때 다른 상품의 재고가 바뀌지 않아야 합니다.

## 3. 현행 기능 및 해결 과제

### 3.1. 현행 동작 (테스트 상점 확인, 2026-11-04)

| 기능 | 현행 동작 |
|---|---|
| 상품검색 항목 | 상품명·키워드·상품코드·상품번호·상품 바코드 중 하나를 골라 검색합니다. |
| 상품번호 검색 | 입력한 값 하나와 같은 상품만 찾습니다. `A,B`를 넣으면 오류 없이 A만 나옵니다. |
| 검색된 상품 엑셀다운 | 검색 전에는 비활성, 검색 후 활성입니다. 상품번호로 검색해도 상품번호 조건이 빠져, 다른 조건(분류·항목 선택)에 맞는 상품이 모두 내려받아집니다. |
| 상품명 검색 엑셀다운 | 화면과 같은 상품이 내려받아집니다. |
| 화면 안내 | 상품번호를 여러 개 넣을 수 있다는 안내가 없습니다. 전체 상품 관리에도 없습니다. |

### 3.2. 문제 원인

- 재고 화면과 엑셀다운이 전체 상품 관리의 공통 검색 처리를 쓰지 않고 각자 검색 조건을 만듭니다(분석서 CAUSE-01).
- 그래서 재고 화면은 상품번호를 하나만 비교하고, 엑셀다운은 상품번호 조건을 빠뜨립니다.

### 3.3. 문제 예시

| 순서 | 운영자 작업 | 현행 결과 | 영향 |
|---|---|---|---|
| 1 | 상품번호 `1001,1002` 검색 | 1001만 표시 | 1002가 없는 상품으로 오해 |
| 2 | 1001만 검색 후 엑셀다운 | 화면 1건, 파일에는 조건에 맞는 다른 상품까지 포함 | 파일 확인 부담 |
| 3 | 받은 파일을 고쳐 엑셀로 등록 | 의도하지 않은 상품의 재고까지 반영될 수 있음 | 재고 오류 |

## 4. 요구사항

| REQ ID | 요구사항 | 필수 여부 |
|---|---|---|
| REQ-001 | 여러 상품번호를 한 번에 넣어 해당 상품과 옵션 재고를 조회할 수 있어야 합니다. | 필수 |
| REQ-002 | 검색된 상품 엑셀다운은 화면에서 찾은 상품만 내려받아야 합니다. | 필수 |
| REQ-003 | 상품번호를 여러 개 넣을 수 있다는 것을 화면에서 알 수 있어야 합니다. | 필수 |
| REQ-004 | 상점의 통합옵션 사용 여부와 관계없이 재고 일괄 관리의 검색 동작이 같아야 합니다. | 필수 |

## 5. 대표 사용자 시나리오

| 시나리오 | 기대 결과 |
|---|---|
| 운영자가 품절 임박 상품 5개의 재고를 확인하려고 상품번호 5개를 쉼표로 넣어 검색 | 5개 상품과 옵션 재고가 한 화면에 나옵니다. |
| 메신저로 받은 상품번호 목록을 붙여 넣었는데 전각 쉼표(，)가 섞여 있음 | 반각 쉼표와 똑같이 나뉘어 모든 상품이 나옵니다. |
| 붙여 넣은 목록에 빈칸·빈 값·오타(문자)가 섞여 있음 | 오류 없이 올바른 번호의 상품만 나옵니다. |
| 검색 결과를 엑셀로 받아 재고를 고친 뒤 다시 올림 | 파일에 검색한 상품만 있어 그 상품의 재고만 바뀝니다. |

## 6. 범위

| 구분 | 내용 |
|---|---|
| 포함 | 재고 일괄 관리 상품번호 복수 검색(통합옵션 재고 화면, 구 재고 화면), 검색된 상품 엑셀다운의 화면 조건 일치, 하단 안내 문구 한 줄 |
| 제외 | 상품번호 외 검색 항목의 화면 검색 방식, 재고 수정·엑셀로 등록·엑셀 샘플 양식, 엑셀 파일 형식·열·정렬, 줄바꿈·공백만으로 나눈 입력, 다른 메뉴의 복수 검색 통일(후속), 모바일 관리자 |

## 7. 완료 기준

- 상품 1001·1002가 있을 때 `1001, 1002`로 검색하면 두 상품과 옵션 재고가 나옵니다.
- 그 상태에서 검색된 상품 엑셀다운을 받으면 두 상품만 들어 있습니다.
- `1001` 하나로 검색하면 지금처럼 1001만 나옵니다.
- `1001,,abc`로 검색해도 오류 없이 1001만 나옵니다.

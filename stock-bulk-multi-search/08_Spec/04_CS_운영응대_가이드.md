# [CS 운영·응대 가이드] 원본 요청 재고 일괄 관리 상품번호 복수 검색

상점 운영자 문의에 응대하기 위한 가이드입니다. 판단 기준은 사양 정의서 14장 정책 원장(POL)이며, 이 문서는 새로운 조건을 만들지 않습니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
|---|---|
| 변경 목적 | 재고 일괄 관리에서 여러 상품을 한 번에 찾고, 엑셀다운 파일을 화면 결과와 맞춥니다. |
| 적용 대상 | 메이크샵 전체 상점의 재고 일괄 관리(통합옵션 사용·미사용 모두) |
| 적용 시점 | 배포 일정 확정 후 공지 |
| 고객 영향 | 상품번호를 쉼표로 여러 개 넣어 검색할 수 있습니다. 검색된 상품 엑셀다운은 화면에 나온 상품만 내려받습니다. 구매자 화면은 바뀌지 않습니다. |
| 상담 핵심 포인트 | 엑셀다운 파일의 상품 수가 예전보다 줄 수 있으며, 이는 화면 결과와 같아진 것입니다. |

## 2. 필수 정책·고지 및 상담 범위

| CON·POL ID | 적용 대상 | 고객에게 안내할 내용 | 필수 확인·고지 시점 | 상담원이 판단하면 안 되는 내용 | 이관 부서 |
|---|---|---|---|---|---|
| POL-001 | 상품번호 검색 | 상품번호를 쉼표(,)로 구분해 넣으면 여러 상품을 한 번에 찾습니다. 넓은 쉼표(，)도 같게 인식합니다. | 사용법 문의 시 | 다른 검색 항목(상품명 등)도 여러 개 검색된다고 안내 | 해당 없음 |
| POL-004 | 상품번호 검색 | 숫자가 아닌 값은 검색에서 빠집니다. | 일부 상품이 안 나온다는 문의 시 | 없음 | 해당 없음 |
| POL-007 | 상품번호 검색 | 넣을 수 있는 개수 제한은 없습니다. | 개수 문의 시 | 특정 개수까지 된다고 보장 | 해당 없음 |
| POL-010 | 검색된 상품 엑셀다운 | 화면에 나온 상품만 파일에 들어갑니다. | 파일 상품 수 문의 시 | 예전 방식으로 되돌릴 수 있다고 안내 | 해당 없음 |

## 4. 문의 유형별 응대 가이드

| 문의 유형·증상 | 먼저 확인할 정보 | 확인 경로 | 처리 절차 | 고객 안내 문구 | 관련 POL |
|---|---|---|---|---|---|
| 상품번호 여러 개를 넣었는데 일부만 나온다 | 입력한 값, 상품검색 항목, 진열 여부·항목 선택 | 재고 일괄 관리 화면(상점 화면 공유 또는 캡처) | ① 상품검색이 '상품번호'인지 확인 ② 번호 사이가 쉼표인지 확인 ③ 다른 검색 조건 확인 | "상품번호 사이를 쉼표로 구분해 주세요. 진열 여부나 항목 선택 같은 다른 조건에 맞지 않는 상품은 함께 나오지 않습니다." | POL-001, POL-004, POL-009 |
| 상품명·상품코드도 여러 개 넣어 검색하고 싶다 | 사용한 검색 항목 | 재고 일괄 관리 화면 | 상품번호만 지원함을 안내 | "여러 개 검색은 상품번호에서만 지원합니다. 상품번호를 쉼표로 구분해 검색해 주세요." | POL-013 |
| 엑셀다운 파일에 상품이 예전보다 적다 | 검색 조건, 화면 목록 수 | 재고 일괄 관리 화면 | 화면 목록 수와 파일 상품 수가 같은지 확인 | "검색된 상품 엑셀다운은 화면에 나온 상품만 내려받도록 바뀌었습니다. 더 많은 상품이 필요하시면 검색 조건을 넓혀 다시 검색해 주세요." | POL-010 |
| 화면 목록과 엑셀 파일 상품이 다르다 | 검색 조건, 화면 목록, 파일 상품 목록 | 상점 제공 화면 캡처·파일 | 같은 조건으로 재현되면 이관 | "확인을 위해 담당 부서에 전달하겠습니다. 확인되는 대로 안내드리겠습니다." | POL-010 |
| 넓은 쉼표(，)로 넣었는데 검색이 안 된다 | 입력한 값 | 상점 제공 캡처 | 반각 쉼표로 다시 검색 안내 후 같은 증상이면 이관 | "번거로우시겠지만 키보드 쉼표(,)로 다시 검색해 주시겠어요? 같은 증상이면 담당 부서에 전달하겠습니다." | POL-001, CON-002 |

## 5. 상태·오류별 고객 안내

| 상태·오류 | 고객에게 보이는 내용 | 안내 문구 | 후속 조치 | 관련 POL |
|---|---|---|---|---|
| 유효한 번호가 없음 | '조건에 맞는 검색 결과가 없습니다.' | "입력하신 값에 숫자로 된 상품번호가 없거나, 다른 검색 조건에 맞는 상품이 없습니다. 입력값과 조건을 확인해 주세요." | 없음 | POL-005 |
| 없는 상품번호 포함 | 있는 상품만 표시 | "상점에 없는 상품번호는 검색 결과에 나오지 않습니다." | 없음 | POL-006 |
| 검색 전 엑셀다운 버튼 비활성 | 버튼을 누를 수 없음 | "먼저 [조건 검색]을 눌러 주세요." | 없음 | POL-015 |

## 6. 상담 체크리스트

- 상품검색 항목이 '상품번호'인지 확인합니다.
- 번호 사이 구분자가 쉼표인지 확인합니다.
- 진열 여부·분류·항목 선택 같은 다른 검색 조건을 확인합니다.
- 엑셀 문의는 화면 목록 수와 파일 상품 수를 비교합니다.

## 7. 이관 기준

| 이관 조건 | 이관 부서 | 전달 정보 |
|---|---|---|
| 같은 검색 조건인데 화면 목록과 엑셀 파일의 상품이 다름 | 개발 | 상점 ID, 검색 조건, 화면 캡처, 내려받은 파일 |
| 쉼표로 구분한 숫자 상품번호가 검색되지 않음 | 개발 | 상점 ID, 입력값 원문, 화면 캡처 |

## 9. FAQ

| 질문 | 답변 |
|---|---|
| 몇 개까지 넣을 수 있나요? | 개수 제한은 없습니다. |
| 줄바꿈으로 구분해도 되나요? | 쉼표로 구분해 주세요. 줄바꿈이나 띄어쓰기만으로는 여러 개로 인식하지 않습니다. |
| 입력 순서대로 나오나요? | 아닙니다. 화면 오른쪽 위에서 고른 정렬 기준을 따릅니다. |
| 전체 상품 관리도 바뀌나요? | 넓은 쉼표(，)도 인식하게 됩니다. 그 밖의 동작은 같습니다. |

## 10. 공지·운영 준비

- 배포 공지에 상품번호 복수 검색 지원과 검색된 상품 엑셀다운 결과 변경을 함께 안내합니다.
- 공지 문구(안): "재고 일괄 관리에서 상품번호를 쉼표(,)로 구분해 여러 상품을 한 번에 검색할 수 있습니다. 검색된 상품 엑셀다운은 화면에 검색된 상품만 내려받도록 개선했습니다."

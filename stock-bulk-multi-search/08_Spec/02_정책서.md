## 2. 변경 사항 요약

이번 개선으로 무엇이 바뀌는지 요약합니다.

### 2.1 한 줄 요약

재고 일괄 관리에서 상품번호를 쉼표로 여러 개 넣어 한 번에 검색하고, 검색된 상품 엑셀다운은 화면에 나온 상품만 내려받습니다.

### 2.2 변경 목적

- 여러 상품의 재고를 확인·수정할 때 상품번호마다 검색을 반복하지 않게 합니다.
- 엑셀다운 파일에 검색하지 않은 상품이 섞여, 고친 파일을 올렸을 때 다른 상품의 재고가 바뀌는 일을 막습니다.
- 재고 화면, 검색된 상품 엑셀다운, 전체 상품 관리가 같은 상품번호 검색 처리를 쓰게 해서 화면과 파일의 결과가 어긋나지 않게 합니다.

### 2.3 변경 전·후

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 상품번호 검색 | 값 하나와 같은 상품만 찾습니다. `A,B`를 넣으면 A만 나옵니다. | 반각·전각 쉼표로 나눈 값마다 같은 상품을 모두 찾습니다. |
| 잘못된 입력 | 입력값을 정리하지 않고 검색 조건에 씁니다. | 앞뒤 공백을 지우고, 빈 값과 숫자가 아닌 값은 뺍니다. |
| 검색된 상품 엑셀다운 | 상품번호 조건이 빠져 다른 상품까지 내려받습니다. 상품코드로 검색하면 상품번호가 같은 상품까지 포함합니다. | 화면 검색과 같은 조건으로 같은 상품만 내려받습니다. |
| 화면 안내 | 복수 검색 안내가 없습니다. | 하단 안내 목록에 복수 검색 안내 한 줄을 추가합니다. |
| 전체 상품 관리 | 반각 쉼표로만 나눕니다. | 같은 검색 처리를 쓰므로 전각 쉼표도 나눕니다. 반각 쉼표 결과는 같습니다. |

## 3. 적용 대상 및 범위

이번 정책을 적용하는 화면과 이번에 다루지 않는 범위입니다.

### 적용 대상

- 메이크샵 전체 버전 상점(EUC-KR 상점, UTF-8 상점)
- 재고 일괄 관리 화면: 통합옵션을 쓰는 상점의 재고 화면과 통합옵션을 쓰지 않는 상점의 구 재고 화면
- 재고 일괄 관리의 검색된 상품 엑셀다운
- 전체 상품 관리의 상품번호 검색(전각 쉼표 구분에 한함)

### 포함 범위

- 상품검색 '상품번호'의 복수 검색과 입력값 정리
- 검색된 상품 엑셀다운의 검색 조건
- 하단 안내 문구 한 줄

### 제외 및 예외 범위

- 상품명·키워드·상품코드·상품 바코드의 화면 검색 방식은 바꾸지 않습니다.
- 재고 수정, 옵션재고 수정, 엑셀로 등록, 엑셀 샘플 양식 다운은 바꾸지 않습니다.
- 엑셀다운 파일의 형식(xml)·열·정렬은 바꾸지 않습니다.
- 줄바꿈이나 공백만으로 나눈 입력은 여러 값으로 보지 않습니다.
- 가상분류 상품관리·분류 검색필터 일괄 관리·아이콘 일괄관리의 복수 검색은 이번에 바꾸지 않습니다.
- 모바일 관리자에는 재고 일괄 관리 화면이 없어 해당하지 않습니다.

### 이용 조건

- 재고 일괄 관리 메뉴에 접근할 수 있는 관리자 권한이 있어야 합니다. 권한 기준은 바꾸지 않습니다.
- 운영자가 따로 설정할 것은 없습니다. 모든 상점에 같은 규칙을 적용하고 상점별 분기를 두지 않습니다.

## 4. 상세 정책

### 4.1 상품번호 구분자

상품번호 칸에 넣은 값을 여러 상품번호로 나누는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 적용 조건 | 상품검색 항목이 '상품번호'일 때만 적용합니다. 다른 항목은 지금처럼 값 하나로 검색합니다. |
| 구분자 | 반각 쉼표(,)와 전각 쉼표(，)를 같은 구분자로 봅니다. |
| 구분자가 없을 때 | 값 하나로 검색합니다. 지금과 같은 결과입니다. |
| 문자셋 | EUC-KR 상점과 UTF-8 상점 모두에서 전각 쉼표를 구분자로 인식합니다. 두 문자셋은 전각 쉼표의 문자 코드가 다르므로 각각 인식해야 합니다. |
| 입력 개수 | 한 번에 넣을 수 있는 상품번호 개수를 제한하지 않습니다. 전체 상품 관리와 같습니다. |

전각 쉼표를 구분자로 인정하는 근거는 다음과 같습니다.

- 운영자는 상품번호 목록을 엑셀, 메신저, 문서에서 복사해 붙여 넣는 경우가 많습니다. 이때 한글 입력 상태에서 입력됐거나 문서 서식이 바뀐 전각 쉼표가 섞일 수 있습니다.
- 전각 쉼표를 인정하지 않으면 `1001，1002`가 숫자가 아닌 값 하나가 되어 검색에서 빠집니다. 오류 없이 결과가 비거나 줄어들어, 운영자가 상품이 없는 것으로 오해합니다.
- 이번 개선의 목적은 여러 상품을 빠짐없이 한 번에 찾는 것이므로, 눈으로 구분하기 어려운 두 쉼표를 같게 처리합니다.

관련 정책: POL-001, POL-007

### 4.2 입력값 정리

구분자로 나눈 값을 검색 조건으로 쓰기 전에 정리하는 기준입니다. 아래 순서대로 적용합니다.

| 순서 | 대상 | 처리 | 예시 |
| --- | --- | --- | --- |
| 1 | 나눈 값 | 앞뒤 공백을 지웁니다. | `1001, 1002` → `1001`, `1002` |
| 2 | 공백을 지운 값 | 빈 값은 뺍니다. | `1001,,1002` → `1001`, `1002` |
| 3 | 남은 값 | 숫자로만 이뤄지지 않은 값은 뺍니다. | `1001,abc` → `1001` |
| 4 | 남은 값 | 같은 번호는 하나로 봅니다. | `1001,1001` → `1001` |

- 입력 원문은 검색 조건에 그대로 넣지 않고, 위 순서로 남은 숫자 값으로만 조건을 만듭니다. 화면 검색과 엑셀다운에 똑같이 적용합니다.
- 검색한 뒤 입력란에는 운영자가 넣은 값이 그대로 남습니다.

관련 정책: POL-002, POL-003, POL-004, POL-008

### 4.3 검색 결과

정리한 상품번호로 상품을 찾는 기준입니다.

| 경우 | 결과 |
| --- | --- |
| 남은 번호가 하나 이상 | 남은 번호와 일치하는 상품을 모두 목록에 표시합니다. |
| 남은 번호 중 없는 상품번호가 있음 | 있는 상품만 표시합니다. 없는 번호는 따로 안내하지 않습니다. |
| 남은 번호가 하나도 없음 | 결과 0건이며 '조건에 맞는 검색 결과가 없습니다.'를 표시합니다. 오류 메시지는 띄우지 않습니다. |
| 다른 검색 조건(분류·진열 여부·항목 선택)을 함께 지정 | 모든 조건을 함께 만족하는 상품만 표시합니다. |
| 정렬 | 화면에서 고른 정렬 기준을 따릅니다. 입력한 순서와 관계없습니다. |

관련 정책: POL-005, POL-006, POL-009

### 4.4 검색된 상품 엑셀다운

검색된 상품 엑셀다운이 내려받는 상품의 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 버튼 활성 | 검색 전에는 비활성, 조건 검색을 한 뒤에는 활성입니다. 지금과 같습니다. |
| 적용 조건 | 화면 검색에 쓴 조건 전체(검색 유형, 분류, 진열 여부, 항목 선택, 상품검색 항목, 검색어, 검색 포함 전체 옵션 노출)를 그대로 적용합니다. |
| 상품번호로 검색했을 때 | 4.1·4.2·4.3과 같은 규칙으로 화면에 나온 상품만 내려받습니다. |
| 상품코드로 검색했을 때 | 화면과 같은 상품코드 조건만 적용합니다. 상품번호가 같은 상품을 추가로 넣지 않습니다. |
| 그 밖의 검색 항목 | 화면과 같은 상품을 내려받습니다. |
| 파일 형식 | 엑셀(xml) 형식, 열 구성, 정렬(등록일 최신순)은 지금과 같습니다. |

관련 정책: POL-010, POL-011, POL-014, POL-015

### 4.5 화면 안내

운영자가 복수 검색을 알 수 있도록 안내하는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 위치 | 재고 일괄 관리 하단 안내 목록, '검색 포함 전체 옵션 노출' 안내 바로 아래 |
| 문구 | 상품검색에서 “상품번호” 선택 시 쉼표(,)로 구분해 여러 상품을 한 번에 검색할 수 있습니다. |
| 입력란 | 입력란의 크기·위치는 바꾸지 않습니다. |

관련 정책: POL-001

### 4.6 화면별 적용

같은 규칙을 적용하는 화면의 범위입니다.

| 화면 | 적용 내용 |
| --- | --- |
| 재고 일괄 관리(통합옵션 사용 상점) | 4.1부터 4.5까지 모두 적용합니다. |
| 재고 일괄 관리 구 화면(통합옵션 미사용 상점) | 4.1·4.2·4.3·4.5를 적용합니다. 이 화면에는 검색된 상품 엑셀다운이 없습니다. |
| 전체 상품 관리 | 같은 검색 처리를 쓰므로 4.1의 전각 쉼표 구분을 함께 적용합니다. 반각 쉼표로 검색한 결과와 그 밖의 동작은 지금과 같습니다. |

관련 정책: POL-012, POL-013, POL-016

### 4.7 처리 흐름

| 순서 | 운영자 | 시스템 |
| --- | --- | --- |
| 1 | 재고 일괄 관리에 들어갑니다. | 목록을 비우고 검색된 상품 엑셀다운을 비활성으로 둡니다. |
| 2 | 상품검색을 '상품번호'로 고르고 번호를 쉼표로 넣은 뒤 [조건 검색]을 누릅니다. | 반각·전각 쉼표로 나누고 공백 제거 → 빈 값 제외 → 숫자 아닌 값 제외 → 중복 제거 순서로 정리합니다. |
| 3 | 결과를 확인합니다. | 남은 번호와 다른 검색 조건을 모두 만족하는 상품을 표시하고, 엑셀다운을 활성으로 바꿉니다. |
| 4 | [검색된 상품 엑셀다운]을 누릅니다. | 같은 조건으로 상품을 찾아 화면과 같은 상품만 파일로 내려줍니다. |
| 5 | 파일을 고쳐 [엑셀로 등록]으로 올립니다. | 지금과 같이 재고를 반영합니다. |

### 4.8 오류 및 예외 처리

| 상황 | 처리 |
| --- | --- |
| 숫자가 아닌 값·빈 값이 섞임 | 해당 값만 빼고 나머지로 검색합니다. 검색 전체를 실패시키지 않습니다. |
| 유효한 번호가 하나도 없음 | 결과 0건과 기존 0건 문구를 표시합니다. 알림창을 띄우지 않습니다. |
| 없는 상품번호 | 결과에서 빠집니다. 따로 안내하지 않습니다. |
| 따옴표·기호가 들어간 값 | 숫자가 아닌 값이므로 뺍니다. 검색 조건에 원문이 들어가지 않습니다. |
| 같은 번호를 여러 번 넣음 | 상품을 한 번만 표시합니다. |
| 검색 결과 0건에서 엑셀다운 | 지금처럼 빈 파일을 내려받습니다. |

관련 정책: POL-004, POL-005, POL-006, POL-008

## 5. 고객 영향 및 안내

### 고객이 반드시 알아야 할 내용

- 재고 일괄 관리에서 상품번호를 쉼표로 구분해 여러 상품을 한 번에 검색할 수 있습니다.
- 검색된 상품 엑셀다운은 화면에 나온 상품만 내려받습니다. 예전보다 파일에 들어가는 상품이 적을 수 있는데, 화면과 같아진 것이며 상품이 빠진 것이 아닙니다.

### 고객 영향

| 대상 | 영향 |
| --- | --- |
| 쇼핑몰 운영자 | 여러 상품 재고를 한 번에 확인·수정할 수 있습니다. 엑셀다운 결과가 화면 결과와 같아집니다. |
| 구매자 | 영향이 없습니다. |
| 저장 데이터 | 바뀌지 않습니다. 검색과 내려받기 결과만 바뀝니다. |

### 안내 방식

- 배포 공지에 상품번호 복수 검색 지원과 엑셀다운 결과 변경을 함께 안내합니다.
- 화면 하단 안내 목록에 복수 검색 안내 한 줄을 추가합니다.

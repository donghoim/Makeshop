## 2. 화면별 구조

### WF-001·WF-002·WF-004 재고 일괄 관리 검색·목록

- 목적: 상품번호 여러 개로 상품과 옵션 재고를 한 번에 찾습니다.
- 진입점·이전 화면: 좌측 메뉴 일괄 관리 > 재고 일괄 관리
- 완료 후 이동: 같은 화면(검색 결과 목록), [검색된 상품 엑셀다운] → WF-003
- 관련 요구사항·정책: REQ-001, REQ-003, FR-001, FR-004, POL-001부터 POL-009, CON-001, CON-002

**처음 진입(검색 전)**

![처음 진입](../03_Wireframe/wf-1-1.png)

- 검색 영역(WF-001)의 항목·순서·입력란 크기는 그대로입니다.
- 하단 안내 목록(WF-004)의 '검색 포함 전체 옵션 노출' 안내 바로 아래에 복수 검색 안내 한 줄을 넣습니다.
- 검색된 상품 엑셀다운은 검색 전 비활성입니다.

**여러 상품번호로 검색**

![여러 상품번호로 검색](../03_Wireframe/wf-1-2.png)

- 입력한 번호와 일치하는 상품을 모두 목록(WF-002)에 표시합니다. 목록 열·정렬·재고수정·옵션재고수정은 그대로입니다.

**입력값 정리**

![입력값 정리](../03_Wireframe/wf-1-3.png)

- 공백·빈 값·숫자가 아닌 값·중복 번호·없는 번호가 섞여도 오류 없이 남은 번호의 상품만 나옵니다.

**유효한 번호가 없음**

![유효한 번호가 없음](../03_Wireframe/wf-1-4.png)

- 기존 0건 문구를 그대로 씁니다.

**다른 검색 조건과 함께**

![다른 검색 조건과 함께](../03_Wireframe/wf-1-5.png)

- 진열 여부·분류·항목 선택 조건을 모두 만족하는 상품만 나옵니다.

### WF-003 검색된 상품 엑셀다운

- 목적: 화면 목록과 같은 상품만 엑셀(xml)로 내려받습니다.
- 진입점·이전 화면: WF-002 목록 상단 [검색된 상품 엑셀다운]
- 완료 후 이동: 파일 내려받기 후 같은 화면
- 관련 요구사항·정책: REQ-002, FR-003, POL-010, POL-011, POL-014, POL-015

![검색된 상품 엑셀다운 미리보기](../03_Wireframe/wf-2-1.png)

- 실제 화면은 창 없이 파일을 바로 내려받습니다. 위 창은 파일 내용을 확인하기 위한 목업 전용 미리보기입니다.
- 파일 형식·열·정렬은 그대로입니다.

### WF-005 재고 일괄 관리(구 재고 화면)

- 목적: 통합옵션을 쓰지 않는 상점에서도 같은 검색 동작을 제공합니다.
- 진입점·이전 화면: 좌측 메뉴 일괄 관리 > 재고 일괄 관리(통합옵션 미사용 상점)
- 완료 후 이동: 같은 화면
- 관련 요구사항·정책: REQ-004, FR-002, POL-012

- 화면 구성은 바꾸지 않고 WF-001·WF-002·WF-004와 같은 규칙을 적용합니다. 이 화면에는 검색된 상품 엑셀다운이 없습니다.
- 테스트 상점이 통합옵션 사용 상점이라 목업에는 넣지 않았습니다.

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 관리자 PC 화면만 해당합니다. 모바일 관리자에는 재고 일괄 관리 화면이 없습니다.
- 키보드·초점 순서: 현행과 같습니다. 검색어 입력란에서 Enter로 검색합니다.
- 오류와 필수값 전달 방식: 잘못된 값은 오류 메시지 없이 빼고 검색합니다.
- 긴 문구·다국어 대응: 입력란 크기는 그대로이며 긴 입력은 입력란 안에서 가로로 이어집니다.
- 법적 고지·동의 노출: 해당 없음

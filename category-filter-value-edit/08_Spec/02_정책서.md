# [정책서] 원본 요청 분류 검색 필터 상세값 수정

## 1. 문서 정보

분류 검색 필터의 상세값 명칭을 고치고, 상세값 순서 이동을 안내하고, 검색 필터 일괄 변경의 작업 유형을 나눌 때 적용하는 정책입니다.

## 2. 변경 사항 요약

이번 개선으로 무엇이 바뀌는지 요약합니다.

### 2.1 한 줄 요약

등록된 필터 상세값의 명칭을 화면에서 바로 고치면 그 값을 쓰는 모든 상품과 쇼핑몰 검색 필터에 반영되고, 일괄 변경은 작업 유형 4가지로 나눠 보여 줍니다.

### 2.2 변경 목적

- 상세값 오타나 단어를 바꿀 때 값을 지우고 다시 만들어 상품마다 다시 적용하는 일을 없앱니다.
- 상세값 순서를 드래그로 바꿀 수 있다는 것을 화면에서 알 수 있게 합니다.
- 일괄 변경에서 상품에 적용된 값을 바꾸는 작업과 필터값 자체의 이름을 바꾸는 작업을 구분합니다.

### 2.3 변경 전·후

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 검색 필터 설정 표 상세값 | 명칭을 고칠 수 없습니다. | 수정 아이콘으로 고치고, 확인하면 바로 저장됩니다. |
| 상세값 순서 | 드래그로 바꿀 수 있지만 표시가 없습니다. | 칩 왼쪽에 이동 아이콘을 표시하고 '필터 상세값' 툴팁으로 안내합니다. |
| 생성·관리 팝업 상세값 | 추가·삭제만 됩니다. | 명칭도 고칠 수 있고, 하단 [등록]·[수정]으로 한 번에 저장합니다. |
| 일괄 변경 팝업 | 변경방식 설정: 변경·추가·삭제 | 작업 유형: 상품 적용값 변경·필터값명 수정·필터값 추가·필터값 적용 해제 |

## 3. 적용 대상 및 범위

이번 정책을 적용하는 화면과 이번에 다루지 않는 범위입니다.

### 적용 대상

- 분류 검색 필터를 쓰는 상점(주문 2.0·통합옵션 버전), EUC-KR 상점과 UTF-8 상점
- 검색 필터 설정 화면의 분류 검색 필터 표
- 분류 검색 필터 생성 팝업([필터추가+])과 관리 팝업([관리])
- 검색 필터 일괄 관리의 상품 분류 검색 필터 일괄 변경 팝업

### 포함 범위

- 상세값 명칭 수정과 입력 검증, 수정 확인 안내
- 상세값 이동 아이콘과 '필터 상세값' 툴팁
- 일괄 변경 작업 유형 4가지와 유형별 툴팁

### 제외 및 예외 범위

- 상품마다 같은 필터값에 다른 명칭을 쓰는 기능은 제공하지 않습니다.
- 상세값을 가나다순 등으로 자동 정렬하는 기능은 제공하지 않습니다.
- 여러 상세값을 한 번에 고치는 기능, 수정 이력 화면은 제공하지 않습니다.
- 필터 추가, 노출 여부, 필터 행 이동, 필터 삭제, 노출 분류 선택, 하단 [저장], 일괄 관리 상품 검색은 지금과 같습니다.
- 쇼핑몰 분류 검색 필터는 명칭만 바뀌어 보이고 화면 구성은 바뀌지 않습니다.
- 모바일 관리자에는 검색 필터 설정 화면이 없어 해당하지 않습니다.

### 이용 조건

- 검색 필터 설정·검색 필터 일괄 관리 메뉴에 접근할 수 있는 관리자 권한이 있어야 합니다. 권한 기준은 바꾸지 않습니다.
- 운영자가 따로 설정할 것은 없습니다.

## 4. 상세 정책

### 4.1 검색 필터 설정 표에서 상세값 고치기

검색 필터 설정 화면의 분류 검색 필터 표에서 상세값 칩의 명칭을 고치는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 수정 진입 | 칩에 마우스를 올리거나 포커스하면 수정 아이콘이 나옵니다. 수정 아이콘을 누르면 칩이 입력창(현재 명칭이 들어 있음)과 확인·취소 아이콘으로 바뀝니다. |
| 한 번에 하나만 | 한 번에 한 칩만 고칠 수 있습니다. 다른 칩의 수정 아이콘을 누르면 고치던 칩은 저장하지 않고 원래 값으로 돌아갑니다. |
| 저장 시도 | Enter를 누르거나 확인 아이콘을 누릅니다. 4.4 입력 검증을 먼저 하고, 통과하면 확인 안내를 띄웁니다. |
| 확인 안내 | '필터 상세값을 수정하면 해당 필터를 사용하는 모든 상품에 변경 내용이 반영됩니다. 계속 진행하시겠습니까?' |
| 확인 | 그 상세값만 바로 저장합니다. 하단 [저장]을 누르지 않아도 됩니다. |
| 확인 안내에서 취소 | 저장하지 않고 입력한 값 그대로 편집 상태를 유지합니다. |
| 편집 취소 | 취소 아이콘을 누르거나 편집 영역 밖을 누르면 원래 값으로 돌아가고 저장하지 않습니다. |
| 저장 실패 | 이전 명칭을 그대로 둡니다. |

관련 정책: POL-001, POL-002, POL-003, POL-004, POL-008, POL-009

### 4.2 고친 명칭이 반영되는 범위

상세값 명칭을 고쳤을 때 어디까지 바뀌는지에 대한 기준입니다. 검색 필터 설정 표, 관리 팝업, 일괄 변경의 필터값명 수정에 모두 같게 적용합니다.

| 구분 | 정책 |
| --- | --- |
| 바뀌는 것 | 상세값의 명칭만 바뀝니다. |
| 바뀌지 않는 것 | 상세값과 상품의 연결은 그대로입니다. 상품에 다시 적용할 필요가 없습니다. |
| 반영 위치 | 그 값을 쓰는 모든 상품, 관리자 화면(검색 필터 일괄 관리의 필터 적용 현황 등), 쇼핑몰 분류 검색 필터 |
| 색상 코드 연동 필터 | 색상 코드는 바뀌지 않고 명칭만 바뀝니다. |
| 화면 표시 | 입력한 명칭은 관리자 화면과 쇼핑몰에 글자 그대로 표시합니다. 태그 같은 문자를 넣어도 서식이나 스크립트로 동작하지 않습니다. |

관련 정책: POL-010, POL-011

### 4.3 상세값 순서 이동

상세값 순서를 바꾸는 기능과 고치기 기능이 서로 부딪히지 않게 하는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 이동 아이콘 | 검색 필터 설정 표의 칩 왼쪽에 이동 아이콘을 표시합니다. |
| 순서 바꾸기 | 칩을 끌어다 놓아 바꿉니다. 지금과 같습니다. |
| 순서 저장 | 하단 [저장]을 눌러야 저장됩니다. 지금과 같습니다. |
| 고치는 중인 칩 | 끌어서 옮길 수 없습니다. 고치기가 끝나면 다시 옮길 수 있습니다. 다른 칩은 옮길 수 있습니다. |
| 수정 아이콘 | 누르거나 누른 채 끌어도 칩이 옮겨지지 않습니다. |
| 입력창 안 | 글자를 끌어서 선택할 수 있고, 칩이 옮겨지지 않습니다. |
| 툴팁 | 표 머리글 '필터 상세값' 옆 ? 아이콘: '필터 상세값에 마우스를 올린 후 수정 아이콘을 클릭하면 명칭을 수정할 수 있으며, 값을 드래그하여 순서를 변경할 수 있습니다.' |

관련 정책: POL-012, POL-013, POL-014

### 4.4 입력 검증

상세값 명칭을 저장하기 전에 확인하는 기준입니다. 모든 화면에 같게 적용합니다.

| 순서 | 검사 | 결과 |
| --- | --- | --- |
| 1 | 비어 있거나 공백만 있음 | 알림 '필터 상세값을 입력해주세요.'를 띄우고 편집 상태를 유지합니다. |
| 2 | 30자를 넘음 | 입력창에 30자까지만 들어갑니다. 따로 알림은 없습니다. |
| 3 | 같은 필터의 다른 상세값과 같음 | 알림 '중복된 필터 상세값이 있습니다. 다시 입력해주세요.'를 띄우고 편집 상태를 유지합니다. |

- 중복은 같은 필터 안에서만 봅니다. 다른 필터에 같은 명칭이 있어도 됩니다.
- 생성·관리 팝업에서는 팝업에 있는 상세값끼리 비교합니다.
- EUC-KR 상점과 UTF-8 상점 모두 한글 30자를 입력하고 저장할 수 있습니다.

관련 정책: POL-005, POL-006, POL-007, POL-026

### 4.5 생성·관리 팝업에서 상세값 고치기

[필터추가+]로 여는 생성 팝업과 [관리]로 여는 관리 팝업의 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 고치는 방법 | 4.1과 같습니다. 칩의 수정 아이콘 → 입력 → Enter 또는 확인 아이콘 → 4.4 검증 → 확인 안내 |
| 확인 안내 | 칩마다 4.1과 같은 확인 안내를 띄웁니다. 확인하면 팝업 안 칩만 바뀌고 아직 저장되지 않습니다. |
| 최종 저장 | 팝업에서 바꾼 필터명, 노출 여부, 상세값(추가·수정·삭제), 노출 분류는 팝업 하단 [등록](생성 팝업) 또는 [수정](관리 팝업)을 눌러야 한 번에 저장됩니다. |
| 저장하지 않음 | 팝업을 닫거나 [취소]하면 아무것도 저장하지 않습니다. |
| 상세값 추가 | 입력창에 값을 넣고 Enter를 누르면 칩으로 추가되고 입력창이 비워집니다. 같은 값은 추가되지 않습니다. |
| 생성 팝업 칩 삭제 | 칩의 X를 누르면 확인 없이 바로 지워집니다(아직 등록 전이기 때문). |
| 생성 팝업 [등록] | 필터명, 노출 여부, 상세값 1개 이상, 노출 분류 설정이 모두 있어야 누를 수 있습니다. |
| 관리 팝업 [수정] 후 | 바뀐 상세값 명칭은 4.2 범위로 반영됩니다. |

관련 정책: POL-015, POL-016, POL-017, POL-018, POL-019, POL-020, POL-021

### 4.6 검색 필터 일괄 변경 작업 유형

검색 필터 일괄 관리에서 상품을 고르고 [일괄변경]을 눌러 여는 팝업의 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 항목명 | '변경방식 설정'을 '작업 유형'으로 바꿉니다. |
| 작업 유형 순서 | 상품 적용값 변경, 필터값명 수정, 필터값 추가, 필터값 적용 해제. 처음에는 상품 적용값 변경이 선택돼 있습니다. |
| 이름 변경 | 변경 → 상품 적용값 변경, 추가 → 필터값 추가, 삭제 → 필터값 적용 해제. 필터값명 수정은 새로 추가합니다. |
| 입력 행 | 고른 작업 유형의 입력 행만 보입니다. |

| 작업 유형 | 입력 행 | 처리 | 대상 상품 | 수정일시 변경 체크박스 |
| --- | --- | --- | --- | --- |
| 상품 적용값 변경 | 기존 필터값, 변경할 필터값 | 기존 필터값이 적용된 상품만 변경할 필터값으로 바꿉니다(지금의 '변경'과 같음). | 선택한 상품 | 표시 |
| 필터값명 수정 | 수정할 필터값, 변경할 명칭(30자) | 해당 필터값의 명칭을 바꿉니다. 4.4 검증을 적용하고 4.2 범위로 반영합니다. | 선택과 관계없이 그 값을 쓰는 모든 상품 | 표시하지 않음 |
| 필터값 추가 | 추가할 필터값 | 필터값을 적용합니다(지금의 '추가'와 같음). | 선택한 상품 | 표시 |
| 필터값 적용 해제 | 적용 해제할 필터값 | 필터값 적용만 해제합니다. 필터값 자체는 지우지 않습니다(지금의 '삭제'와 같음). | 선택한 상품 | 표시 |

입력 행 옆 ? 아이콘의 툴팁입니다. N은 선택한 상품 수입니다.

| 작업 유형 | 툴팁 |
| --- | --- |
| 상품 적용값 변경 | 선택한 상품 N개의 분류 검색 필터를 변경합니다. |
| 필터값명 수정 | 필터값명 수정은 해당 값을 사용하는 모든 상품과 쇼핑몰 검색 필터에 반영됩니다. / 선택한 상품과 관계없이 해당 필터값을 사용하는 전체 상품에 반영됩니다. |
| 필터값 추가 | 선택한 상품 N개의 분류 검색 필터를 변경합니다. |
| 필터값 적용 해제 | 선택한 상품에서 필터값 적용만 해제됩니다. 필터값 자체는 삭제되지 않습니다. / 선택한 상품 N개의 분류 검색 필터를 변경합니다. |

관련 정책: POL-022, POL-023, POL-024, POL-025, POL-026, POL-027, POL-028, POL-029

### 4.7 처리 흐름

| 순서 | 운영자 | 시스템 |
| --- | --- | --- |
| 1 | 검색 필터 설정 표에서 칩에 마우스를 올리고 수정 아이콘을 누릅니다. | 칩을 입력창으로 바꾸고 그 칩은 끌어서 옮길 수 없게 합니다. |
| 2 | 새 명칭을 넣고 Enter를 누릅니다. | 빈 값·중복을 확인하고 확인 안내를 띄웁니다. |
| 3 | [확인]을 누릅니다. | 바로 저장하고, 그 값을 쓰는 모든 상품과 쇼핑몰 필터에 새 명칭을 보여 줍니다. |
| 4 | (일괄 변경) 상품을 고르고 '필터값명 수정'으로 명칭을 넣어 [저장]합니다. | 같은 검증을 하고, 선택과 관계없이 모든 상품에 반영합니다. |

### 4.8 오류 및 예외 처리

| 상황 | 처리 |
| --- | --- |
| 빈 값·공백만 입력 | 알림 '필터 상세값을 입력해주세요.' 후 편집 상태 유지 |
| 같은 필터의 중복값 | 알림 '중복된 필터 상세값이 있습니다. 다시 입력해주세요.' 후 편집 상태 유지 |
| 31자 이상 입력 | 30자까지만 입력됩니다. |
| 다른 칩을 고치려 함 | 고치던 칩은 원래 값으로 돌아갑니다. |
| 확인 안내에서 취소 | 저장하지 않고 편집 상태 유지 |
| 팝업을 닫음 | 팝업에서 바꾼 내용은 저장하지 않습니다. |
| 저장 실패 | 이전 명칭 유지 |

관련 정책: POL-002, POL-004, POL-005, POL-006, POL-007, POL-008, POL-017

## 5. 고객 영향 및 안내

### 고객이 반드시 알아야 할 내용

- 검색 필터 설정 표에서 상세값 명칭을 고치면 하단 [저장]을 누르지 않아도 바로 저장되고, 그 값을 쓰는 모든 상품과 쇼핑몰에 바로 반영됩니다.
- 상세값 순서 변경은 지금처럼 하단 [저장]을 눌러야 저장됩니다.
- 일괄 변경의 '필터값명 수정'은 선택한 상품만이 아니라 그 값을 쓰는 모든 상품에 반영됩니다.
- '필터값 적용 해제'는 선택한 상품에서만 빼고 필터값 자체는 지우지 않습니다.

### 고객 영향

| 대상 | 영향 |
| --- | --- |
| 쇼핑몰 운영자 | 상세값 명칭을 한 번에 고칠 수 있습니다. 일괄 변경 작업 이름이 바뀝니다. |
| 구매자 | 쇼핑몰 분류 검색 필터에 바뀐 명칭이 보입니다. 화면 구성은 같습니다. |
| 저장 데이터 | 상세값 명칭만 바뀌고 상품과 필터의 연결은 그대로입니다. |

### 안내 방식

- 업그레이드 노트로 안내합니다. 작업 유형 이름은 화면과 같게('필터값명 수정', '필터값 적용 해제') 씁니다.
- 화면에서는 '필터 상세값' 툴팁과 일괄 변경 툴팁으로 안내합니다.

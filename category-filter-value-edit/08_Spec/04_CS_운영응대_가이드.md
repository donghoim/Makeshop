# [CS 운영·응대 가이드] 원본 요청 분류 검색 필터 상세값 수정

상점 운영자 문의에 응대하기 위한 가이드입니다. 판단 기준은 사양 정의서 14장 정책 원장(POL)이며, 이 문서는 새로운 조건을 만들지 않습니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
|---|---|
| 변경 목적 | 분류 검색 필터 상세값의 명칭을 화면에서 바로 고치고, 일괄 변경 작업을 이름만 보고 구분할 수 있게 합니다. |
| 적용 대상 | 분류 검색 필터를 쓰는 상점(주문 2.0·통합옵션 버전)의 검색 필터 설정, 검색 필터 일괄 관리 |
| 적용 시점 | 11월 정기 배포(사이트 오픈 예정일 2026-11-10) |
| 고객 영향 | 상세값 명칭을 고치면 그 값을 쓰는 모든 상품과 쇼핑몰 검색 필터에 바로 반영됩니다. 일괄 변경의 작업 이름이 바뀝니다. |
| 상담 핵심 포인트 | 검색 필터 설정 표에서 고친 명칭은 하단 [저장] 없이 바로 쇼핑몰에 반영됩니다. 순서 변경은 지금처럼 [저장]을 눌러야 합니다. |

## 2. 필수 정책·고지 및 상담 범위

| CON·POL ID | 적용 대상 | 고객에게 안내할 내용 | 필수 확인·고지 시점 | 상담원이 판단하면 안 되는 내용 | 이관 부서 |
|---|---|---|---|---|---|
| POL-009, POL-010 | 검색 필터 설정 표 | 명칭을 고치고 확인하면 바로 저장되고, 그 값을 쓰는 모든 상품과 쇼핑몰에 반영됩니다. | 사용법·반영 문의 시 | 특정 상품만 다른 명칭으로 바꿀 수 있다고 안내 | 해당 없음 |
| POL-012 | 상세값 순서 | 순서는 끌어서 바꾼 뒤 하단 [저장]을 눌러야 저장됩니다. | 순서가 저장되지 않는다는 문의 시 | 없음 | 해당 없음 |
| POL-017 | 생성·관리 팝업 | 팝업에서 고친 값은 팝업 하단 [등록]·[수정]을 눌러야 저장됩니다. | 팝업에서 고친 값이 사라졌다는 문의 시 | 없음 | 해당 없음 |
| POL-025 | 일괄 변경 > 필터값명 수정 | 선택한 상품과 관계없이 그 값을 쓰는 모든 상품에 반영됩니다. | 선택하지 않은 상품도 바뀌었다는 문의 시 | 선택한 상품만 바꾸도록 되돌릴 수 있다고 안내 | 해당 없음 |
| POL-028 | 일괄 변경 > 필터값 적용 해제 | 선택한 상품에서만 빠지고 필터값 자체는 남습니다. | 필터값이 안 지워진다는 문의 시 | 없음 | 해당 없음 |

## 3. 고객이 경험하는 변화

| 상황 | 변경 전 | 변경 후 | 고객이 해야 할 일 | 관련 POL |
|---|---|---|---|---|
| 상세값 명칭을 바꾸려 함 | 지우고 다시 만든 뒤 상품마다 다시 적용 | 칩의 수정 아이콘으로 바로 고침 | 없음 | POL-001, POL-009 |
| 상세값 순서를 바꾸려 함 | 끌어서 바꿀 수 있지만 표시가 없음 | 칩 왼쪽에 이동 아이콘 표시 | 없음 | POL-012 |
| 필터 관리 팝업 | 상세값 추가·삭제만 됨 | 명칭도 고칠 수 있음 | 하단 [수정] 클릭 | POL-015, POL-017 |
| 일괄 변경 팝업 | 변경방식 설정: 변경·추가·삭제 | 작업 유형: 상품 적용값 변경·필터값명 수정·필터값 추가·필터값 적용 해제 | 없음 | POL-022 |

## 4. 문의 유형별 응대 가이드

| 문의 유형·증상 | 먼저 확인할 정보 | 확인 경로 | 처리 절차 | 고객 안내 문구 | 관련 POL |
|---|---|---|---|---|---|
| 상세값 이름을 어떻게 바꾸나요 | 사용 화면 | 검색 필터 설정 | 칩에 마우스 → 수정 아이콘 → 입력 → Enter → 확인 안내 [확인] 순서 안내 | "검색 필터 설정 화면에서 바꾸실 값에 마우스를 올리시면 연필 모양 아이콘이 나옵니다. 누르신 뒤 새 이름을 입력하고 Enter를 누르시면 됩니다." | POL-001, POL-003 |
| 이름을 바꿨는데 [저장]을 안 눌렀어요 | 확인 안내에서 [확인]을 눌렀는지 | 검색 필터 설정 화면 새로 고침 | 새로 고친 뒤 바뀐 이름인지 확인 | "확인 안내에서 [확인]을 누르셨다면 이미 저장됐습니다. 하단 [저장]은 순서를 바꾸셨을 때만 누르시면 됩니다." | POL-009, POL-012 |
| 한 상품만 이름을 바꾸고 싶어요 | 바꾸려는 상품·값 | 검색 필터 일괄 관리 | 상품별 다른 이름은 지원하지 않음 안내, 다른 값을 만들어 '상품 적용값 변경'으로 바꾸도록 안내 | "같은 값의 이름은 모든 상품에 똑같이 적용됩니다. 그 상품만 다르게 하시려면 새 값을 만들고, 일괄 변경의 '상품 적용값 변경'으로 그 상품의 값을 바꿔 주세요." | POL-010, POL-024 |
| 이름이 저장되지 않아요(중복 안내) | 같은 필터에 같은 이름이 있는지 | 검색 필터 설정 표 | 같은 필터 안 중복 확인 | "같은 필터 안에 이미 같은 이름의 값이 있어 저장되지 않았습니다. 다른 이름으로 입력해 주세요." | POL-007 |
| 이름이 30자에서 더 안 써져요 | 입력 길이 | 검색 필터 설정 | 30자 제한 안내 | "상세값 이름은 30자까지 입력할 수 있습니다." | POL-006 |
| 팝업에서 고쳤는데 반영이 안 됐어요 | 팝업 하단 [수정]·[등록]을 눌렀는지 | 관리 팝업 | 팝업을 다시 열어 고친 뒤 [수정] 클릭 안내 | "팝업에서 고치신 내용은 팝업 아래 [수정] 버튼을 누르셔야 저장됩니다. 다시 고치신 뒤 [수정]을 눌러 주세요." | POL-017 |
| 선택하지 않은 상품도 이름이 바뀌었어요 | 사용한 작업 유형 | 일괄 변경 | '필터값명 수정' 사용 여부 확인 | "'필터값명 수정'은 선택하신 상품과 관계없이 그 값을 쓰는 모든 상품의 이름을 바꿉니다. 일부 상품만 바꾸시려면 '상품 적용값 변경'을 써 주세요." | POL-025 |
| '필터값 적용 해제'를 했는데 값이 그대로 있어요 | 검색 필터 설정 표의 값 | 검색 필터 설정 | 적용 해제와 값 삭제 차이 안내 | "'필터값 적용 해제'는 선택하신 상품에서만 값을 뺍니다. 값 자체를 지우시려면 검색 필터 설정의 [관리]에서 지워 주세요." | POL-028 |
| 색상 필터 이름을 바꿨는데 색이 그대로예요 | 색상 코드 연동 사용 여부 | 검색 필터 설정 | 정상 동작 안내 | "이름만 바뀌고 연결된 색상은 그대로 유지됩니다." | POL-011 |
| 바꾼 이름이 쇼핑몰에 안 보여요 | 상점 ID, 필터·값, 상품번호, 쇼핑몰 화면 | 관리자 검색 필터 설정, 쇼핑몰 분류 화면 | 관리자 표에 새 이름이 있는데 쇼핑몰이 다르면 이관 | "확인을 위해 담당 부서에 전달하겠습니다. 확인되는 대로 안내드리겠습니다." | POL-010 |

## 6. 상담 체크리스트

- 어느 화면에서 고쳤는지 확인합니다(검색 필터 설정 표, 관리 팝업, 일괄 변경).
- 검색 필터 설정 표라면 확인 안내에서 [확인]을 눌렀는지, 팝업이라면 하단 [수정]·[등록]을 눌렀는지 확인합니다.
- 일괄 변경이라면 어떤 작업 유형을 썼는지 확인합니다.

## 9. FAQ

| 질문 | 답변 |
|---|---|
| 이름을 바꾸면 상품에 다시 적용해야 하나요? | 아닙니다. 상품 연결은 그대로이고 이름만 바뀝니다. |
| 여러 값을 한 번에 바꿀 수 있나요? | 한 번에 한 값씩 고칩니다. |
| 이름은 몇 자까지 되나요? | 30자까지입니다. |
| 다른 필터에 같은 이름을 써도 되나요? | 됩니다. 같은 필터 안에서만 겹치면 안 됩니다. |
| 바꾼 이름을 예전 이름으로 되돌릴 수 있나요? | 같은 방법으로 예전 이름을 다시 입력하시면 됩니다. |

## 10. 공지·운영 준비

- 업그레이드 노트로 안내합니다. 작업 유형 이름은 화면과 같게 '상품 적용값 변경', '필터값명 수정', '필터값 추가', '필터값 적용 해제'로 씁니다.
- 유의사항: 검색 필터 설정 표에서 고친 이름은 저장 버튼 없이 바로 반영되므로 고칠 때 주의하도록 안내합니다.

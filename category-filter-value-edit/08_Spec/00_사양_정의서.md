## 2. 배경과 문제

| 항목 | 내용 |
|---|---|
| 배경 | 타사에서 이전하는 상점(운영 상점)은 4단계 분류를 쓰지만 메이크샵은 3단계 분류입니다. 부족한 세부 분류를 분류 검색 필터로 대신하기로 했고, 상품군이 늘면서 필터 상세값의 단어를 바꿔야 하는 일이 생겼습니다. |
| 해결할 문제 | ① 등록된 필터 상세값의 명칭을 바꾸는 기능이 없어, 오타 하나를 고치려 해도 값을 지우고 다시 만든 뒤 상품마다 다시 적용해야 합니다. ② 상세값 순서는 드래그로 바꿀 수 있지만 화면에 드래그할 수 있다는 표시가 없어 운영자가 기능을 찾지 못합니다. ③ 검색 필터 일괄 변경의 '변경·추가·삭제'가 상품에 적용된 값을 바꾸는 것인지 필터값 자체를 바꾸는 것인지 구분되지 않습니다. 특히 '삭제'는 필터값이 지워지는 것처럼 보입니다. |
| 사용자·운영 영향 | 명칭을 바꾸려면 상품 수만큼 일괄 변경을 반복해야 하고, 재등록 과정에서 상품의 필터 적용이 빠질 수 있습니다. 타사 이전 상점은 이 작업이 막혀 이전을 망설입니다(이탈 위험). |

## 3. 목표와 범위

### 3.1 목표

- 운영자가 필터 상세값 명칭을 화면에서 바로 고치고, 그 값을 쓰는 모든 상품과 쇼핑몰 검색 필터에 한 번에 반영합니다.
- 상세값 순서를 바꿀 수 있다는 것을 이동 아이콘과 툴팁으로 알립니다.
- 일괄 변경 작업 유형 이름만 보고 무엇이 바뀌는지 알 수 있게 합니다.

### 3.2 포함 범위

- 검색 필터 설정 > 분류 검색 필터 표: 필터 상세값 칩 명칭 수정(즉시 저장), 상세값 이동 아이콘, '필터 상세값' 툴팁
- 분류 검색 필터 생성·관리 팝업: 필터 상세값 칩 명칭 수정(하단 버튼으로 최종 저장)
- 상품 분류 검색 필터 일괄 변경 팝업: 항목명 '변경방식 설정' → '작업 유형', 작업 유형 3개 → 4개(필터값명 수정 추가), 기존 3개 명칭 변경, 작업 유형별 툴팁

### 3.3 제외 범위

- 상품마다 같은 필터값에 다른 명칭을 쓰는 기능(요청자 확인: 검색·일괄 변경으로 처리)
- 상세값 가나다순·숫자순 자동 정렬(요청 철회)
- 여러 상세값을 한 번에 수정하는 기능, 상세값 수정 이력 화면
- 여러 관리자가 같은 필터를 동시에 고칠 때의 충돌 안내
- 필터 추가·노출 여부·필터 삭제·노출 분류 선택·하단 [저장]의 현행 동작 변경
- 쇼핑몰 분류 검색 필터의 화면 구성 변경(명칭만 바뀌어 보임)
- 모바일 관리자(해당 화면 없음)

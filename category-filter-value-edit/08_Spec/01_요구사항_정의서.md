# [요구사항 정의서] 원본 요청 분류 검색 필터 상세값 수정

## 1. 문서 목적

분류 검색 필터의 상세값 명칭을 고쳐야 하는 이유와, 무엇을 만족해야 하는지 정리합니다. 상세 정책은 정책서, 기능·수용 조건은 사양 정의서에서 관리합니다.

## 2. 요청 배경 및 목표

### 2.1. 요청 배경

- 운영 상점은 다른 쇼핑몰 솔루션에서 메이크샵으로 옮기는 중입니다. 이전 솔루션은 상품 분류가 4단계인데 메이크샵은 3단계라서, 부족한 세부 분류를 분류 검색 필터로 대신하기로 했습니다.
- 문구는 세부 분류가 중요한 상품군이고, 상품군이 늘면서 필터 상세값의 단어(예: 노랑 → Yellow)를 바꿔야 하는 일이 생겼습니다.
- 지금은 상세값 명칭을 바꾸는 기능이 없어 값을 지우고 다시 만든 뒤 상품마다 다시 적용해야 합니다. 요청자는 명칭을 바꾸면 그 값이 적용된 모든 상품에 한 번에 반영되기를 원했습니다(원본 요청 댓글, 2026-06-10).

### 2.2. 운영자가 필요한 결과

- 검색 필터 설정 화면과 필터 관리 팝업에서 상세값 명칭을 바로 고칠 수 있어야 합니다.
- 고친 명칭이 그 값을 쓰는 모든 상품과 쇼핑몰 검색 필터에 반영되어야 합니다.
- 상세값 순서를 바꿀 수 있다는 것과 일괄 변경의 작업 종류를 화면에서 쉽게 알 수 있어야 합니다.

## 3. 현행 기능 및 해결 과제

### 3.1. 현행 동작

| 기능 | 현행 동작 |
|---|---|
| 검색 필터 설정 표 | 필터별 상세값이 칩으로 나옵니다. 칩을 드래그해 순서를 바꾸고 하단 [저장]으로 저장할 수 있지만, 드래그할 수 있다는 표시가 없습니다. 명칭은 고칠 수 없습니다. |
| 필터 생성·관리 팝업 | 상세값을 입력 후 Enter로 추가하고 X로 지울 수 있습니다. 명칭은 고칠 수 없습니다. |
| 검색 필터 일괄 변경 팝업 | '변경방식 설정'에 변경·추가·삭제 3가지가 있습니다. 모두 선택한 상품에 적용된 값을 바꾸는 작업이지만, 이름만 보면 필터값 자체를 바꾸거나 지우는 것처럼 보입니다. |

### 3.2. 문제 예시

| 순서 | 운영자 작업 | 현행 결과 | 영향 |
|---|---|---|---|
| 1 | 색상 필터의 '노랑'을 'Yellow'로 바꾸려 함 | 고치는 기능이 없음 | 값을 새로 만들어야 함 |
| 2 | 'Yellow'를 추가하고 '노랑' 상품을 찾아 일괄 변경 | 상품이 많으면 여러 번 반복 | 작업 시간 증가, 누락 위험 |
| 3 | '노랑'을 지움 | 일부 상품에 필터가 빠질 수 있음 | 쇼핑몰 검색 필터에서 상품이 안 보임 |

## 4. 요구사항

| REQ ID | 요구사항 | 필수 여부 |
|---|---|---|
| REQ-001 | 등록된 필터 상세값의 명칭을 바꾸고, 그 값이 적용된 모든 상품과 쇼핑몰에 한 번에 반영할 수 있어야 합니다. | 필수 |
| REQ-002 | 필터를 만들거나 관리하는 팝업에서도 상세값 명칭을 고칠 수 있어야 합니다. | 필수 |
| REQ-003 | 상세값 순서를 바꿀 수 있다는 것을 화면에서 알 수 있어야 합니다. | 필수 |
| REQ-004 | 일괄 변경에서 상품에 적용된 값을 바꾸는 작업과 필터값 이름을 바꾸는 작업을 구분할 수 있어야 합니다. | 필수 |

## 5. 대표 사용자 시나리오

| 시나리오 | 기대 결과 |
|---|---|
| 운영자가 검색 필터 설정 표에서 '노랑' 칩의 수정 아이콘을 눌러 'Yellow'로 바꾸고 확인 | 하단 [저장] 없이 바로 저장되고, '노랑'이 적용됐던 상품과 쇼핑몰 필터에 'Yellow'가 나옵니다. |
| 운영자가 같은 필터에 이미 있는 '빨강'으로 바꾸려 함 | 중복 안내가 나오고 저장되지 않습니다. |
| 운영자가 필터 관리 팝업에서 상세값 두 개를 고치고 팝업 하단 [수정]을 누름 | 두 값이 한 번에 저장됩니다. [수정]을 누르지 않고 닫으면 저장되지 않습니다. |
| 운영자가 일괄 관리에서 상품 1개만 선택하고 '필터값명 수정'으로 '노랑'을 바꿈 | 선택하지 않은 상품까지 '노랑'을 쓰는 모든 상품의 명칭이 바뀝니다. |
| 운영자가 '필터값 적용 해제'로 선택 상품의 '노랑'을 해제 | 선택한 상품에서만 빠지고 '노랑' 값은 필터에 남습니다. |

## 6. 범위

| 구분 | 내용 |
|---|---|
| 포함 | 검색 필터 설정 표 상세값 명칭 수정(즉시 저장)·이동 아이콘·툴팁, 생성·관리 팝업 상세값 명칭 수정, 일괄 변경 팝업 작업 유형 4종과 툴팁 |
| 제외 | 상품별 다른 명칭, 자동 정렬(가나다순 등), 여러 값 한 번에 수정, 수정 이력 화면, 동시 수정 충돌 안내, 필터 추가·노출·삭제 등 현행 기능 변경, 모바일 관리자 |

## 7. 완료 기준

- 검색 필터 설정 표에서 '노랑'을 'Yellow'로 고치면 하단 [저장] 없이 저장되고 해당 상품과 쇼핑몰 필터에 'Yellow'가 나옵니다.
- 빈 값, 31자 이상, 같은 필터의 중복값으로는 저장되지 않습니다.
- 필터 관리 팝업에서 고친 값은 [수정]을 눌러야 저장됩니다.
- 일괄 변경 팝업에 작업 유형 4가지가 나오고, '필터값명 수정'은 선택 상품과 관계없이 모든 상품에 반영됩니다.

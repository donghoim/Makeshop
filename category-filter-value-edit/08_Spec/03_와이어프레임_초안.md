## 2. 화면별 구조

### WF-001 검색 필터 설정 > 분류 검색 필터 표

- 목적: 상세값 명칭을 표에서 바로 고치고, 상세값 순서를 바꿀 수 있다는 것을 알립니다.
- 진입점·이전 화면: 좌측 메뉴 부가서비스 > 상품 > 검색 필터 설정
- 완료 후 이동: 같은 화면, [필터추가+] → WF-002, [관리] → WF-003
- 관련 요구사항·정책: REQ-001, REQ-003, FR-001부터 FR-004, POL-001부터 POL-014

**기본 화면**

![기본 화면](../03_Wireframe/wf-1-1.png)

- 모든 칩 왼쪽에 이동 아이콘을 표시하고, 색상 코드 연동 필터는 색상을 함께 표시합니다.
- 머리글 '필터 상세값' 옆에 툴팁 ? 아이콘을 추가합니다.

**마우스 오버**

![마우스 오버](../03_Wireframe/wf-1-2.png)

- 칩에 마우스를 올리면 명칭 오른쪽에 수정 아이콘이 나옵니다.

**편집 모드**

![편집 모드](../03_Wireframe/wf-1-3.png)

- 칩이 입력창과 확인·취소 아이콘으로 바뀝니다. 편집 중인 칩은 끌어서 옮길 수 없습니다.

**수정 확인 안내**

![수정 확인 안내](../03_Wireframe/wf-1-4.png)

- Enter·확인 아이콘 → 검증 → 확인 안내 → [확인]하면 하단 [저장] 없이 바로 저장됩니다.

**순서 이동**

![순서 이동](../03_Wireframe/wf-1-8.png)

- 같은 필터 행 안에서 끌어다 놓습니다. 순서는 하단 [저장]을 눌러야 저장됩니다(현행).

### WF-002 분류 검색 필터 생성 팝업

- 목적: 필터를 만들면서 입력한 상세값을 고칩니다.
- 진입점·이전 화면: WF-001 [필터추가+]
- 완료 후 이동: [등록] → WF-001(필터 추가), [취소]·닫기 → WF-001(저장 안 함)
- 관련 요구사항·정책: REQ-002, FR-005, POL-015부터 POL-020

![생성 팝업 상세값 편집](../03_Wireframe/wf-2-1.png)

- 칩 편집 방법·검증·확인 안내는 WF-001과 같고, 확인하면 팝업 안 칩만 바뀝니다. [등록]을 눌러야 저장됩니다.
- 팝업 칩에는 이동 아이콘·색상이 없고, X로 바로 지울 수 있습니다.

### WF-003 분류 검색 필터 관리 팝업

- 목적: 등록된 필터의 상세값 명칭을 다른 설정과 함께 고칩니다.
- 진입점·이전 화면: WF-001 [관리]
- 완료 후 이동: [수정] → WF-001(한 번에 저장), 닫기 → WF-001(저장 안 함)
- 관련 요구사항·정책: REQ-002, FR-005, POL-015부터 POL-017, POL-021

![관리 팝업 상세값 편집](../03_Wireframe/wf-2-3.png)

- 팝업 제목·[삭제]·노출 분류 영역은 현행 그대로입니다.

### WF-004 상품 분류 검색 필터 일괄 변경 팝업

- 목적: 일괄 변경 작업을 4가지로 나눠, 상품에 적용된 값을 바꾸는 작업과 필터값 이름을 바꾸는 작업을 구분합니다.
- 진입점·이전 화면: 검색 필터 일괄 관리에서 상품 선택 후 [일괄변경]
- 완료 후 이동: [저장]·[취소] → 검색 필터 일괄 관리
- 관련 요구사항·정책: REQ-004, FR-006부터 FR-008, POL-022부터 POL-029

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 관리자 PC 화면만 해당합니다. 모바일 관리자에는 이 화면이 없습니다.
- 키보드·초점 순서: 칩에 포커스하면 수정 아이콘이 나오고, 입력창에서 Enter로 저장을 시도합니다.
- 오류와 필수값 전달 방식: 브라우저 기본 알림창으로 안내하고 편집 상태를 유지합니다.
- 긴 문구·다국어 대응: 명칭은 30자까지이며 칩은 글자 길이만큼 늘어나고 표 안에서 줄바꿈됩니다.
- 법적 고지·동의 노출: 해당 없음

## 8. 미결정 사항

화면 관련 미결정 사항은 사양 정의서 12장(OPEN-001, OPEN-002)에서 관리합니다. 목업은 수정 전과 같은 값으로 저장하면 저장 없이 편집을 끝내는 것으로 표현했습니다.

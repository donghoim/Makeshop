# 묶음상품 엑셀 업로드 등록/수정 개선

메이크샵 판매상품 엑셀 업로드에서 묶음상품도 등록·수정할 수 있도록 개선하는 기획 프로젝트입니다. 사양 정의서·요구사항 정의서·정책서·CS 운영 가이드·TC 사전 작성서까지 완료했고, 이 저장소에는 사내 정보(이슈 번호, 사내 문서 링크, 고객사명)를 뺀 공개본을 둡니다.

## 배경

묶음상품은 가격 변동이 잦지만 엑셀 일괄 등록·수정을 지원하지 않아, 운영자가 묶음상품 수정 화면에서 한 건씩 수기로 수정하고 있습니다. 현행 판매상품 엑셀 양식(66개 컬럼)에는 일반상품과 묶음상품을 구분하는 값도, 구성상품·묶음수량 컬럼도 없습니다.

## 해결 방향

별도 양식을 만들지 않고 **기존 판매상품 엑셀 양식 뒤에 묶음상품 전용 컬럼 2개를 추가**합니다.

| 컬럼 | 입력 형식 | 예시 |
|---|---|---|
| 묶음 구성상품 | 구성상품의 상품 고유번호를 콤마(,)로 구분 | `1001,1002,1003` |
| 묶음수량 | 구성상품별 수량을 같은 순서로 콤마(,)로 구분 | `1,2,1` |

## 핵심 정책

- 두 컬럼에 값이 있는 신규 행은 묶음상품으로 등록합니다. 묶음상품은 구성상품이 필수입니다.
- 수정 행은 기존 상품 유형을 따르고, 엑셀로 일반↔묶음 유형을 바꾸지 않습니다.
- 기존 엑셀이 전체 필드를 갱신하는 방식이므로 구성 정보도 매번 전체를 교체합니다(공란이면 오류).
- 묶음상품 필수값: 상품명·판매가격·상품진열여부·묶음 구성상품·묶음수량
- 묶음상품 행의 옵션·재고 수량·판매가능여부 컬럼은 오류 없이 무시합니다(판매가능여부는 구성상품 기준으로 산정).
- 구성상품 등록 조건은 묶음상품 등록 화면과 같습니다(공급자 상품, 하이브리드·DIY 옵션 상품, 정기배송 전용 상품 등은 등록 불가).
- 일부 행 오류 처리, 권한, 업로드 건수 제한, 이력은 기존 일반상품 엑셀 업로드와 같게 처리합니다.

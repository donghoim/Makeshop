# 묶음상품 엑셀 업로드 등록/수정 개선

메이크샵 판매상품 엑셀 업로드에서 묶음상품도 등록·수정할 수 있도록 개선하는 기획 프로젝트입니다. 현재 단계는 PRD 분석·문제 정의·해결 방향 검토이며, 정책서는 해결 방향이 확정된 뒤 추가합니다.

## 배경

묶음상품은 가격 변동이 잦지만 엑셀 일괄 등록·수정을 지원하지 않아, 운영자가 묶음상품 수정 화면에서 한 건씩 수기로 수정하고 있습니다. 묶음상품 비중이 커질수록 수정 공수와 가격 반영 누락 위험이 함께 커집니다.

## 문제 정의

현행 판매상품 엑셀 양식(66개 컬럼)을 분석한 결과, 묶음상품을 엑셀로 다룰 수 없는 이유는 공통 필드가 부족해서가 아닙니다.

| 원인 | 내용 |
|---|---|
| 상품 유형 판별 기준이 없습니다. | 양식에 일반상품과 묶음상품을 구분하는 값이 없습니다. 지금까지 엑셀은 일반상품만 다뤘습니다. |
| 묶음상품 전용 컬럼이 없습니다. | 묶음상품의 필수 정보인 구성상품·묶음수량을 담을 컬럼이 없습니다. |
| 공통 필드는 이미 있습니다. | 상품명·판매가격·소비자가격·구매원가·가격대체문구·적립금 등 수정 요청 항목 대부분이 기존 컬럼에 있습니다. |

## 해결 방향 [제안]

별도 양식을 만들지 않고 **기존 판매상품 엑셀 양식에 묶음상품 전용 컬럼 2개를 추가**합니다.

| 컬럼 | 입력 형식 | 예시 |
|---|---|---|
| 구성상품 상품번호 | 구성상품의 상품 고유번호를 콤마(,)로 구분 | `1001,1002,1003` |
| 묶음수량 | 구성상품별 수량을 같은 순서로 콤마(,)로 구분 | `1,2,1` |

- 신규 등록 행은 두 컬럼에 값이 있으면 묶음상품, 비어 있으면 일반상품으로 처리합니다.
- 묶음상품은 구성상품이 필수이므로 구성 정보 없이 묶음상품을 등록할 수 없습니다.
- 수정 행은 기존 상품의 유형을 따르고, 엑셀로 유형을 바꾸는 것(일반↔묶음)은 허용하지 않습니다.
- 수정 시 구성 컬럼이 비어 있으면 기존 구성을 유지하고, 값이 있으면 전체 교체합니다.

대안 비교, 검토 포인트(R-01~R-10), 처리 흐름은 [PRD 분석 · 문제 정의 · 해결 방향](./01_Requirements/PRD-분석-문제정의-해결방향.md) 문서에 정리했습니다.

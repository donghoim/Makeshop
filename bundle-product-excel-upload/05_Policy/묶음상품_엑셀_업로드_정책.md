# 묶음상품 엑셀 업로드 등록·수정 정책

판매상품 엑셀 업로드·다운로드에 "묶음 구성상품"과 "묶음수량" 컬럼을 추가해 묶음상품을 등록·수정·다운로드할 때 적용하는 정책입니다. 기존 컬럼의 처리 방식은 현행과 같으며, 이 문서는 추가되는 두 컬럼의 처리를 정의합니다.

| 항목 | 내용 |
|---|---|
| 대상 메뉴 | 판매상품 엑셀업로드, 상품 엑셀 다운로드(엑셀 양식관리) |
| 대상 상품 | 묶음상품(신규 등록·기존 상품 수정), 일반상품(두 컬럼 처리에 한함) |
| 적용 상점 | UTF-8 전체 상점 [확정] |
| 문서 상태 | 최종본 |

---

## 1. 배경

묶음상품은 가격 변동이 잦지만 엑셀 일괄 등록·수정을 지원하지 않아, 운영자가 묶음상품 수정 화면에서 한 건씩 수기로 수정하고 있습니다. 판매상품 엑셀 양식에는 묶음상품의 구성상품·묶음수량을 담을 컬럼이 없어서 묶음상품을 처리할 수 없습니다.

## 2. 목적

- 묶음상품을 엑셀 업로드로 대량 등록·수정할 수 있게 합니다.
- 기존 컬럼과 처리 방식은 그대로 사용하고, 묶음상품 전용 컬럼 2개만 추가합니다.

## 3. 적용 범위

이 정책이 다루는 기능과 다루지 않는 기능의 경계입니다.

| 구분 | 내용 | 상태 |
|---|---|---|
| 포함 | 묶음 구성상품·묶음수량 컬럼 추가와 입력 규칙 | [확정] |
| 포함 | 두 컬럼 입력 여부에 따른 묶음상품 신규 등록·수정 판정 | [확정] |
| 포함 | 묶음 구성상품·묶음수량 검증과 구성정보 저장 | [확정] |
| 포함 | 엑셀 양식관리 항목 추가와 다운로드 시 구성정보 출력 | [확정] |
| 제외 | 기존 66개 컬럼의 처리 방식 변경(현행 유지) | [확정] |
| 제외 | 묶음상품의 옵션 생성·수정. 묶음상품은 구성상품에 등록된 옵션을 사용합니다. | [확정] |
| 제외 | 구성상품의 옵션(품목) 단위 지정, 묶음상품 전용 시트, 구성상품별 행 입력 | [확정] |
| 제외 | 같은 파일에서 신규 등록하는 상품을 구성상품으로 지정하는 기능 | [확정] |
| 제외 | 관련상품·추가구성상품에 묶음상품을 설정·노출하는 기능의 개선 | [확정] |

## 4. 추가 컬럼 정책

판매상품 엑셀 양식에 묶음상품 전용 컬럼 2개를 추가하는 정책입니다.

- 기존 66개 컬럼의 순서와 필드 구조를 유지하고, 맨 뒤에 아래 2개 컬럼을 추가합니다. [확정]

| 항목 | 입력 대상 | 입력 형식 | 상태 |
|---|---|---|---|
| 묶음 구성상품 | 묶음상품 | 구성상품의 상품 고유번호를 콤마(`,`)로 구분해 입력합니다. 예) `101,102,103` | [확정] |
| 묶음수량 | 묶음상품 | 구성상품별 수량을 묶음 구성상품과 같은 순서로 콤마(`,`)로 구분해 입력합니다. 예) `2,1,1` | [확정] |

- 두 컬럼의 값은 입력 순서대로 1:1로 대응합니다. 묶음 구성상품의 N번째 상품번호의 수량은 묶음수량의 N번째 값입니다. [확정]
- 한 셀 안의 콤마 구분값 해석(앞뒤 공백 등)은 기존 엑셀의 콤마 구분 컬럼(옵션값 등)과 같습니다. [확정]
- 일반상품 행은 두 컬럼을 비워 둡니다. [확정]
- 판매상품 엑셀 업로드 예제 양식에 두 컬럼과 항목 설명(1행), 묶음상품 예시 행을 추가해 제공합니다. [확정]
- 두 컬럼의 영문 필드 키는 개발 판단 영역입니다.

## 5. 기존 컬럼 처리 정책

묶음상품 행에서 기존 66개 컬럼을 처리하는 정책입니다. 기존 컬럼은 현행과 같게 처리하며, 묶음상품에 해당하지 않는 항목만 아래와 같이 처리합니다.

| 항목 | 묶음상품 행 처리 | 근거 | 상태 |
|---|---|---|---|
| 옵션 관련 컬럼, 재고 수량, 판매가능여부 | 입력할 필요가 없고, 입력해도 반영하지 않습니다(오류 없이 무시). 옵션 관련 필수값 검증도 하지 않습니다. | 묶음상품 등록 시 제공되지 않는 항목이며, 묶음상품은 구성상품의 옵션·재고·상태를 따릅니다. | [확정] |
| 판매가격 | 엑셀에 입력한 판매가격은 묶음상품의 실제 판매가격으로 저장돼 판매에 반영돼야 합니다. | 엑셀 일괄 수정의 핵심 목적입니다. | [확정] |

- 일반상품 행의 기존 컬럼 처리와 검증은 현행과 같습니다. [확정]

## 6. 상품 유형 판정 정책

업로드한 각 행을 신규 등록·기존 상품 수정과 일반상품·묶음상품 중 어떤 처리로 볼지 판정하는 정책입니다. 판정은 행 단위로 합니다.

- 상품 고유번호가 공란이면 신규 등록, 입력돼 있으면 기존 상품 수정입니다. [확정]
- 신규 등록 행은 묶음 구성상품·묶음수량 입력 여부로 상품 유형을 정합니다. 묶음 구성상품에 상품번호가 입력돼 있으면 묶음상품으로 처리합니다. [확정]
- 기존 상품 수정 행은 해당 상품의 현재 상품 유형을 유지합니다. 엑셀로 일반상품↔묶음상품을 바꿀 수 없으며, 유형을 바꾸려면 새 상품으로 등록해야 합니다. [확정]

| 상품 고유번호 | 기존 상품 유형 | 묶음 구성상품 | 묶음수량 | 처리 결과 | 상태 |
|---|---|---|---|---|---|
| 공란 | — | 공란 | 공란 | 일반상품 신규 등록(현행 처리) | [확정] |
| 공란 | — | 입력 | 입력 | 묶음상품 신규 등록 | [확정] |
| 공란 | — | 둘 중 하나만 입력 | — | 오류 — 구성정보 일부 누락 | [확정] |
| 입력 | 일반상품 | 공란 | 공란 | 일반상품 수정(현행 처리) | [확정] |
| 입력 | 일반상품 | 둘 중 하나 이상 입력 | — | 오류 — 상품 유형 변경 불가 | [확정] |
| 입력 | 묶음상품 | 입력 | 입력 | 묶음상품 수정(구성정보 전체 교체) | [확정] |
| 입력 | 묶음상품 | 둘 중 하나 이상 공란 | — | 오류 — 필수값 누락 | [확정] |

- 기존 일반상품 수정 행에 묶음 구성상품·묶음수량 값이 있으면 무시하지 않고 오류로 처리합니다. 운영자가 묶음상품으로 바뀌었다고 오해하지 않도록 하기 위함입니다. [확정]
- 묶음상품 행에서 묶음 구성상품·묶음수량은 필수입니다. 업로드 파일에 두 컬럼이 없거나 공란이면 필수값 누락 오류입니다. [확정]

## 7. 묶음 구성상품 검증 정책

묶음 구성상품에 입력한 각 상품번호가 구성상품이 될 수 있는지 검증하는 정책입니다. 구성상품은 업로드 시점에 이미 등록돼 상품 고유번호가 있는 일반상품만 지정할 수 있습니다. 묶음상품 등록 화면과 같은 구성상품 등록 조건을 적용하며, 화면에 적용된 조건 외의 추가 제한은 두지 않습니다. [확정]

| 조건 | 결과 | 상태 |
|---|---|---|
| 같은 상점에 등록된 일반상품(아래 등록 불가 조건 해당 없음) | 정상 | [확정] |
| 옵션이 있는 일반상품 | 정상 — 해당 상품의 기존 옵션 구조를 그대로 사용 | [확정] |
| 같은 상품번호를 2번 이상 입력 | 정상 | [확정] |
| 존재하지 않는 상품번호, 다른 상점의 상품번호, 숫자가 아닌 값 | 오류 — 존재하지 않는 구성상품 | [확정] |
| 묶음상품의 상품번호 | 오류 — 묶음상품은 구성상품으로 지정 불가 | [확정] |
| 공급자 상품, 하이브리드·DIY 옵션 상품, 정기배송 전용 상품, 분류 미지정 상품 | 오류 — 구성상품 등록 불가 | [확정] |
| 구성상품 간 부가세 구분(부가세·면세·영세율) 불일치 | 오류 — 구성상품 등록 불가 | [확정] |
| 품절·미진열·판매불가 상태의 일반상품 | 묶음상품 등록 화면의 구성상품 선택 기준과 같음 | [확정] |
| 콤마 사이에 값이 없는 항목(예: `101,,102`, `101,102,`) | 오류 — 구성정보 값 누락 | [확정] |

## 8. 묶음수량·개수 검증 정책

묶음수량에 입력한 각 수량과 두 컬럼의 항목 개수를 검증하는 정책입니다.

| 조건 | 결과 | 상태 |
|---|---|---|
| 0 이상의 정수(0 포함, 모든 수량이 0인 경우 포함) | 정상 | [확정] |
| 음수, 소수, 숫자가 아닌 값 | 오류 — 묶음수량 형식 오류 | [확정] |
| 콤마 사이에 값이 없는 항목 | 오류 — 구성정보 값 누락 | [확정] |
| 묶음 구성상품 개수 ≠ 묶음수량 개수 | 오류 — 구성상품 상품번호와 묶음수량 개수 불일치 | [확정] |
| 구성상품 개수가 묶음상품 등록 화면의 최대 개수 초과 | 오류 — 구성상품 최대 개수 초과 | [확정] |

## 9. 구성정보 저장 정책

검증을 통과한 묶음상품 행의 구성정보(구성상품·묶음수량)를 저장하는 정책입니다.

- 신규 등록 행은 입력한 구성정보로 묶음상품을 구성합니다. [확정]
- 기존 묶음상품 수정 행은 기존 구성정보와 비교해 일부만 추가·수정·삭제하지 않고, 엑셀 입력값으로 구성정보 전체를 교체합니다. [확정]
- 구성정보를 바꾸지 않으려는 경우에도 기존 묶음 구성상품과 묶음수량을 다시 입력해야 합니다. [확정]
- 구성정보는 입력한 순서대로 저장하며, 같은 상품번호를 중복 입력해도 입력한 구성상품과 묶음수량의 대응 관계를 유지합니다. [확정]
- 검증에 실패하면 저장하지 않으며, 기존 묶음상품의 구성정보는 그대로 유지됩니다. [확정]

| 기존 구성정보 | 엑셀 입력값(묶음 구성상품 / 묶음수량) | 저장 결과 | 상태 |
|---|---|---|---|
| 101×2, 102×1 | `101,102` / `2,1` | 101×2, 102×1(변경 없음) | [확정] |
| 101×2, 102×1 | `101,103` / `1,1` | 101×1, 103×1(102 제외, 103 추가) | [확정] |
| 101×2, 102×1 | (공란) / (공란) | 오류, 기존 구성정보 유지 | [확정] |

## 10. 엑셀 양식관리·다운로드 정책

상품 엑셀 다운로드에 사용하는 엑셀 양식관리(양식별 출력 항목 선택·순서·저장)에 묶음상품 전용 항목 2개를 추가하는 정책입니다.

| 추가 항목 | 출력 내용 | 묶음상품 행 | 일반상품 행 | 상태 |
|---|---|---|---|---|
| 묶음 구성상품 | 상품 고유번호 | 저장된 구성 순서대로 콤마(`,`) 구분 출력 | 공란 | [확정] |
| 묶음수량 | 묶음 수량 | 묶음 구성상품과 같은 순서로 콤마(`,`) 구분 출력 | 공란 | [확정] |

- 두 항목의 선택·제외·순서 변경·양식 저장 방식은 기존 항목과 같습니다. [확정]
- 두 항목을 포함한 양식으로 다운로드한 파일을 그대로 다시 업로드하면 같은 묶음 구성이 재현됩니다. 같은 상품번호를 중복 입력한 묶음상품도 구성상품과 묶음수량의 대응 관계를 유지해 출력합니다. [확정]
- 두 항목을 포함하지 않은 양식으로 다운로드한 파일로 기존 묶음상품을 수정하면, 묶음상품 행에 묶음 구성상품·묶음수량이 없으므로 필수값 누락 오류입니다. [확정]

## 11. 오류 및 예외 처리

두 컬럼과 관련해 추가되는 실패 사유와 경계 상황의 처리입니다. 일부 행에 오류가 났을 때의 처리 범위와 결과 확인 방식은 현행 엑셀 업로드와 같습니다. [확정]

| 실패 사유 | 발생 조건 | 상태 |
|---|---|---|
| 필수값 누락 | 묶음상품 행에 묶음 구성상품·묶음수량 중 공란이 있거나 컬럼이 없음 | [확정] |
| 구성정보 일부 누락 | 신규 행에서 묶음 구성상품·묶음수량 중 하나만 입력 | [확정] |

## 12. 운영

정책 적용과 운영자 안내에 관한 사항입니다.

- 묶음수량 0은 유효한 값이지만, 0으로 저장하면 상품 상세페이지에서 해당 구성의 금액이 0원으로 처리되므로 운영상 권장하지 않습니다. 업로드 가이드에 안내합니다. [확정]
- 기존 묶음상품을 수정할 때는 엑셀 양식관리에서 "묶음 구성상품"·"묶음수량"을 포함한 양식으로 다운로드한 파일을 사용하도록 안내합니다. [확정]

## 13. 권한·로그

- 권한, 1회 업로드 건수·동시 처리 제한, 업로드 결과 확인, 처리 이력은 현행 판매상품 엑셀 업로드·다운로드와 같습니다. 묶음상품만을 위한 별도 권한·제한·로그는 두지 않습니다. [확정]

# [CS 운영·응대 가이드] 원 요청 이슈 묶음상품 엑셀 등록·수정

사양 정의서의 정책(POL·CON)을 상점 운영자 문의 응대용으로 요약한 문서입니다. 새로운 조건·예외를 만들지 않으며, 판단 기준은 사양 정의서의 POL·CON을 따릅니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
|---|---|
| 변경 목적 | 묶음상품도 판매상품 엑셀 업로드로 등록·수정할 수 있게 합니다. |
| 적용 대상 | UTF-8 전체 상점의 운영자·부운영자(판매상품 엑셀 업로드·다운로드 메뉴 권한 보유자) |
| 적용 시점 | 배포일 [배포 일정 확정 후 기재] |
| 고객 영향 | 엑셀 양식에 "묶음 구성상품"·"묶음수량" 컬럼이 추가됩니다. 쇼핑몰 구매자 화면은 바뀌지 않습니다. |
| 기존 고객 처리 | 기존 66개 컬럼 양식으로 일반상품을 올리면 지금과 같게 처리됩니다. 기존 묶음상품을 수정하려면 두 컬럼이 포함된 양식이 필요합니다. |
| 상담 핵심 포인트 | ① 묶음상품 행은 두 컬럼 필수 ② 수정 시 구성정보 전체 교체 ③ 일반↔묶음 유형 변경 불가 ④ 옵션·재고·판매가능여부는 입력해도 무시 |

| CON-002 | 업로드 전반 | 권한·업로드 건수 제한·결과 확인 방식은 기존 엑셀 업로드와 같습니다. | 해당 문의 시 | 제한값 변경 요청 수용 | 기획 |

## 10. 공지 및 운영 준비

- 고객 공지 필요 여부와 시점: 배포 시 상점 운영자 대상 업그레이드 노트로 안내합니다.
- 도움말·매뉴얼 수정: 판매상품 엑셀 업로드 예제 양식·항목 설명, 엑셀 양식관리 안내를 수정합니다.
- 상담 도구·관리자 조회 기능: 기존 업로드 결과 화면과 묶음상품 수정 화면을 사용합니다.
- 장애·대량 문의 발생 시 공지 기준: 일반상품 업로드 회귀가 확인되면 개발 이관 후 공지 여부를 정합니다.
- 알려진 제한사항과 임시 우회 방법: 같은 파일에서 신규 등록하는 상품은 구성상품으로 지정할 수 없습니다. 먼저 일반상품을 등록한 뒤 묶음상품을 등록해야 합니다.

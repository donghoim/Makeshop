## 2. 배경과 문제

| 항목 | 내용 |
|---|---|
| 배경 | 묶음상품은 가격 변동이 잦지만 엑셀 일괄 등록·수정을 지원하지 않아 수기로 개별 수정하고 있습니다. 요청 상점가 묶음상품 비중 확대를 앞두고 엑셀 일괄 수정을 요청했습니다. |
| 해결할 문제 | 판매상품 엑셀 양식(66개 컬럼)에 묶음상품의 필수 정보인 구성상품·묶음수량 컬럼이 없어 묶음상품을 구분하고 처리할 수 없습니다. 공통 상품 정보 컬럼은 이미 있습니다. |
| 사용자·운영 영향 | 가격 변동마다 수기 수정 공수가 들고 가격 반영 누락 위험이 있습니다. |
| 확인 근거 | 요구사항·AS-IS 분석 이슈 본문·댓글, 요구사항·AS-IS 분석서(2026-10-12), 기획 하위 작업, 판매상품 엑셀 업로드 예제 양식, 상품 등록·수정 기능 사양서(AI 초안·소스 확인), 기획 결정(2026-10-14) |

## 3. 목표와 범위

### 3.1 목표

- 묶음상품을 엑셀 업로드로 신규 등록·일괄 수정할 수 있게 합니다.
- 기존 컬럼과 처리 방식은 그대로 두고, 묶음상품 전용 컬럼 2개만 추가합니다.
- 묶음상품을 다운로드한 파일을 다시 업로드하면 같은 묶음 구성이 재현되게 합니다.
- 일반상품 엑셀 업로드·다운로드에 회귀가 없게 합니다.

### 3.2 포함 범위

- 묶음 구성상품·묶음수량 컬럼 추가와 예제 양식 교체
- 두 컬럼 입력 여부에 따른 상품 유형 판정과 유형 변경 차단
- 묶음 구성상품·묶음수량 검증, 구성정보 전체 교체 저장
- 엑셀 양식관리 항목 추가와 다운로드 시 구성정보 출력

### 3.3 제외 범위

- 기존 66개 컬럼의 처리 방식 변경(현행 유지)
- 묶음상품·구성상품의 옵션 생성·수정, 옵션(품목) 단위 구성 지정
- 묶음상품 전용 시트·구성상품별 행 입력, 같은 파일에서 신규 등록하는 상품을 구성상품으로 지정
- 관련상품·추가구성상품 묶음 설정 기능(관련상품 설정 과제) 개선, 신규 메뉴·화면

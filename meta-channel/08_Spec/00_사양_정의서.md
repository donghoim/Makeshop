## 2. 배경과 문제

| 항목 | 내용 |
| --- | --- |
| 배경 | 운영자는 Meta 광고·카탈로그를 쓰려면 Meta 비즈니스 관리자에서 자산을 하나씩 설정하고, 상품 연동·광고 성과·전환 추적을 각각 다른 화면에서 관리해야 합니다. |
| 해결할 문제 | FBE로 자산을 한 번에 연결하고, 메이크샵 상품의 Meta 카탈로그 전송 상태와 광고 성과·전환 추적 설정을 메이크샵 관리자에서 통합 관리하게 합니다. |
| 사용자·운영 영향 | 운영자의 Meta 관리 화면 이동이 줄고, 상품 피드 제한 사유를 메이크샵에서 바로 확인·수정할 수 있습니다. |
| 확인 근거 | Epic, Confluence 01·02·03(2026-10-13), 사용자 정책서(2026-10-19), 2026-10-19 결정: 개발자 앱 권한으로 커머스 계정을 받을 수 없어 커머스 연동 제외 / 대량 업데이트는 큐로 처리하므로 수동 전송 단계 폐지 |

## 3. 목표와 범위

### 3.1 목표

- FBE(Meta Embedded Signup)로 필수 자산 5종(Business Manager, Facebook Page, Pixel/Dataset, Catalog, Ad Account)을 한 번에 연결합니다.
- 메이크샵 상품을 기준으로 Meta Catalog 전송 상태를 6개 상태로 관리하고, 전송은 큐로 자동 처리합니다.
- 연결된 광고 계정의 캠페인 성과를 조회하고, 외부 결제수단 구매전환을 CAPI로 전송합니다.

### 3.2 포함 범위

- 연결 관리: 개인정보 동의, FBE 연동·재설정·해제, 자산 조회·상태·바로가기, 도메인 인증 안내, 상품 피드·광고 요약
- 카테고리 매칭(카테고리 단위·상품 단위), GPC·성별·연령대·사용여부 설정
- 상품 피드: 현황 요약, 상태 필터, 목록, 제한·미승인 사유, 전송 큐, 상품 변경 자동 동기화, 카탈로그 변경 재동기화
- 광고 관리: 광고 계정 정보, 캠페인 성과 요약·목록, 항목 설정, 전환 추적 설정
- 쇼핑몰 Pixel·CAPI 이벤트, 외부 결제(네이버페이 주문형·톡 체크아웃) Purchase 서버 전송
- Shops 관리: Instagram Shop 연결 상태 조회, 커머스 관리자(카탈로그)·Commerce Manager 바로가기
- 기존 페이스북 연동(FBE) 상점 전환: 기존 연동 정보 이관, Meta 비즈니스 진입 시 재연동 안내 얼럿, [확인] 시 연결 관리로 화면 전환 후 약관 노출, 동의 후 FBE 재연동(Meta 로그인부터), 재연동 완료 후 상품 피드 전송 시작. 기존 [페이스북 연동] 메뉴는 제공하지 않음

### 3.3 제외 범위

- 기존 [페이스북 연동] 메뉴의 사용 이벤트 선택(이벤트별 체크박스) 기능
- 기존 연동 정보를 삭제하거나 기존 전송을 중단하는 강제 해제(신규 메뉴 이용은 약관부터 재연동)
- Meta Commerce Account 연동(수신·저장·표시·바로가기)
- Shop·판매 채널의 생성·설정·삭제(Meta Commerce Manager에서 진행)
- 운영자가 상품을 골라 Meta로 보내는 수동 전송(선택 전송·재전송) 기능
- Meta 자산 생성·수정·삭제, 광고 캠페인·소재·예산 관리, 도메인 인증 직접 처리
- Meta에 직접 등록한 상품의 조회·수정·삭제, 카탈로그 전체 삭제 후 재등록
- Meta 광고 성과의 자체 귀속 판단

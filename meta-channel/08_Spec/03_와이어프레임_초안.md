# [와이어프레임 초안] Epic 메타 비즈니스 연동

화면·상태·동작·권한과 관련 정책 참조를 제공합니다. 화면 원본은 첨부한 HTML 화면정의서이며, 내려받아 브라우저로 열면 왼쪽 목차에서 화면을 골라 볼 수 있습니다.

| 구분 | 자료 | 기준 |

## 2. 화면별 구조

원본 레이아웃과 주석은 첨부 HTML에서 화면 번호로 확인합니다. 아래는 구현·디자인 인계를 위한 구조 요약이며, 처리 규칙의 원문은 각 FR·POL을 참조합니다.

### WF-001 채널 카드·홈 (3-1·3-2)

- 목적: 채널에서 Meta 기능과 주요 관리 영역으로 진입합니다.
- 진입점·이전 화면: 채널 목록 → Meta 비즈니스 홈
- 완료 후 이동: 카드 선택 → 연결 관리·상품 피드·광고 관리·Shops 관리
- 관련 요구사항·정책: REQ-001 · FR-001
- 원본 화면 번호: 3-1·3-2

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 채널 카드 → 홈의 4개 영역 카드 → 상태별 진입 버튼 | WF-001 |
| 노출·활성 | 카드명 "Meta 비즈니스"(기존 "페이스북 연동"). 홈은 연결 관리·상품 피드·광고 관리·Shops 관리 4개 영역 카드이며, 영역별 연동 상태에 따라 [설정하기]·[자세히 보기] 중 1개를 노출 | FR-001 |
| 안내·실패 | 별도 오류 문구가 정의되지 않은 경우 상위 사양의 해당 FR을 따릅니다. | FR-001 |

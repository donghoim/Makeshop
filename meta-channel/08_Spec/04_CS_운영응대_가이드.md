# [CS 운영·응대 가이드] Epic 메타 비즈니스 연동

> CS 운영·응대 가이드를 사양 정의서 하위에 게시했습니다(v1, 2026-10-20). 판단 기준은 사양 정의서 14장 POL이며, 이 문서는 새로운 조건·예외·보상을 만들지 않습니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 변경 목적 | 운영자가 Meta(페이스북·인스타그램) 자산 연결, 상품 카탈로그 연동, 광고 성과 확인, 전환 추적을 메이크샵 관리자에서 함께 관리하게 합니다. |
| 적용 대상 | 부가서비스 > 채널 > Meta 비즈니스(기존 "페이스북 연동") 사용 상점 |
| 적용 시점 | 배포일(미정) |
| 고객 영향 | 운영자: 메뉴명·화면 변경, 상품 자동 반영 / 쇼핑몰 구매 고객: 변화 없음 |
| 기존 고객 처리 | 기존 [페이스북 연동] 메뉴는 없어집니다. 기존 연동 정보는 이관하되, Meta 비즈니스에 들어오면 안내 얼럿이 뜨고 [확인]을 누르면 연결 관리로 이동해 약관이 열리고, 동의 후 Meta 로그인부터 다시 연동합니다. 재연동을 마치면 신규 상품 전송이 시작되고 안내는 더 이상 뜨지 않습니다. 취소해도 기존 연결은 유지됩니다. |
| 상담 핵심 포인트 | 기존 상점도 약관부터 재연동해야 합니다. 취소했다고 기존 연결이 해제되는 것은 아닙니다. 신규 큐는 성공 전까지 보류합니다. 커머스 계정 연동은 제공하지 않으며 Shops 관리는 조회·Meta 화면 이동만 제공합니다. |

| POL-086 부터 POL-095 | 기존 페이스북 연동 상점 | 기존 메뉴는 없어지고, Meta 비즈니스에서 약관 동의 후 다시 연동해야 합니다. 연동 정보와 기존 연결은 유지됩니다. 사용 이벤트 선택 기능은 제공하지 않습니다. | 기존 메뉴·재연동 문의 | 이관 정보 누락의 원인 | 개발(BE) |
| POL-005, POL-083 | 커머스 계정·Shops | 메이크샵 Meta 비즈니스는 커머스 계정을 연동하지 않습니다. Shops 관리 탭은 Instagram Shop 연결 상태와 바로가기만 보여주고, Shop 생성·판매 채널 설정은 Meta Commerce Manager에서 합니다. | Shops·커머스 계정 문의 | 향후 제공 일정 | 기획 |
| CON-004 | Meta 팝업·자산 | Meta 로그인·자산 선택 화면과 자산 생성·수정은 Meta가 제공합니다. | Meta 팝업 오류 문의 | Meta 화면 내부 오류 원인 | Meta 고객센터 안내 |
| POL-054 | 직접 등록 상품 | Meta에서 직접 등록한 상품은 메이크샵 상품 피드에 보이지 않고 메이크샵이 수정·삭제하지 않습니다. | 상품 누락 문의 | 직접 등록 상품 복구 | 없음(안내로 종결) |
| POL-081 | 광고 성과 | 광고 성과는 Meta 집계 기준이라 쇼핑몰 주문 매출과 다를 수 있습니다. | 성과 차이 문의 | 귀속 결과의 옳고 그름 | Meta 고객센터 안내 |

## 10. 공지 및 운영 준비

- 고객 공지 필요 여부와 시점: 배포 시 메뉴명 변경, 자동 전송, 커머스 계정 미연동·Shops 관리 탭 범위 공지. 기존 페이스북 연동 상점에는 약관부터 재연동해야 한다는 점, 성공 후 신규 상품 전송이 시작된다는 점, 이벤트별 선택·CAPI 사용 설정이 없어진다는 점을 함께 공지
- 도움말·매뉴얼 수정: 기존 "페이스북 연동" 매뉴얼을 Meta 비즈니스 기준으로 수정
- 상담 도구·관리자 조회 기능: 신규 조회 기능 없음. 운영자 화면의 상태·사유로 확인
- 장애·대량 문의 발생 시 공지 기준: 반영대기 장기 정체가 여러 상점에서 발생하면 개발 확인 후 공지
- 알려진 제한사항과 임시 우회 방법: 반영대기 상품을 수동으로 보내는 방법은 없습니다.

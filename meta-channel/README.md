# Meta 비즈니스 연동

메이크샵 관리자에서 Meta(페이스북·인스타그램) 자산을 FBE(Facebook Business Extension)로 한 번에 연결하고, 상품 피드·광고 성과·전환 추적·Instagram Shop 연결 상태를 관리하는 기능의 기획 산출물과 목업입니다.

| 구분 | 위치 | 내용 |
|---|---|---|
| 목업 | [`index.html`](./index.html) · [바로 보기](https://donghoim.github.io/Makeshop/meta-channel/) | 홈·연결 관리·상품 피드·광고 관리·Shops 관리 탭, FBE 연동 시뮬레이션, 기존 연동 상점 재연동 시나리오 |
| HTML 화면정의서 | [`screen-spec.html`](./screen-spec.html) · [바로 보기](https://donghoim.github.io/Makeshop/meta-channel/screen-spec.html) | 화면 16개, 왼쪽 목차·검색·확대, 번호 마커와 DESCRIPTION |
| 기획 문서 | [`08_Spec/`](./08_Spec) | 사양 정의서(FR 30·POL 95·AC 47), 요구사항 정의서, 개발 공유용 정책서, 와이어프레임 초안, CS 운영·응대 가이드 |
| 테스트 케이스 | [`qa/`](./qa) | 품질관리팀 표준 템플릿 기준 TC 111건(정상·예외·권한·회귀, P0~P2) |

## 주요 기획 내용

- **FBE 일괄 연동:** 개인정보 동의(필수 3개 + 전체 동의) 후 Meta 팝업에서 비즈니스·페이지·픽셀·카탈로그·광고 계정 5종을 연결합니다. 커머스 계정은 받지 않습니다.
- **상품 피드:** 상품 변경 시 전송 큐로 자동 반영합니다. 상태는 사용안함 → 노출제한 → 반영대기 → Meta 결과(검토중·활동중·미승인) 순으로 판정하고, Meta에 직접 등록한 상품은 건드리지 않습니다.
- **광고 관리·전환 추적:** 광고 계정과 캠페인 성과를 조회합니다. CAPI는 별도 사용 설정 없이 연동 중이면 전송하고, 외부 결제(네이버페이·톡 체크아웃) 구매 전환만 결제수단별로 켜고 끕니다.
- **기존 연동 상점 전환:** 기존 페이스북 연동 메뉴는 제공하지 않습니다. 기존 연동 상점은 Meta 비즈니스에 들어오면 안내 얼럿 → 연결 관리 화면 전환 → 약관 동의 → Meta 로그인부터 재연동합니다. 기존 연동 정보는 갱신되고(새 연동 추가 없음), 재연동을 마치면 얼럿이 더 이상 뜨지 않습니다.

## 실행 방법

- `index.html`을 브라우저로 열면 동작합니다(백엔드·DB 없음, Mock 데이터).
- 오른쪽 아래 **시나리오 패널**에서 미연동(최초 진입)·연동 완료·기존 상점(재연동 전) 상태와 자산 조회 실패, 광고 계정 상태 등을 바꿔 볼 수 있습니다. 실제 서비스 화면에는 없는 도구입니다.

## 폴더 구조

```
meta-channel
├── index.html          # 목업(어드민 셸 + 스크립트 로드)
├── src/                # css · js(app/store/ui/fbe-oauth/pages) · components · data
├── screen-spec.html    # HTML 화면정의서(화면 16개, SVG 내장)
├── 08_Spec/            # 사양·요구사항·정책서·와이어프레임 초안·CS 가이드
└── qa/                 # TC 엑셀
```

공개본에서는 사내 이슈 번호·문서 링크·담당자 정보를 일반 표현으로 바꾸거나 제외했습니다.

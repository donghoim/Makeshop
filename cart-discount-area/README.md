# 장바구니 결제 정보 할인 영역 추가

장바구니에서는 할인·쿠폰 정보가 보이지 않고 주문서에서만 적용되어, 고객이 장바구니 단계에서 받을 혜택과 결제 예정 금액을 알기 어려운 문제를 해결하기 위한 기획입니다. 대형 운영 상점의 요청에서 시작했고, 기본 템플릿을 일괄 변경하지 않고 가상태그 추가 개발과 기본 스킨 퍼블 방식으로 제공합니다.

| 구분 | 위치 | 내용 |
|---|---|---|
| 목업 | [`index.html`](./index.html) · [바로 보기](https://donghoim.github.io/Makeshop/cart-discount-area/) | 장바구니 결제 정보 영역의 할인 상세·최대 할인 적용, 쿠폰 선택 모달, 장바구니 타입별 화면 |
| HTML 화면정의서 | [`screen-spec.html`](./screen-spec.html) · [바로 보기](https://donghoim.github.io/Makeshop/cart-discount-area/screen-spec.html) | 화면 15개, 실제 동작하는 목업 + 번호 마커 + DESCRIPTION |
| 와이어프레임 | [`03_Wireframe/`](./03_Wireframe) | SVG 4장(결제 정보 할인 영역, 통합 장바구니 공급사별 쿠폰, 쿠폰 선택 모달, 할인 0건·정기배송 탭) |
| 기획 문서 | [`08_Spec/`](./08_Spec) | 사양 정의서, 요구사항 정의서, 정책서, 와이어프레임 초안, CS 운영·응대 가이드 |

## 주요 기획 내용

- 장바구니 결제 정보 영역에 총 할인 금액, 할인 상세(상품 할인·상품 쿠폰·장바구니 쿠폰), 최대 할인 기준 총 결제 금액을 노출합니다.
- 할인 산출 기준은 주문서와 같게 맞추고, 노출·최대 할인 적용에 더해 장바구니에서 쿠폰을 바꿀 수 있게 합니다.
- 개별·통합 장바구니, 정기배송 탭, 회원·비회원, 할인 0건·빈 장바구니 등 상태별 표현을 정의했습니다.

## 실행 방법

- `index.html`을 브라우저로 열면 동작합니다(백엔드·DB 없음, Mock 데이터).
- 오른쪽 아래 **[시나리오 설정]** 드로어에서 장바구니 타입, 데이터 프리셋, 회원 여부, 배송비 기준, PC·모바일 폭을 바꿀 수 있습니다.
- `?cartType=int1&preset=productOnly&view=mobile`처럼 주소로 시나리오를 지정할 수 있습니다.
- `screen-spec.html`은 같은 폴더의 `src` 목업 코드를 불러오므로 폴더째 받아서 엽니다.

## 단순화한 부분

- 절사는 원 단위 반올림입니다. 실제는 할인별 상점 설정을 따릅니다.
- 최대 할인 자동 조합은 할인액이 큰 조합부터 배정하는 방식으로 단순화했습니다. 실제 조합 산출은 개발 구현을 따릅니다.
- 쿠폰 등록, 옵션 변경, 견적서 출력, 주문하기는 토스트로만 표시합니다.

공개본에서는 고객사명·사내 이슈 번호·문서 링크·담당자 정보를 일반 표현으로 바꾸거나 제외했습니다.

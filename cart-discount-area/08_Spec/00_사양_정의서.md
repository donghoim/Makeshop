## 2. 배경과 문제

| 항목 | 내용 |
|---|---|
| 배경 | 대형 운영 상점(VVIP)가 29CM처럼 장바구니에서 할인·쿠폰 적용 상태와 최대 할인 금액을 보여 주기를 요청했습니다. 2026-09-09 쿠폰 변경을 포함한 2안으로 범위를 확정했습니다. |
| 해결할 문제 | 현행 장바구니 결제 정보는 "총 상품 금액 + 배송비 = 총 결제 금액"만 보여 주며, 할인과 쿠폰은 주문서에서만 확인·적용할 수 있습니다. |
| 사용자·운영 영향 | 고객이 받을 할인과 실제 결제 금액을 모른 채 주문서로 이동하거나 이탈하고, 상품 상세·장바구니·주문서 금액 차이로 문의가 생깁니다. |
| 확인 근거 | 원본 요청 본문·댓글(2026-06-02 범위 정리, 2026-09-09 2안 확정, 2026-10-01 결제정보 태그 처리), 기획 Task 댓글(1안·2안 공수, 정기배송 제외), Figma 기획/정책 v0.1(2026-10-01), Figma 디자인, 테스트 상점 장바구니 확인(2026-10-27) |

## 3. 목표와 범위

### 3.1 목표

- 장바구니 단계에서 상품 할인·상품 쿠폰·장바구니 쿠폰 할인과 최종 결제 금액을 보여 줍니다.
- 보유 쿠폰으로 만들 수 있는 최대 할인을 자동 적용하고, 고객이 쿠폰을 직접 고를 수 있게 합니다.
- 할인 산출은 주문서 기준을 재사용해 장바구니와 주문서 금액이 같게 합니다.
- 기본 스킨 사용 상점은 별도 작업 없이 적용되고, 개별디자인 상점은 가상태그로 적용합니다.

### 3.2 포함 범위

- 결제 정보 구성 변경(최대 할인 적용 토글, 총 상품 금액·총 할인 금액 하위 항목, 최종 결제 금액)
- 상품 할인·상품 쿠폰·장바구니 쿠폰 할인 산출과 노출
- 최대 할인 자동 적용, 쿠폰 직접 선택(상품쿠폰·장바구니 쿠폰 버튼, 쿠폰 선택 모달)
- 장바구니 타입 4종별 장바구니 쿠폰 적용 단위
- 기본 스킨 4종(반응형, basic_simple, modern_simple, 모바일 4.0) 반영, 개별디자인용 가상태그

### 3.3 제외 범위

- 정기배송 탭(현행 유지)
- 구매 버튼 금액 표기 변경, 팝업·바텀시트 형태의 할인 안내. 기본 템플릿 UI 일괄 변경 대신 가상태그 제공으로 정했으며(2026-06-02), 이 형태는 상점 개별디자인으로 구성합니다.
- 주문 할인(회원그룹 결제조건, 결제수단 할인)·적립금·배송비 쿠폰의 장바구니 적용, 적립 예정 금액 노출
- 지역별 추가 배송비, 당일배송 배송비
- EUC-KR 상점, 일반 쿠폰 상점, 관리자 노출 설정 추가

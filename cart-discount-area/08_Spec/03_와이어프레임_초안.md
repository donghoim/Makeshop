## 2. 화면별 구조

### WF-001 장바구니 일반구매 탭 · 결제 정보 할인 영역

- 목적: 장바구니에서 할인 금액과 최종 결제 금액을 확인하고 쿠폰을 고릅니다.
- 진입점·이전 화면: 장바구니 아이콘, 장바구니 담기 후 이동
- 완료 후 이동: 주문하기 → 주문서
- 관련 정책: POL-001부터 POL-051까지
- SVG: [WF-001](./WF-001_장바구니_결제정보_할인영역.svg)

```text
[일반구매(n)] [정기배송(n)]
------------------------------------------------------------------
☑ 전체                       [선택삭제] | 결제 정보      [최대 할인 적용 ○●]
☑ [이미지] 상품명·옵션·판매가 [수량][옵션변경][상품쿠폰] | 총 상품 금액 ︿          000,000원
☑ [이미지] 상품명·옵션·판매가 [수량][옵션변경][상품쿠폰] |  ㄴ 상품 금액 / 배송비
                                                    | 총 할인 금액 ︿          -00,000원
· 지역별 배송정책 안내    [견적서 출력][장바구니 쿠폰]   |  ㄴ 상품 할인 / 상품 쿠폰 / 장바구니 쿠폰
                                                    |  ㄴ 주문 할인 / 보유 적립금 / 적립금 즉시 할인: 주문서에서 확인 가능
                                                    | 최종 결제 금액           000,000원
                                                    | [주문하기]
```

### WF-002 통합 장바구니 공급사별 장바구니 쿠폰

- 목적: 공급사 묶음마다 장바구니 쿠폰을 따로 적용합니다.
- 관련 정책: POL-020, POL-021, POL-040, POL-041, POL-042, POL-043
- SVG: [WF-002](./WF-002_통합장바구니_공급사별_쿠폰.svg)

```text
본사배송
☑ 상품 행 …                                   [상품쿠폰]
상품 금액 + 배송비 = 총 합계 금액(현행)
                                            [장바구니 쿠폰]
A업체배송
☑ 상품 행 …                                   [상품쿠폰]
상품 금액 + 배송비 = 총 합계 금액(현행)
                                            [장바구니 쿠폰]
(전체 장바구니 쿠폰 버튼 없음)
```

### WF-003 쿠폰 선택 모달

- 목적: 버튼의 적용 단위에 쓸 수 있는 쿠폰을 고릅니다.
- 진입점: WF-001·WF-002의 [상품쿠폰], [장바구니 쿠폰]
- 완료 후 이동: [쿠폰적용] → 결제 정보 다시 계산, [×]·바깥 영역·Esc → 변경 없이 닫기
- 관련 정책: POL-022, POL-023, POL-024, POL-025, POL-026, POL-033, POL-034, POL-035, POL-036, POL-037, POL-038, POL-044, POL-045, POL-046
- SVG: [WF-003](./WF-003_쿠폰선택_모달.svg)

```text
상품쿠폰 적용 (또는 장바구니 쿠폰 적용)                    [×]
쿠폰 등록      [쿠폰 번호 입력          ] [등록]
적용 쿠폰 선택  ○ 쿠폰 적용 안함 / ○ 쿠폰 … (1개)
적용 중복 쿠폰 선택  □ 중복 쿠폰 … (여러 개)
적용 불가 쿠폰  쿠폰 · 사용 조건 (선택 불가)
· 결제수단 제한 / 조건부 미적용 / 마이페이지 확인 안내
[쿠폰적용]
```

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 모바일은 결제 정보가 상품 목록 아래로 내려갑니다. 장바구니 쿠폰 버튼 위치는 스킨별로 다릅니다(반응형: 상품 목록 하단, basic_simple·modern_simple·모바일 4.0: 결제 정보 박스 안).
- 키보드·초점 순서: 토글은 스위치 역할로 Space·Enter 조작, 모달은 열릴 때 모달 안으로 초점 이동, Esc로 닫기.
- 긴 문구: 쿠폰명은 줄바꿈 허용.

# [정책서] 원본 요청 장바구니 결제 정보 할인 노출

| 항목 | 내용 |

| 문서 유형 | 기능 개선 |
| 대상 서비스 | 쇼핑몰 장바구니(일반구매 탭) 결제 정보 영역, 장바구니 쿠폰 선택 |

## 2. 변경 사항 요약

이번 개선으로 바뀌는 내용과 그 이유를 요약합니다.

### 2.1 한 줄 요약

장바구니 결제 정보에 상품 할인·상품 쿠폰·장바구니 쿠폰 할인과 최종 결제 금액을 보여 주고, 최대 할인 자동 적용과 장바구니 쿠폰 선택을 제공합니다.

### 2.2 변경 목적

- 고객이 장바구니에서 받을 수 있는 할인과 예상 결제 금액을 주문서에 들어가기 전에 확인할 수 있게 합니다.
- 상품 상세, 장바구니, 주문서 사이의 금액 차이로 생기는 이탈과 문의를 줄입니다.
- 할인 산출은 주문서 기준을 그대로 사용해 장바구니와 주문서 금액이 같게 합니다.

### 2.3 변경 전·후

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 결제 정보 구성 | 총 상품 금액, 배송비, 총 결제 금액 | 최대 할인 적용 토글, 총 상품 금액(상품 금액·배송비), 총 할인 금액(할인 항목별 금액), 최종 결제 금액 |
| 할인 확인 시점 | 주문서에서만 확인 | 장바구니에서 상품 할인·상품 쿠폰·장바구니 쿠폰 할인 확인 |
| 쿠폰 선택 | 주문서에서만 선택 | 장바구니에서 상품 쿠폰·장바구니 쿠폰 선택, 최대 할인 자동 적용 |
| 제공 방식 | 개별디자인 가상태그로 일부 금액만 노출 | 기본 스킨 소스에 반영하고 개별디자인 가상태그로 제공 |

## 3. 적용 대상 및 범위

이 정책이 적용되는 상점·화면과 이번 범위에서 제외하는 항목을 정의합니다.

### 적용 대상

- VER3(주문 2.0, 통합옵션) UTF-8 상점
- 스마트 쿠폰 사용 상점
- 기본 스킨: 반응형, basic_simple, modern_simple, 모바일 4.0
- 장바구니 타입: 개별 장바구니, 통합 장바구니1, 통합 장바구니2(통합쿠폰), 통합 장바구니2(개별쿠폰)
- 장바구니 일반구매 탭

### 포함 범위

- 결제 정보 영역 구성과 금액 산출·노출
- 최대 할인 적용 토글
- 상품 쿠폰·장바구니 쿠폰 선택 버튼과 쿠폰 선택 모달
- 장바구니 단계 배송비 계산 범위

### 제외 및 예외 범위

- 장바구니 정기배송 탭. 정기배송 탭의 결제 정보는 현행(총 상품 금액, 배송비, 총 결제 금액, 정기배송 자동결제 금액 변동 안내)을 그대로 유지합니다.
- EUC-KR 상점, 일반 쿠폰(스마트 쿠폰 미사용) 상점
- 배송비 쿠폰. 배송비 쿠폰은 주문서에서만 노출·적용합니다.
- 주문 할인(회원그룹 결제조건 혜택, 결제수단 할인), 보유 적립금, 적립금 즉시 할인의 장바구니 적용. 금액은 주문서에서 확정합니다.
- 적립 예정 금액 노출
- 배송지에 따라 정해지는 지역별 추가 배송비와 당일배송 배송비
- 관리자 설정 화면 추가. 노출 여부는 별도 설정 없이 스킨 소스(가상태그)로 제어합니다.

### 이용 조건

- 쿠폰 할인은 쿠폰을 보유한 로그인 회원에게만 적용합니다. 비회원과 쿠폰 사용 조건, 권한, 쿠폰 발급·보유 처리는 현행 주문서 쿠폰 적용과 같습니다.
- 상점의 할인·쿠폰·배송비 설정값을 그대로 사용하며, 이 기능을 위한 별도 설정은 추가하지 않습니다.

## 4. 상세 정책

### 4.1 제공 방식과 노출 범위

결제 정보의 할인 영역을 어떤 화면에 어떤 방식으로 제공하는지 정의합니다.

- 할인 영역은 장바구니 일반구매 탭의 결제 정보에만 노출합니다.
- 정기배송 탭은 일반구매 탭과 분리된 별도 장바구니이며, 할인 영역·최대 할인 적용 토글·쿠폰 버튼을 노출하지 않습니다.
- 기본 스킨 4종의 장바구니 소스에 할인 영역을 반영합니다. 개별디자인을 사용하는 상점은 제공하는 가상태그를 직접 넣어 적용합니다.
- 관리자에 노출 여부 설정을 추가하지 않습니다. 스킨 소스에 할인 영역 가상태그가 있으면 노출하고, 없으면 노출하지 않습니다.

관련 정책: POL-001, POL-002, POL-003

### 4.2 결제 정보 구성

결제 정보 영역을 구성하는 항목과 각 항목의 노출 조건입니다.

| 항목 | 하위 항목 | 노출 조건 |
| --- | --- | --- |
| 최대 할인 적용 토글 | - | 항상 노출합니다. 적용할 수 있는 할인이 없으면 비활성화합니다(4.9). |
| 총 상품 금액 | 상품 금액, 배송비 | 항상 노출합니다. |
| 총 할인 금액 | 상품 할인, 상품 쿠폰, 장바구니 쿠폰, 주문 할인, 보유 적립금, 적립금 즉시 할인 | 상품 할인·상품 쿠폰·장바구니 쿠폰 중 할인 금액이 있는 항목이 1개 이상이면 노출합니다(4.6). |
| 최종 결제 금액 | - | 항상 노출합니다. |

- 총 상품 금액과 총 할인 금액의 하위 항목은 처음에 펼친 상태로 노출합니다. 접기/펼치기 아이콘을 누르면 하위 항목을 접거나 펼칩니다.
- 접기/펼치기 상태는 장바구니 페이지 안에서만 유지하고, 다시 들어오면 펼친 상태로 노출합니다.
- 최종 결제 금액은 할인 적용 후 금액만 노출하고, 할인 전 금액을 취소선으로 함께 노출하지 않습니다.
- 적립 예정 금액은 노출하지 않습니다. 개별디자인으로 기존 적립 예정 금액 가상태그를 넣으면 노출할 수 있으나, 이 금액은 쿠폰 할인이 반영되지 않은 금액이라 주문서와 다를 수 있습니다.

관련 정책: POL-004, POL-005, POL-006, POL-007

### 4.3 총 상품 금액

할인을 적용하기 전 금액을 산출하는 기준입니다.

| 항목 | 산출 기준 |
| --- | --- |
| 상품 금액 | 선택한 상품의 (판매가 + 옵션 추가 금액) × 수량 합계 |
| 배송비 | 선택한 상품 기준으로 장바구니에서 계산할 수 있는 배송비 합계(4.12) |
| 총 상품 금액 | 상품 금액 + 배송비 |

- 체크한 상품만 합산하고, 체크를 해제한 상품은 제외합니다.
- 현행 결제 정보의 항목은 다음과 같이 포함합니다. 별도 줄로 다시 더하지 않습니다.

| 기존 항목 | 처리 |
| --- | --- |
| 부가세 | 상품 금액에 포함합니다. |
| 상품별 추가 배송비 | 배송비에 포함합니다. |
| 상품별 그룹 할인 | 총 할인 금액의 상품 할인에 포함합니다. |
| 세트상품 할인 | 세트상품 판매가에 이미 반영된 금액이므로 다시 차감하지 않습니다(4.5.4). |

- 상점이 위 항목을 따로 보여 주려면 개별디자인으로 기존 가상태그를 해당 항목의 하위 줄로 추가합니다. 예) 상품 금액 아래에 부가세 줄을 추가합니다. 이때도 금액은 다시 더하지 않습니다.

관련 정책: POL-008, POL-009, POL-010

### 4.4 재계산

결제 정보 금액을 다시 계산하는 시점입니다.

- 아래 동작이 일어나면 새로고침 없이 총 상품 금액, 총 할인 금액, 최종 결제 금액을 즉시 다시 계산합니다.
  - 상품 수량 변경
  - 상품 체크·체크 해제, 선택 삭제
  - 옵션 변경
  - 쿠폰 적용·변경·해제
  - 최대 할인 적용 토글 ON·OFF
- 통합 장바구니는 공급사 묶음 합계도 함께 다시 계산합니다.

관련 정책: POL-011

### 4.5 할인 항목별 산출

할인 항목별 산출 기준입니다. 쿠폰 적용 가능 여부, 산출 기준, 계산 순서, 안분 방식, 절사 단위는 모두 주문서와 같습니다.

#### 4.5.1 적용 순서

| 순서 | 할인 | 계산 기준 금액 |
| --- | --- | --- |
| 1 | 상품 할인 | 상품 판매가 |
| 2 | 상품 쿠폰 | 상품 할인 적용 후 금액 |
| 3 | 장바구니 쿠폰 | 상품 할인과 상품 쿠폰 적용 후 금액의 합계 |

- 각 할인의 절사 단위와 방식은 해당 할인의 상점 설정값을 따릅니다.

관련 정책: POL-012

#### 4.5.2 상품 할인

상품 단위로 설정한 할인입니다. 토글 상태와 관계없이 항상 적용합니다.

| 차수 | 할인 | 계산 기준 금액 |
| --- | --- | --- |
| 1차 | 리바이 할인, 기간 할인, 신상품 할인 중 1개 | 판매가. 리바이 할인 → 기간 할인 → 신상품 할인 순으로 우선순위가 가장 높은 1개만 적용합니다. |
| 2차 | 대량 구매 할인 | 1차 할인가 |
| 3차 | 상품별 그룹 할인 | 2차 할인가 |

- 상품별 할인 금액은 (판매가 − 3차 할인가) × 수량이며, 상품 할인은 상품별 할인 금액의 합계입니다.
- 정액 할인은 설정 금액을, 정률 할인은 해당 차수의 계산 기준 금액 × 설정 비율을 차감합니다.
- 아래 상품 할인 설정값을 함께 적용합니다.

| 설정 | 처리 |
| --- | --- |
| 옵션 금액 할인 | 사용하면 옵션 추가 금액에도 할인을 적용합니다. 사용하지 않으면 옵션 추가 금액은 할인 없이 더합니다. |
| 상품 그룹 혜택 | 적용으로 설정한 상품만 로그인 회원의 회원그룹 기준 상품별 그룹 할인을 적용합니다. |

예) 판매가 20,000원, 기간 할인 5%, 상품별 그룹 할인 10%, 수량 1

| 단계 | 계산 | 금액 |
| --- | --- | --- |
| 1차 기간 할인 | 20,000 × 5% = 1,000원 차감 | 19,000원 |
| 3차 그룹 할인 | 19,000 × 10% = 1,900원 차감 | 17,100원 |
| 상품 할인 | (20,000 − 17,100) × 1 | 2,900원 |

관련 정책: POL-013, POL-014, POL-015, POL-016

#### 4.5.3 상품 쿠폰

개별 상품에 적용하는 상품 쿠폰·상품 중복 쿠폰입니다.

- 회원이 이미 보유한 쿠폰(자동 발급, 수동 발급, 다운로드)만 대상입니다.
- 상품 할인 적용 후 금액을 기준으로 계산하며, 쿠폰의 옵션 금액 포함 설정에 따라 옵션 추가 금액을 포함하거나 제외합니다.
- 정액 쿠폰은 설정 금액을, 정률 쿠폰은 계산 기준 금액 × 설정 비율을 할인합니다. 정률 쿠폰에 최대 할인 금액이 있으면 그 금액을 넘지 않습니다.
- 쿠폰의 수량 적용 설정에 따라 수량을 할인 금액에 반영합니다. 쿠폰 할인 금액에 수량을 항상 곱하지는 않습니다.
- 상품 쿠폰은 상품 단위로 적용하므로 장바구니 타입의 영향을 받지 않습니다.
- 상품에 쿠폰 사용 결제를 허용하지 않았거나 상품 쿠폰 할인을 적용하지 않도록 설정한 경우, 해당 상품에는 상품 쿠폰·장바구니 쿠폰 할인을 계산하지 않습니다.

예) 상품 할인 적용 후 금액 17,100원, 수량 1, 옵션 추가 금액 없음

| 쿠폰 | 계산 | 쿠폰 할인 |
| --- | --- | --- |
| 정액 1,000원 | 1,000원 | 1,000원 |
| 정률 10% | 17,100 × 10% | 1,710원 |
| 정률 10%, 최대 할인 1,500원 | 1,710원이 1,500원을 넘음 | 1,500원 |

관련 정책: POL-018, POL-019

#### 4.5.4 세트상품 할인

세트상품의 구성 할인은 세트상품 판매가에 이미 반영되어 있습니다.

- 세트상품 할인 금액은 상품 할인에 포함하지 않고, 결제 금액에서 다시 차감하지 않습니다.
- 다른 할인은 세트 할인이 반영된 판매가를 기준으로 계산합니다.
- 개별디자인으로 세트상품 할인 가상태그(`total_package_price`)를 넣으면 구성상품별 세트 할인 금액의 합계를 안내 금액으로 노출할 수 있습니다. 예) 구성상품 A 10,000원·5%, B 20,000원·5% → 1,500원

관련 정책: POL-017

#### 4.5.5 장바구니 쿠폰

주문(장바구니) 단위로 적용하는 장바구니 쿠폰·장바구니 중복 쿠폰입니다.

- 회원이 이미 보유한 쿠폰만 대상입니다.
- 적용 단위에 속한 상품의 상품 할인·상품 쿠폰 적용 후 금액을 합산한 금액에 1회 적용하며, 결제 정보에서는 상품별로 나누어 표시하지 않습니다.
- 정액·정률·최대 할인 금액 처리는 상품 쿠폰과 같습니다.
- 적용 단위는 장바구니 타입에 따라 정합니다.

| 장바구니 타입 | 적용 단위 | 결제 정보 표시 |
| --- | --- | --- |
| 개별 장바구니 | 장바구니 전체(단일 업체) | 장바구니 쿠폰 1줄 |
| 통합 장바구니1 | 공급사 묶음별 | 묶음별 할인 금액의 합계 1줄 |
| 통합 장바구니2(통합쿠폰) | 장바구니 전체 | 장바구니 쿠폰 1줄 |
| 통합 장바구니2(개별쿠폰) | 공급사 묶음별 | 묶음별 할인 금액의 합계 1줄 |

예) 본사 묶음 79,100원, 공급사 A 묶음 21,800원, 쿠폰 5%

| 장바구니 타입 | 계산 | 장바구니 쿠폰 |
| --- | --- | --- |
| 개별 장바구니(본사) | 79,100 × 5% | 3,955원 |
| 통합 장바구니1, 통합 장바구니2(개별쿠폰) | 79,100 × 5% + 21,800 × 5% | 5,045원 |
| 통합 장바구니2(통합쿠폰) | 100,900 × 5% | 5,045원 |

관련 정책: POL-020, POL-021

#### 4.5.6 쿠폰 적용 대상

쿠폰마다 적용할 수 있는 상품과 조건입니다.

| 쿠폰 설정 | 처리 |
| --- | --- |
| 쿠폰 사용 조건(최소 구매 금액) | 조건을 충족한 경우에만 적용합니다. 장바구니 쿠폰은 적용 단위(공급사 묶음 또는 전체) 기준으로 판정합니다. |
| 적용 상품·제외 상품 | 전체·개별·브랜드·분류·가상분류·기획전 단위 설정에 따라 적용하거나 제외합니다. |
| 사용 가능 회원 등급 | 해당 등급의 로그인 회원에게만 적용합니다. |
| 발행 주체 | 공급사 발행 쿠폰은 해당 공급사 상품에만, 본사 전용 쿠폰은 본사 상품에만, 본사+공급사 쿠폰은 공급사 구분 없이 적용합니다. 본사+공급사 쿠폰은 통합 장바구니2에서만 발행할 수 있습니다. |
| 쿠폰 중복 설정 | 중복 사용 가능 쿠폰만 최대 할인 자동 적용 대상입니다. 중복 사용 불가 쿠폰은 고객이 직접 선택할 때만 적용합니다(4.8). |

- 쿠폰을 적용한 뒤 수량 변경, 상품 체크 해제 등으로 사용 조건을 충족하지 못하면 해당 쿠폰을 자동으로 해제하고 다시 계산합니다.

관련 정책: POL-022, POL-023, POL-024, POL-025, POL-026

### 4.6 총 할인 금액 노출

총 할인 금액 영역과 하위 항목의 노출 기준입니다.

- 총 할인 금액 = 상품 할인 + 상품 쿠폰 + 장바구니 쿠폰이며, 음수(예: -4,800원)로 표기합니다.
- 하위 항목의 금액을 모두 더한 값과 총 할인 금액은 항상 같습니다.

| 하위 항목 | 노출 |
| --- | --- |
| 상품 할인 | 할인 금액이 0원이면 노출하지 않습니다. |
| 상품 쿠폰 | 할인 금액이 0원이면 노출하지 않습니다. |
| 장바구니 쿠폰 | 할인 금액이 0원이면 노출하지 않습니다. |
| 주문 할인, 보유 적립금, 적립금 즉시 할인 | 금액 대신 "주문서에서 확인 가능"으로 노출합니다. 상품 쿠폰과 장바구니 쿠폰 할인이 모두 0원이면 3개 항목 모두 노출하지 않습니다. |

| 상황 | 결과 |
| --- | --- |
| 상품 할인·상품 쿠폰·장바구니 쿠폰이 모두 0원 | 총 할인 금액 영역 전체를 노출하지 않습니다. "총 할인 금액 0원" 같은 빈 줄도 노출하지 않습니다. |
| 상품 할인만 있고 쿠폰 할인 0원 | 총 할인 금액과 상품 할인만 노출합니다. 주문서에서 확인 가능 항목 3개는 노출하지 않습니다. |
| 쿠폰 할인이 1건 이상 | 할인 금액이 있는 항목과 주문서에서 확인 가능 항목 3개를 노출합니다. |

관련 정책: POL-027, POL-028, POL-029, POL-030

### 4.7 최종 결제 금액

장바구니 단계의 최종 결제 예정 금액입니다.

- 최종 결제 금액 = 총 상품 금액 − 총 할인 금액
- 배송비는 할인 차감 대상이 아니며, 총 상품 금액에 포함된 배송비를 그대로 유지합니다.
- 주문 할인, 적립금, 예치금 등 주문서 단계 혜택은 반영하지 않습니다.
- 총 할인 금액은 총 상품 금액을 넘을 수 없으며, 계산 결과가 음수이면 0원으로 노출합니다.

예) 판매가 19,000원, 배송비 3,000원

| 단계 | 할인 | 계산 | 적용 후 금액 |
| --- | --- | --- | --- |
| 1 | 상품 할인(기간 할인 5%) | 19,000 × 5% = 950원 | 18,050원 |
| 2 | 상품 할인(그룹 할인 1%) | 18,050 × 1% = 181원 | 17,869원 |
| 3 | 상품 쿠폰 10% | 17,869 × 10% = 1,787원 | 16,082원 |
| 4 | 상품 중복 쿠폰 5% | 16,082 × 5% = 804원 | 15,278원 |
| 5 | 장바구니 쿠폰 10% | 15,278 × 10% = 1,528원 | 13,750원 |
| 6 | 장바구니 중복 쿠폰 5% | 13,750 × 5% = 688원 | 13,062원 |
| 결과 | 총 상품 금액 22,000원, 총 할인 금액 -5,938원 | 22,000 − 5,938 | 최종 결제 금액 16,062원 |

관련 정책: POL-031, POL-032

### 4.8 최대 할인 적용 토글

적용 가능한 쿠폰을 조합해 최저 결제 금액을 자동으로 적용할지 고객이 선택하는 기능입니다.

| 항목 | 내용 |
| --- | --- |
| 기본값 | ON |
| 상태 유지 | 장바구니 페이지 안에서만 유지하고, 다시 들어오면 ON으로 돌아갑니다. |
| 토글 ON | 상품 할인에 더해, 보유한 중복 사용 가능 상품 쿠폰·장바구니 쿠폰을 조합해 최저 결제 금액이 되도록 자동 적용합니다. |
| 토글 OFF | 상품 할인만 적용하고 자동 적용한 쿠폰을 모두 해제합니다. |

| 할인 | 토글 ON | 토글 OFF |
| --- | --- | --- |
| 상품 할인 | 적용 | 적용 |
| 상품 쿠폰 | 자동 적용 | 해제(고객이 직접 선택한 쿠폰만 적용) |
| 장바구니 쿠폰 | 자동 적용 | 해제(고객이 직접 선택한 쿠폰만 적용) |

- 중복 사용 불가 쿠폰은 자동 적용 대상에서 제외합니다. 고객이 쓰려던 쿠폰(유효기간 임박 등)이 자동 적용 때문에 배제되지 않도록, 중복 불가 쿠폰 사용 여부는 고객이 직접 정합니다.
- 사용 조건을 충족하지 못한 쿠폰은 자동 적용 대상에서 제외합니다.

#### 처리 흐름

| 고객 동작 | 처리 |
| --- | --- |
| 장바구니 진입 | 토글 ON. 적용 가능한 할인 수집 → 중복 불가 쿠폰 제외 → 상품 할인 → 상품 쿠폰 → 장바구니 쿠폰 순으로 계산해 최저 결제 금액을 적용합니다. |
| 토글을 OFF로 변경 | 자동 적용한 쿠폰과 직접 선택한 쿠폰을 모두 해제하고, 상품 할인만으로 다시 계산합니다. |
| 토글 ON 상태에서 쿠폰을 직접 선택 | 토글을 OFF로 바꾸고, 자동 적용 결과를 해제한 뒤 직접 선택한 쿠폰만 적용해 다시 계산합니다. |
| 토글 OFF 상태에서 쿠폰을 직접 선택 | 토글은 OFF를 유지하고, 직접 선택한 쿠폰을 적용해 다시 계산합니다. |
| 중복 불가 쿠폰을 직접 선택 | 같은 적용 대상에 적용된 중복 가능 쿠폰을 해제하고, 선택한 쿠폰만 단독으로 적용합니다. |
| 토글을 다시 ON으로 변경 | 직접 선택한 쿠폰을 해제하고, 최대 할인 조합을 다시 계산해 적용합니다. |

관련 정책: POL-033, POL-034, POL-035, POL-036, POL-037, POL-038

### 4.9 최대 할인 적용 토글 비활성화

적용할 수 있는 할인이 없을 때의 토글 처리입니다.

- 선택한 상품에 적용 가능한 할인(상품 할인, 사용 조건을 충족한 보유 쿠폰)이 1건도 없으면 토글을 OFF 모양으로 비활성화하고, 고객이 바꿀 수 없게 합니다.
- 수량 변경, 상품 체크 등으로 적용 가능한 할인이 생기면 토글을 다시 활성화하고 ON으로 최대 할인을 다시 계산합니다.
- 적용 가능한 할인은 있지만 고객이 쿠폰을 직접 해제한 경우에는 토글을 비활성화하지 않습니다.

관련 정책: POL-039

### 4.10 쿠폰 버튼 노출

상품 쿠폰 버튼과 장바구니 쿠폰 버튼을 노출하는 기준입니다. 버튼 위치는 스킨마다 다르며, 노출 개수와 적용 단위는 아래 기준을 따릅니다.

| 버튼 | 노출 | 적용 단위 |
| --- | --- | --- |
| 상품 쿠폰 | 장바구니 타입과 관계없이 상품마다 1개 | 해당 상품 |
| 장바구니 쿠폰 | 장바구니 타입에 따라 아래 기준으로 노출 | 아래 기준 |

| 장바구니 타입 | 장바구니 쿠폰 버튼 | 적용 단위 |
| --- | --- | --- |
| 개별 장바구니 | 장바구니 전체에 1개 | 단일 업체(본사 또는 공급사) |
| 통합 장바구니1 | 공급사 묶음마다 1개 | 공급사 묶음 |
| 통합 장바구니2(통합쿠폰) | 장바구니 전체에 1개 | 장바구니 전체 |
| 통합 장바구니2(개별쿠폰) | 공급사 묶음마다 1개 | 공급사 묶음 |

- 공급사 묶음별 버튼과 장바구니 전체 버튼은 함께 노출하지 않습니다.
- 적용할 수 있는 쿠폰이 없어도 버튼을 노출합니다. 버튼을 누르면 쿠폰 선택 모달을 열고, 선택할 수 있는 쿠폰이 없는 상태로 보여 줍니다.
- 배송비 쿠폰 버튼은 노출하지 않습니다.

관련 정책: POL-040, POL-041, POL-042, POL-043

### 4.11 쿠폰 선택 모달

쿠폰 버튼을 눌렀을 때 쿠폰을 고르는 모달입니다. 쿠폰 등록, 쿠폰 정보 표시, 선택 규칙은 주문서 쿠폰 선택과 같습니다.

| 영역 | 내용 | 선택 방식 |
| --- | --- | --- |
| 쿠폰 등록 | 쿠폰 코드를 입력해 쿠폰을 등록합니다. | - |
| 적용 쿠폰 선택 | 상품 쿠폰(또는 장바구니 쿠폰) 목록과 "쿠폰 적용 안함" | 1개만 선택 |
| 적용 중복 쿠폰 선택 | 상품 중복 쿠폰(또는 장바구니 중복 쿠폰) 목록 | 여러 개 선택 |
| 적용 불가 쿠폰 | 보유했지만 사용 조건을 충족하지 못한 쿠폰과 그 조건 | 선택 불가 |
| 안내 | 쿠폰별 결제수단 제한, 조건에 따라 적용되지 않을 수 있음, 적용 불가 쿠폰 상세 조건은 마이페이지 보유쿠폰에서 확인 | - |

- 모달에는 회원이 보유한 쿠폰만 노출합니다. 보유 쿠폰 중 사용 조건을 충족한 쿠폰은 적용 쿠폰 선택·적용 중복 쿠폰 선택 영역에, 충족하지 못한 쿠폰은 적용 불가 쿠폰 영역에 노출합니다.
- 모달에는 누른 버튼의 적용 단위에 쓸 수 있는 쿠폰만 노출합니다. 상품 쿠폰 버튼은 해당 상품, 공급사 묶음별 장바구니 쿠폰 버튼은 해당 공급사 묶음 기준입니다.
- 모달을 열면 현재 적용된 쿠폰을 선택한 상태로 보여 줍니다.
- 중복 사용 불가 쿠폰을 선택하면 중복 쿠폰은 선택할 수 없습니다.
- [쿠폰적용]을 누르면 선택을 적용하고 모달을 닫으며 결제 정보를 다시 계산합니다. 닫기를 누르면 변경 없이 닫습니다.
- 다른 상품이나 공급사 묶음에 이미 적용한 쿠폰은 같은 쿠폰을 중복으로 쓸 수 없는 경우 선택할 수 없습니다. 이 판정은 주문서와 같습니다.

관련 정책: POL-044, POL-045, POL-046

### 4.12 배송비

장바구니에서 배송비를 계산하는 범위와 기준입니다. 기존 메이크샵 배송비 설정과 계산 방식을 그대로 사용하며, 이 기능을 위한 계산 방식을 추가하지 않습니다.

#### 4.12.1 계산 범위

| 구분 | 배송비 |
| --- | --- |
| 장바구니에서 계산 | 무료, 착불, 고정, 조건, 금액별 차등, 무게별 차등, 상품별 무료, 상품별 추가 배송비 |
| 장바구니에서 계산하지 않음 | 제주·도서산간·관리자 지정 지역 추가 배송비 등 배송지에 따라 정해지는 배송비. 주문서에서 배송지를 정한 뒤 계산합니다. |

- 상품별 개별 배송비와 기본 배송비가 함께 있으면 기존 적용 우선순위와 합산 방식을 따릅니다.

#### 4.12.2 주문금액 조건 판정

조건 배송비, 금액별 차등 배송비처럼 주문금액에 따라 배송비가 바뀌는 경우, 상점의 배송비 청구 기준 설정을 따릅니다.

| 상점 설정 | 판정 기준 | 예) 무료배송 기준 50,000원, 할인 전 52,000원, 할인 후 45,000원 |
| --- | --- | --- |
| 할인 전 정상판매가격 기준 | 할인 전 상품 금액. 할인이 바뀌어도 배송비를 다시 판정하지 않습니다. | 무료배송 |
| 최종 주문금액 기준 | 최대 할인 적용 후 상품 금액. 할인이 바뀌면 배송비를 다시 판정합니다. | 배송비 청구 |

- 적립금, 예치금, 주문서 단계 혜택은 판정 금액에 반영하지 않습니다.

#### 4.12.3 배송비 유형별 처리

| 유형 | 처리 |
| --- | --- |
| 무료 | 0원을 적용합니다. |
| 착불 | 결제 금액에 포함하지 않으므로 배송비와 최종 결제 금액에 더하지 않습니다. |
| 고정 | 설정한 배송비를 적용합니다. |
| 조건 | 주문금액 조건 충족 여부를 4.12.2 기준으로 판정해 적용합니다. |
| 금액별 차등 | 주문금액 구간을 4.12.2 기준으로 판정해 적용합니다. |
| 무게별 차등 | 수량과 상품 무게 기준으로 적용합니다. 할인으로 무게가 바뀌지 않으므로 무게 구간을 다시 판정하지 않습니다. 주문금액 조건이 함께 있으면 4.12.2를 따릅니다. |

#### 4.12.4 당일배송

- 당일배송 가능 여부는 배송지, 요일, 시간에 따라 정해지므로 장바구니에서는 일반배송 기준 금액을 보여 줍니다.
- 당일배송 상품의 상품 할인·쿠폰 할인은 계산에 포함하고, 당일배송 배송비만 제외합니다. 당일배송 배송비는 주문서에서 고객이 당일배송을 선택한 뒤 반영합니다.

관련 정책: POL-047, POL-048, POL-049, POL-050, POL-051

### 4.13 처리 흐름

```
장바구니 진입
 └ 탭 판정
    ├ 정기배송 탭 → 현행 결제 정보 유지(할인 영역·토글·쿠폰 버튼 없음)
    └ 일반구매 탭
       ├ 담긴 상품 없음 → 빈 장바구니 안내, 결제 정보 0원
       └ 담긴 상품 있음
          ├ 총 상품 금액 = 선택 상품 금액 + 배송비
          ├ 적용 가능한 할인 판정
          │   ├ 0건 → 토글 비활성화, 총 할인 금액 영역 미노출
          │   └ 1건 이상 → 토글 ON(기본값)
          │        └ 상품 할인 → 중복 가능 상품 쿠폰 → 중복 가능 장바구니 쿠폰 자동 적용
          ├ 총 할인 금액·하위 항목 노출 판정
          └ 최종 결제 금액 = 총 상품 금액 − 총 할인 금액(최소 0원)
 └ 고객 동작(수량·체크·옵션·쿠폰·토글) → 즉시 다시 계산
```

### 4.14 오류 및 예외 처리

장바구니 금액 계산·쿠폰 적용 중 생기는 예외 상황의 처리입니다.

| 예외 상황 | 처리 |
| --- | --- |
| 쿠폰 적용 후 사용 조건 미충족(수량 감소, 상품 체크 해제 등) | 해당 쿠폰을 자동으로 해제하고 다시 계산합니다. |
| 쿠폰 사용 결제를 허용하지 않은 상품 | 토글이 ON이어도 해당 상품에는 쿠폰 할인을 계산하지 않습니다. |
| 총 할인 금액이 총 상품 금액보다 큼 | 최종 결제 금액을 0원으로 노출합니다. |
| 담긴 상품 없음, 모든 상품 체크 해제 | 결제 정보 금액을 0원으로 노출하고, 총 할인 금액 영역은 노출하지 않으며 토글은 비활성화합니다. |
| 적용 가능한 쿠폰 0건에서 쿠폰 버튼 클릭 | 쿠폰 선택 모달을 열고 선택할 쿠폰이 없는 상태로 노출합니다. |
| 장바구니와 주문서 금액 차이 | 지역별 추가 배송비, 당일배송 배송비, 주문 할인, 적립금은 주문서에서 반영하므로 금액이 달라질 수 있습니다. 결제 정보 아래 "지역별 배송정책에 따라 배송비가 변동될 수 있습니다." 안내를 유지합니다. |

## 5. 고객 영향 및 안내

이번 개선으로 고객과 상점 운영자에게 생기는 변화입니다.

| 대상 | 내용 |
| --- | --- |
| 쇼핑몰 구매자 | 장바구니에서 상품 할인, 상품 쿠폰, 장바구니 쿠폰 할인과 최종 결제 금액을 확인할 수 있습니다. |
| 쇼핑몰 구매자 | 장바구니에 들어가면 보유한 중복 사용 가능 쿠폰이 최대 할인 조합으로 자동 적용됩니다. 원하지 않으면 최대 할인 적용을 끄거나 쿠폰을 직접 고를 수 있습니다. |
| 쇼핑몰 구매자 | 중복 사용 불가 쿠폰은 자동 적용되지 않으므로 직접 선택해야 합니다. |
| 쇼핑몰 구매자 | 주문 할인, 적립금, 지역별 추가 배송비는 주문서에서 반영되어 최종 금액이 장바구니와 다를 수 있습니다. |
| 쇼핑몰 구매자 | 정기배송 탭은 변경이 없습니다. |
| 상점 운영자 | 기본 스킨을 사용하면 별도 작업 없이 할인 영역이 노출됩니다. 개별디자인 상점은 제공되는 가상태그를 넣어야 노출됩니다. |
| 상점 운영자 | 부가세, 추가 배송비, 그룹 할인, 세트 할인은 각각 상품 금액, 배송비, 상품 할인, 판매가에 포함되어 있습니다. 별도 노출이 필요하면 개별디자인으로 하위 줄을 추가합니다. |

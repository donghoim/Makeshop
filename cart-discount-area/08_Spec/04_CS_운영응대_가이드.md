# [CS 운영·응대 가이드] 원본 요청 장바구니 결제 정보 할인 노출

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
|---|---|
| 변경 목적 | 고객이 장바구니에서 받을 할인과 결제 예정 금액을 주문서 전에 확인할 수 있게 합니다. |
| 적용 대상 | VER3 UTF-8 스마트 쿠폰 상점의 장바구니 일반구매 탭(기본 스킨 4종, 가상태그를 넣은 개별디자인 스킨) |
| 적용 시점 | 11월 정기 배포(일정 확정 전) |
| 고객 영향 | 장바구니 결제 정보에 할인 항목, 최대 할인 적용 토글, 쿠폰 선택 버튼이 생깁니다. |
| 기존 고객 처리 | 별도 처리 없음. 정기배송 탭과 주문서는 그대로입니다. |
| 상담 핵심 포인트 | 장바구니 금액은 예상 금액이며, 주문 할인·적립금·지역별 추가 배송비는 주문서에서 반영됩니다. |

## 10. 공지 및 운영 준비

- 고객 공지 필요 여부와 시점: 상점 운영자 대상 업그레이드 노트(배포 시)
- 도움말·매뉴얼 수정: 개별디자인 TIP에 할인 영역 가상태그 추가(OPEN-002)
- 상담 도구·관리자 조회 기능: 추가 없음
- 장애·대량 문의 발생 시 공지 기준: 금액 불일치 문의가 반복되면 개발 이관 후 공지 여부 결정
- 알려진 제한사항과 임시 우회 방법: 지역별 추가 배송비·주문 할인·적립금은 장바구니에 반영되지 않습니다.

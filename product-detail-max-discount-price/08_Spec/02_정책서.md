## 2. 변경 사항 요약

선배포 기능과 비교해 전체 배포에서 무엇이 바뀌는지 요약합니다.

### 2.1 한 줄 요약

최대할인가를 지원 버전 전체 상점에 공개하면서, 화면에서 선택된 할인만 금액에 반영하고, 쿠폰은 일반 기간 기준으로 노출하며, 결제수단별 프로모션과 보유 적립금을 고객이 고를 수 있게 합니다.

### 2.2 변경 목적

- 화면에 보이는 할인 내역과 최대할인가 금액이 항상 맞게 합니다.
- 대형 운영 상점에 맞춘 쿠폰 노출 조건을 일반 상점 기준으로 되돌립니다.
- 고객이 실제로 쓸 결제수단과 적립금 사용 여부에 맞는 예상 가격을 볼 수 있게 합니다.

### 2.3 변경 전·후

| 구분 | 변경 전(선배포) | 변경 후 |
| --- | --- | --- |
| 제공 상점 | 대형 운영 상점·운영 상점 | 지원 버전을 쓰고 가상태그를 넣은 모든 상점 |
| 최대할인가 금액 | 서버에서 모든 할인을 더함. 디자인에서 영역을 지워도 금액에 남음 | 화면에 있는 체크박스 중 선택된 할인만 더함. 지운 영역은 빠짐 |
| 쿠폰 노출 | 대형 운영 상점는 노출기간을 보지 않음 | 발급·노출·사용기간을 모두 봄(대형 운영 상점만 기존 유지) |
| 공급자용 쿠폰 | 제외 | 해당 공급자 상품에 노출 |
| 결제수단별 프로모션 | 없음 | 진행 중인 할인 프로모션 노출, 최대 1건 기본 선택, 1개만 선택·해제 가능 |
| 보유 적립금 | 항상 선택, 해제 불가 | 진입 시 선택, 고객이 해제·선택 가능 |

## 3. 적용 대상 및 범위

이번 정책을 적용하는 상점·화면과 이번에 다루지 않는 범위입니다.

### 적용 대상

- 주문 2.0, 통합옵션, 디자인 D4·반응형, 모바일 4.0·파워팩, 고급형 주문서, 스마트쿠폰을 모두 쓰는 상점
- 상품 상세 페이지에 최대할인가 가상태그를 넣은 디자인
- PC, 모바일 웹, 파워앱

### 포함 범위

- 최대할인가 요약과 할인 영역 9개: 상품 할인, 상품 추가 할인, 상품 쿠폰, 장바구니 쿠폰, 적립금 즉시 할인, 회원 등급 할인, 앱 전용 할인, 보유 적립금, 결제수단별 프로모션
- 화면 체크 기준 금액 계산
- 기본 스킨(반응형·베이직심플·모던심플·모바일 4.0)의 결제수단 영역과 디자인 가이드 안내

### 제외 및 예외 범위

- 옵션 추가금액과 선택 수량은 반영하지 않습니다. 단일 상품 1개 기준입니다.
- 세트상품, 배송비 쿠폰, 적립형 결제수단 프로모션은 제공하지 않습니다.
- 할인 유형별 사용 여부를 관리자에서 설정하는 기능은 제공하지 않습니다. 상점은 디자인에서 영역을 지워 조정합니다.
- 특정 회원 그룹 쿠폰은 비회원에게 보이지 않습니다.
- 쿠폰 일괄 다운로드와 쿠폰 노출기간 미검증은 대형 운영 상점에만 적용합니다.
- 상세에서 고른 쿠폰·적립금·결제수단은 주문서로 넘어가지 않습니다. 주문서에서 다시 고릅니다.

### 이용 조건

- 상점이 디자인 편집에서 상품 상세 페이지에 최대할인가 소스를 넣어야 합니다.
- 스마트쿠폰을 사용해야 합니다.

## 4. 상세 정책

### 4.1 섹션 노출

상품 상세에서 최대할인가 섹션을 보여 줄지 정하는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 노출 | 적용 대상 버전을 모두 쓰고 가상태그가 있으면 판매가 아래에 최대할인가 요약이 보입니다. |
| 상세 내역 | 진입 시에는 접혀 있고, 자세히보기를 누르면 할인 영역별 내역이 펼쳐집니다. |
| 스마트쿠폰 미사용 | 가상태그가 있어도 섹션이 보이지 않습니다. |
| 가격 대체 문구 상품 | 섹션이 보이지 않습니다(0원으로 표시하지 않습니다). |
| 세트상품 | 섹션이 보이지 않습니다. |
| 묶음상품 | 최종판매가를 기준으로 계산하고 묶음 수량은 반영하지 않습니다. |
| 계산 단위 | 단일 상품 1개 기준이며 옵션 추가금액과 선택 수량은 반영하지 않습니다. |

관련 정책: POL-001, POL-002, POL-003, POL-004, POL-005, POL-006, POL-008

### 4.2 최대할인가 금액 계산

화면에 있는 할인 중 선택된 것만 금액에 반영하는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 반영 대상 | 상세 내역에 있는 할인 체크박스 중 선택된 할인만 반영합니다. 자동으로 적용되는 할인(상품 할인, 상품 추가 할인, 적립금 즉시 할인, 회원 등급 할인, 앱 전용 할인)은 선택된 상태로 고정된 체크박스로 반영합니다. |
| 지운 영역 | 상점이 디자인에서 할인 영역을 지워 체크박스가 없으면 그 할인은 반영하지 않습니다. |
| 접힌 내역 | 자세히보기로 펼치지 않아도 화면에 있는 영역이므로 반영합니다. |
| 상세 내역을 모두 지운 경우 | 반영할 할인이 없으므로 최대할인가는 판매가와 같습니다. |
| 진입 시 금액 | 기본 선택을 적용한 뒤의 화면 체크 상태로 계산한 금액을 보여 줍니다. |
| 계산 순서 | 상품 할인 → 상품 추가 할인 → 상품 쿠폰 → 장바구니 쿠폰 → 적립금 즉시 할인 → 회원 등급 할인 → 앱 전용 할인 → 보유 적립금 → 결제수단별 프로모션 순으로 뺍니다. |
| 다시 계산 | 선택이 바뀌거나 영역이 없으면, 그 뒤 순서의 할인은 바뀐 금액을 기준으로 다시 계산합니다. 예를 들어 쿠폰 영역이 없으면 쿠폰을 자동으로 고르지 않고, 쿠폰·적립금 동시 사용 제한도 적용하지 않습니다. |
| 0원 이하 | 계산 결과가 0원 이하면 0원으로 표시하고, 그 뒤 할인의 차감금액은 0원 또는 미표시합니다. 보유 적립금 금액은 계속 표시합니다. |
| 복제 영역 | 개별디자인에서 선택 항목을 다른 곳에 복제해 보여 주는 영역은 계산에 넣지 않습니다. |

관련 정책: POL-007, POL-009, POL-010, POL-011, POL-012, POL-013, POL-014

### 4.3 회원·비회원별 노출 영역

로그인 여부에 따라 보이는 할인 영역입니다.

| 구분 | 보이는 영역 | 보이지 않는 영역 |
| --- | --- | --- |
| 비회원 | 상품 할인, 상품 쿠폰, 장바구니 쿠폰, 보유 적립금(0원), 비회원 대상 결제수단 프로모션 | 상품 추가 할인, 회원 등급 할인, 적립금 즉시 할인 |
| 회원 | 모든 영역 | 각 영역의 설정·조건을 충족하지 않는 영역 |

- 상품 추가 할인은 상품별 그룹할인 구매 권한이 '비회원에게도 할인가격 노출'이어도 비회원에게 보이지 않습니다. 비회원은 회원 그룹에 속하지 않기 때문입니다.

관련 정책: POL-015, POL-021

### 4.4 자동 적용 할인

고객이 고르지 않아도 조건을 충족하면 적용되는 할인입니다. 고객이 해제할 수 없습니다.

| 영역 | 노출 조건 | 계산 |
| --- | --- | --- |
| 상품 할인 | 리바이·기간·신상품 할인 중 우선순위(리바이 > 기간 > 신상품)가 가장 높은 1건. 비회원에게는 상품 가격 노출 설정이 '비회원에게도 할인가격 노출(상품상세 포함)'일 때만 보입니다. | 판매가 × 할인율, 또는 할인 금액 |
| 대량 구매 할인 | 적용된 상품이면 상품 할인 영역에 항상 보입니다. | 최대할인가에 반영하지 않습니다. |
| 상품 추가 할인 | 상품별 그룹할인이 설정되어 있고 해당 그룹 회원이며, 도매회원 그룹이 아니고, 상품 할인에서 '상품 그룹 혜택 적용 제외'가 아닐 때 | (판매가 - 상품 할인) × 그룹 할인율, 또는 할인 금액 |
| 적립금 즉시 할인 | 적립금 즉시할인을 쓰고, 신규 적립 기준이 '무조건 적립' 또는 'N원 이상 사용 시 적립 안 함'일 때 | (판매가 - 상품 할인 - 상품 추가 할인 - 상품 쿠폰) × 지급률, 또는 지급 금액 |
| 회원 등급 할인 | 회원 그룹의 결제 조건에 따른 혜택이 추가 할인일 때. 추가 적립, 혜택 없음, 구매 불가 그룹은 보이지 않습니다. | 결제금액 조건은 상품 할인·상품 추가 할인을 뺀 금액으로 판단합니다. N원 할인은 N원, N% 할인은 (상품 할인·상품 추가 할인·상품 쿠폰을 뺀 금액) × N% |
| 앱 전용 할인 | 파워앱으로 들어왔고 앱 주문 추가 혜택이 할인일 때. 상품 할인 영역과 따로 표시합니다. 추가 적립·미지급 설정, 앱에서 PC 모드로 바꾼 경우, '파워앱 할인/적립 제외' 상품은 보이지 않습니다. | 500원 할인은 500원. 결제금액 N원 이상 N% 할인은 상품 판매가로 조건을 비교하고, (상품 할인·상품 쿠폰을 뺀 금액) × N%(그룹 할인 제외) |

- 앱 전용 할인은 상세에서 상품 판매가로 조건을 보기 때문에, 주문서에서는 결제금액에 따라 적용되지 않을 수 있습니다.

관련 정책: POL-016, POL-017, POL-018, POL-019, POL-020, POL-038, POL-039, POL-040, POL-041, POL-042, POL-043

### 4.5 쿠폰 노출

상품 쿠폰·상품 중복 쿠폰·장바구니 쿠폰·장바구니 중복 쿠폰을 보여 주는 기준입니다. 자동·수동·다운로드 발급 쿠폰에 모두 적용합니다.

| 구분 | 정책 |
| --- | --- |
| 노출 대상 | 접속 기기가 쿠폰 사용 범위(PC·모바일·파워앱)에 들고, 혜택이 할인인 쿠폰. 배송비 쿠폰과 적립 쿠폰은 보이지 않습니다. |
| 노출기간 | 노출기간이 진행 중이 아니면(시작 전·종료) 다른 조건과 관계없이 보이지 않습니다. |
| 사용기간 | 사용기간이 시작 전이거나 끝났으면 보이지 않습니다. |
| 발급기간 | 진행 중이면 보입니다. 시작 전이면 보이지 않습니다. 끝났으면 쿠폰을 가진 회원에게만 보입니다. |
| 사용 완료 | 이미 쓴 쿠폰은 보이지 않습니다. |
| 발급 방식 | 자동·수동 발급 쿠폰은 가진 회원에게만 보입니다. 다운로드 쿠폰은 가지지 않은 회원과 비회원에게도 보입니다. |
| 사용 가능 회원 등급 | 전체 회원이면 모두에게, 특정 그룹이면 그 그룹 회원에게만 보입니다. |
| 공급자용 쿠폰 | 쿠폰을 만든 공급자의 상품에서만 보입니다. |
| 쿠폰 제한 상품 | '쿠폰 사용 결제 불가' 상품은 쿠폰 영역 2개가 모두 보이지 않습니다. '쿠폰 적용 예외'로 지정한 쿠폰은 그 쿠폰만 보이지 않습니다. |
| 사용 조건 | 쿠폰에 금액 등 사용 조건이 있어도 보이고 계산에 넣으며, 사용 조건 안내 문구를 함께 표시합니다. |
| 정렬 | 단일 쿠폰 다음에 중복 쿠폰을 보여 줍니다. 같은 종류 안에서는 차감액이 큰 순, 같으면 유효기간이 빠른 순입니다. |
| 표시 | 쿠폰명, 차감금액, 중복 불가 라벨, 가진 쿠폰은 발급완료, 가지지 않은 다운로드 쿠폰은 받기 |

### 4.6 쿠폰 선택과 받기

쿠폰을 고르고 내려받을 때의 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 자동 선택 | 진입 시 상품 쿠폰 영역과 장바구니 쿠폰 영역에서 각각 차감액이 가장 큰 단일 쿠폰 1건을 고릅니다. 중복 쿠폰은 자동으로 고르지 않습니다. |
| 선택 조합 | 단일 쿠폰은 영역마다 1개, 중복 쿠폰은 여러 개 고를 수 있습니다. |
| 중복 불가 쿠폰 | 고르면 같은 영역의 다른 쿠폰을 고를 수 없게 되고, 해제하면 다시 고를 수 있습니다. |
| 계산 | 상품 쿠폰은 (판매가 - 상품 할인 - 상품 추가 할인)에, 장바구니 쿠폰은 상품 쿠폰까지 뺀 금액에 적용합니다. 같은 영역의 쿠폰은 같은 기준 금액에 적용합니다. |
| 받기 | 비회원이 누르면 로그인 화면으로 이동합니다. 접속 기기가 발급 범위 밖이면 '해당 쿠폰은 (모바일 웹, 앱)에서 다운이 가능합니다.' 알림을 띄웁니다. 발급되면 발급완료로 바뀌고 금액을 다시 계산합니다. |
| 적립금 미지급 쿠폰 | '쿠폰 사용 시 적립금 지급 불가' 쿠폰을 고르면 적립금 즉시 할인이 0원으로 바뀌고 비활성화됩니다. 해제하면 다시 반영합니다. |

관련 정책: POL-033, POL-034, POL-035, POL-036, POL-037

### 4.7 보유 적립금

회원이 가진 적립금을 최대할인가에 넣을지 고객이 정하는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 노출 | 적립금을 쓸 수 있는 상품이면 회원·비회원 모두에게 보입니다. 비회원과 보유 0원 회원은 0원으로 보입니다. '적립금 사용 결제 불가' 상품, 회원 그룹이 '적립금 적립+사용 불가'면 보이지 않습니다. |
| 사용 금액 | 1회 최대 사용 한도에 따릅니다. 한도가 없으면 보유 전액, 최대 N원이면 보유액과 N원 중 작은 값, 상품 구매액 N%면 (판매가 - 상품 할인 - 상품 추가 할인 - 상품 쿠폰) × N%와 보유액 중 작은 값입니다. 그룹별 제한이면 그룹 설정을 따릅니다. 100원 단위는 버립니다. |
| 진입 시 | 쓸 수 있으면 선택된 상태로 반영합니다. |
| 고객 해제·선택 | 해제하면 금액에서 빼고, 다시 선택하면 반영합니다. 바로 다시 계산합니다. |
| 쿠폰 변경 | 쿠폰을 바꿔도 체크 상태는 바꾸지 않고 사용 금액만 다시 계산합니다. 고객이 해제했으면 해제 상태가 유지됩니다. |
| 동시 사용 불가 쿠폰 선택 | 쿠폰·적립금 동시 사용 불가 쿠폰을 고르면 적립금 선택을 해제하고 비활성화합니다. 보유 금액과 안내 문구는 표시합니다. |
| 동시 사용 불가 쿠폰 해제 | 체크박스를 다시 활성화하고, 그 쿠폰을 고르기 직전에 고객이 정해 둔 상태로 돌려놓습니다. |
| 사용 조건 미충족 | 보유 0원, 보유 금액 조건 미충족, 구매 금액 조건 미충족, 그룹별 사용 제한이면 보유 금액을 연한 색으로 보여 주고 체크박스는 해제·비활성화하며 금액에 반영하지 않습니다. |
| 최초 구매 사용 불가 | 상세에서는 구매 이력을 보지 않고 반영합니다. 주문서에서 다시 판단하므로 다를 수 있습니다. |

관련 정책: POL-044, POL-045, POL-046, POL-047, POL-048, POL-049, POL-050, POL-051, POL-052

### 4.8 결제수단별 프로모션

특정 결제수단으로 결제할 때 받는 할인을 보여 주고 고르는 기준입니다.

| 구분 | 정책 |
| --- | --- |
| 노출 | 현재 진행 중인 프로모션을 최대 10개까지 보여 줍니다. 없으면 영역이 보이지 않습니다. |
| 혜택 방식 | 할인은 보이고, 적립은 보이지 않습니다. 할인+적립은 할인 부분만 보입니다. |
| 적용 대상 | 회원 대상이면 회원에게만, 회원+비회원이면 모두에게 보입니다. |
| 정렬 | 진입 시 차감액이 큰 순, 같으면 등록 순입니다. 이후 쿠폰·적립금 선택이 바뀌어 차감액이 달라져도 순서와 고객 선택은 그대로 둡니다. |
| 기본 선택 | 차감액이 가장 큰 1건을 고릅니다. |
| 선택 | 1개만 고를 수 있습니다. 다른 프로모션을 고르면 기존 선택이 해제되고, 고른 것을 해제하면 결제수단 할인 없이 계산합니다. |
| 계산 | 주문서에서 결제수단 프로모션을 계산하는 기준 금액과 같은 금액에 할인율을 곱하거나 할인 금액을 뺍니다. 적용 구간 조건(N원 이상)도 같은 금액으로 판단하고, 충족하지 않는 프로모션은 보이지 않습니다. |
| 표시 | 프로모션명, 차감금액 |

관련 정책: POL-053, POL-054, POL-055, POL-056, POL-057, POL-058

## 5. 고객 영향 및 안내

### 고객이 반드시 알아야 할 내용

- 최대할인가는 상품 1개를 살 때의 예상 가격이며, 옵션 추가금액·수량·주문서 조건에 따라 실제 결제 금액과 다를 수 있습니다.
- 상점이 디자인에서 지운 할인 영역은 최대할인가에도 반영되지 않습니다.
- 상세에서 고른 쿠폰·적립금·결제수단은 주문서에 자동으로 적용되지 않습니다.

### 고객 영향

| 대상 | 영향 |
| --- | --- |
| 구매자 | 받을 수 있는 할인을 상세에서 확인하고, 쿠폰·보유 적립금·결제수단을 골라 예상 가격을 볼 수 있습니다. |
| 쇼핑몰 운영자 | 가상태그를 넣으면 기능을 쓸 수 있고, 필요 없는 할인 영역은 디자인에서 지워 금액에서도 뺄 수 있습니다. |
| 선배포 상점 | 디자인에서 영역을 지운 경우 배포 후 최대할인가가 달라집니다. 보유 적립금을 고객이 해제할 수 있게 되고 결제수단 영역이 추가됩니다. |
| 저장 데이터 | 바뀌는 저장 데이터가 없습니다. |

### 안내 방식

- 업그레이드 노트와 매뉴얼로 안내합니다.
- 최대할인가 노출 가이드와 개별디자인 Tip에 "영역을 지우면 그 할인이 금액에서 빠지고, 상세 내역을 모두 지우면 판매가와 같게 보인다"는 내용을 넣습니다.

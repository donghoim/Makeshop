## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 작성 목적 | 대형 운영 상점·운영 상점에 선배포된 상품 상세 최대할인가를 전체 상점에 제공하기 위해, 재사용할 기능과 바뀌는 정책(쿠폰 노출 기간, 결제수단별 프로모션, 보유 적립금 선택, 화면 체크 기준 합산)을 개발·QA·운영 기준으로 정의합니다. |

## 2. 배경과 문제

| 항목 | 내용 |
|---|---|
| 배경 | 상품 상세에는 상품 할인만 반영된 가격이 보이고, 쿠폰·회원 등급·적립금·앱·결제수단 혜택은 고객이 직접 따져야 합니다. 29CM의 "나의 구매 가능 가격"처럼 적용 가능한 할인 목록과 예상 최저가를 상세에서 보여 주기 위해 2026-03-25 대형 운영 상점, 이후 운영 상점에 선배포했습니다. |
| 해결할 문제 | ① 쿠폰 노출 조건이 대형 운영 상점 요청(노출기간 미검증)에 맞춰져 있어 일반 상점 기준과 다릅니다. ② 결제수단별 프로모션이 최대할인가에 연결되어 있지 않습니다. ③ 보유 적립금이 항상 선택·비활성이라 고객이 적립금을 쓰지 않는 가격을 볼 수 없습니다(관련 Task). ④ 최대할인가 가상태그가 서버에서 모든 할인을 합산해, 상점이 개별디자인에서 영역을 지워도 그 할인이 금액에 남습니다. 화면에 보이는 내역과 금액이 맞지 않습니다. |
| 사용자·운영 영향 | 고객은 내역에 없는 할인이 포함된 가격을 보고, 주문서 금액과 비교하며 혼란을 겪습니다. 상점은 원하지 않는 할인 영역을 끌 방법이 없어 CS 문의가 생깁니다. |
| 확인 근거 | 원본 요청 본문·댓글(2026-11-06 개발 리드 범위 요청), 관련 Task 댓글(2026-04-01, 2026-04-14), 관련 Task, 오픈프로젝트 이력, 분석서 SRC-001부터 SRC-008까지, 기획/정책 Figma v0.2·최신 작업 섹션·배포준비, 2026-11-06 기획 결정 |

## 3. 목표와 범위

### 3.1 목표

- 지원 버전 전체 상점이 가상태그를 넣으면 최대할인가 섹션을 쓸 수 있게 합니다.
- 고객이 화면에서 선택한 할인만으로 최대할인가를 계산해, 보이는 내역과 금액이 항상 맞게 합니다.
- 쿠폰은 일반 기간 기준으로, 결제수단 혜택과 보유 적립금은 고객이 고를 수 있게 제공합니다.

### 3.2 포함 범위

- 최대할인가 섹션과 할인 영역 9개(상품 할인, 상품 추가 할인, 상품 쿠폰, 장바구니 쿠폰, 적립금 즉시 할인, 회원 등급 할인, 앱 전용 할인, 보유 적립금, 결제수단별 프로모션)
- 쿠폰 노출 기간 조건 일반화, 공급자용 쿠폰 포함
- 결제수단별 프로모션 영역 신규 연결
- 보유 적립금 고객 선택·해제
- 화면 체크박스 기준 합산(진입 시 금액 포함)
- 기본 스킨 결제수단 영역 마크업, 최대할인가 노출 가이드·개별디자인 Tip 갱신

### 3.3 제외 범위

- 옵션 추가금액, 선택 수량 N개 반영(단일 상품 1개 기준 유지)
- 세트상품, 배송비 쿠폰, 적립형 결제수단 프로모션
- 할인 유형별 사용 여부·자동 선택·특정 쿠폰 제외 등 관리자 설정(Figma 고도화시 페이지, 다음 단계)
- 특정 그룹 쿠폰의 비회원 노출
- 쿠폰 일괄 다운로드·노출기간 미검증의 공통 확대(대형 운영 상점 특별처리 유지)
- 선택한 할인을 섹션 상단에 다시 모아 보여 주는 요약 영역(대형 운영 상점 퍼블 전용)

# [와이어프레임 초안] 원본 요청 상품 상세 최대할인가 전체 배포

## 2. 화면별 구조

아래 이미지는 목업 화면 캡처입니다. 번호 표시와 번호별 설명은 화면정의서에 있습니다.

### WF-001 최대할인가 요약

- 목적: 이 상품을 살 때 받을 수 있는 예상 최저가를 판매가 아래에서 바로 보여 줍니다.
- 진입점·이전 화면: 상품 상세 진입
- 관련 요구사항·정책: REQ-001, REQ-006, FR-001, FR-011, POL-001부터 POL-014까지

**기본 화면(상세 접힘)**

![기본 화면(상세 접힘)](../03_Wireframe/wf-1-1.png)

- 금액은 상세 내역에서 선택된 할인만 더한 결과이며, 접혀 있어도 반영합니다(POL-011, POL-013).

**상세 내역을 모두 지운 경우**

![상세 내역을 모두 지운 경우](../03_Wireframe/wf-3-3.png)

- 자세히보기가 없고 최대할인가는 판매가와 같습니다(POL-012).

**가격 대체 문구 상품**

![가격 대체 문구 상품](../03_Wireframe/wf-4-3.png)

- 최대할인가 섹션이 보이지 않습니다(POL-003).

### WF-002 최대할인가 상세 내역

- 목적: 할인 영역별 내역을 보여 주고, 쿠폰·보유 적립금·결제수단을 고르게 합니다.
- 진입점·이전 화면: WF-001 자세히보기
- 관련 요구사항·정책: REQ-002부터 REQ-006까지, FR-002부터 FR-010까지, POL-015부터 POL-058까지

**회원 · 상세 펼침**

![회원 · 상세 펼침](../03_Wireframe/wf-1-2.png)

- 영역 순서는 선배포 화면과 같습니다: 상품 할인 → 상품 추가 할인 → 상품 쿠폰 → 장바구니 쿠폰 → 회원 등급 할인 → (앱 전용 할인) → 적립금 사용 → 적립금 즉시 할인 → 결제수단별 프로모션. 금액 계산 순서는 POL-014를 따릅니다. 자동 적용 할인은 연한 체크(해제 불가), 고객이 고르는 쿠폰·보유 적립금·결제수단은 파란 체크입니다.

**중복 불가 쿠폰 선택**

![중복 불가 쿠폰 선택](../03_Wireframe/wf-1-4.png)

- 같은 영역의 다른 쿠폰이 비활성화됩니다(POL-034).

**비회원**

![비회원](../03_Wireframe/wf-2-1.png)

- 상품 추가 할인·회원 등급 할인·적립금 즉시 할인이 없고, 보유 적립금은 0원·비활성입니다(POL-015).

**파워앱**

![파워앱](../03_Wireframe/wf-1-15.png)

- 앱 전용 할인이 별도 영역으로 보입니다(POL-042).

**개별디자인에서 적립금 사용 영역을 지운 경우**

![개별디자인에서 적립금 사용 영역을 지운 경우](../03_Wireframe/wf-3-1.png)

- 적립금 사용 금액이 최대할인가에 들어가지 않습니다(POL-010).

**모바일**

![모바일](../03_Wireframe/wf-4-4.png)

- 행 구성은 PC와 같고, 긴 이름은 줄바꿈합니다.

### WF-003 결제수단별 프로모션 영역

- 목적: 결제수단별 할인을 보여 주고 1개를 고르게 합니다.
- 진입점·이전 화면: WF-002 마지막 영역
- 관련 요구사항·정책: REQ-004, FR-010, POL-053부터 POL-058까지

**결제수단 변경**

![결제수단 변경](../03_Wireframe/wf-1-12.png)

- 진입 시 차감액이 가장 큰 1건이 선택되고, 다른 건을 고르면 기존 선택이 해제됩니다. 고른 것을 다시 누르면 선택 없음이 됩니다(POL-056, POL-057).

### WF-004 보유 적립금 행

- 목적: 보유 적립금을 최대할인가에 넣을지 고객이 고르게 합니다.
- 진입점·이전 화면: WF-002
- 관련 요구사항·정책: REQ-005, FR-009, POL-044부터 POL-052까지

**보유 적립금 해제**

![보유 적립금 해제](../03_Wireframe/wf-1-7.png)

- 진입 시 선택되어 있고 고객이 해제할 수 있습니다(POL-046, POL-047).

**적립금 동시 사용 불가 쿠폰 선택**

![적립금 동시 사용 불가 쿠폰 선택](../03_Wireframe/wf-1-9.png)

- 보유 적립금이 해제·비활성화되고 안내 문구가 보입니다. 쿠폰을 해제하면 직전 상태로 돌아옵니다(POL-049, POL-050).

**적립금 사용 조건 미충족**

![적립금 사용 조건 미충족](../03_Wireframe/wf-1-11.png)

- 보유 금액이 연한 색으로 보이고 선택할 수 없습니다(POL-051).

## 7. 반응형·접근성·콘텐츠 주석

- PC·모바일 차이: 행 구성은 같고, 모바일은 할인명이 길면 줄바꿈하며 금액·버튼이 다음 줄로 넘어가지 않게 합니다(선배포 반응형 처리 유지).
- 키보드·초점 순서: 자세히보기 → 영역 순서대로 체크박스 → 받기 버튼 순입니다.
- 오류와 필수값 전달 방식: 입력값이 없어 필수값 오류는 없습니다. 쿠폰 받기 실패는 알림으로 알립니다.
- 긴 문구·다국어 대응: 쿠폰명·프로모션명이 길면 줄바꿈합니다. 다국어는 해당하지 않습니다.
- 법적 고지·동의 노출: 해당 없음.

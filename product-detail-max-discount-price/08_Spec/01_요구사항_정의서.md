# [요구사항 정의서] 원본 요청 상품 상세 최대할인가 전체 배포

## 1. 문서 목적

대형 운영 상점·운영 상점에 먼저 제공한 상품 상세 최대할인가를 전체 상점에 제공하면서 무엇이 바뀌어야 하는지 정리합니다. 상세 정책은 정책서, 기능·수용 조건은 사양 정의서에서 관리합니다.

## 2. 요청 배경 및 목표

### 2.1. 요청 배경

- 상품 상세에는 상품 할인만 반영된 가격이 보입니다. 쿠폰·회원 등급·적립금·앱·결제수단 혜택까지 받으면 얼마에 살 수 있는지는 고객이 직접 계산해야 합니다.
- 29CM의 "나의 구매 가능 가격"처럼, 상품 상세에서 받을 수 있는 할인 목록과 예상 최저가를 보여 주는 기능을 대형 운영 상점 요청으로 만들어 2026-03-25 선배포했습니다(오픈프로젝트 이력).
- 선배포 기능은 대형 운영 상점 요청에 맞춘 부분이 있어, 전체 상점에 공개하려면 일반 기준으로 바꾸고 빠진 기능을 채워야 합니다.
- 선배포 상점에서 보유 적립금을 고객이 직접 빼 볼 수 있게 해 달라는 요청이 이어졌습니다(관련 Task).

### 2.2. 고객과 상점이 필요한 결과

- 고객은 이 상품을 살 때 받을 수 있는 할인을 한눈에 보고, 원하는 할인만 골라 예상 가격을 확인할 수 있어야 합니다.
- 화면에 보이는 할인 내역과 최대할인가 금액이 항상 맞아야 합니다.
- 상점은 필요 없는 할인 영역을 디자인에서 지우면 그 할인이 금액에서도 빠져야 합니다.

## 3. 현행 기능 및 해결 과제

### 3.1. 현행 동작(선배포)

| 기능 | 현행 동작 |
|---|---|
| 쿠폰 노출 | 대형 운영 상점는 쿠폰 노출기간을 보지 않고, 발급·사용기간과 보유·사용 여부로만 노출합니다. |
| 결제수단별 프로모션 | 최대할인가에 나오지 않습니다. |
| 보유 적립금 | 항상 선택된 상태로 고정되어 고객이 뺄 수 없습니다. |
| 최대할인가 금액 | 서버에서 모든 할인을 더해 계산합니다. 상점이 디자인에서 영역을 지워도 그 할인이 금액에 남습니다. |

### 3.2. 문제 예시

| 순서 | 상황 | 현행 결과 | 영향 |
|---|---|---|---|
| 1 | 상점이 디자인에서 보유 적립금 영역을 지움 | 화면에는 적립금이 없는데 최대할인가에는 적립금 5,000원이 빠져 있음 | 고객이 금액을 이해하지 못하고 문의 |
| 2 | 고객이 적립금을 쓰지 않을 생각으로 상품을 봄 | 적립금을 뺄 수 없어 적립금 사용 가격만 보임 | 실제 결제 예상 금액을 알 수 없음 |
| 3 | 상점이 현금 결제 할인 프로모션을 진행 중 | 최대할인가에 나오지 않음 | 받을 수 있는 할인을 고객이 모름 |

## 4. 요구사항

| REQ ID | 요구사항 | 필수 여부 |

| REQ-001 | 지원 버전 전체 상점의 상품 상세에 최대할인가 섹션을 제공해야 합니다. | 필수 |
| REQ-002 | 할인 영역별 노출·선택·계산 규칙은 선배포 기준을 유지해야 합니다. | 필수 |
| REQ-003 | 쿠폰은 발급·노출·사용기간을 모두 보는 일반 기준으로 노출해야 합니다. | 필수 |
| REQ-004 | 결제수단별 프로모션 할인을 최대할인가에 포함해야 합니다. | 필수 |
| REQ-005 | 고객이 보유 적립금 사용을 선택·해제할 수 있어야 합니다. | 필수 |

| REQ-007 | 예외 상품·설정을 정책대로 처리하고 기존 상품 상세·쿠폰·주문에 영향이 없어야 합니다. | 필수 |
| REQ-008 | 대형 운영 상점 특별처리는 대형 운영 상점에만 유지해야 합니다. | 필수 |

## 5. 대표 사용자 시나리오

| 시나리오 | 기대 결과 |
|---|---|
| 회원이 보유 적립금 5,000원을 가진 채 상품 상세에 들어옴 | 보유 적립금이 선택된 상태로 최대할인가에 반영됩니다. |
| 회원이 보유 적립금을 해제함 | 적립금 5,000원이 빠진 금액으로 바로 바뀝니다. |
| 회원이 적립금을 해제한 뒤 상품 쿠폰을 다른 쿠폰으로 바꿈 | 적립금은 해제된 채로 남고, 쿠폰이 바뀐 금액만 다시 계산됩니다. |
| 현금 결제 3,000원 할인과 카드 결제 2,000원 할인이 진행 중 | 두 프로모션이 보이고 3,000원 할인이 선택됩니다. 카드 할인을 고르면 현금 할인은 해제됩니다. |
| 상점이 디자인에서 보유 적립금 영역을 지움 | 최대할인가에 적립금이 반영되지 않습니다. |
| 노출기간이 끝난 쿠폰(사용기간은 남음)이 있는 일반 상점 | 쿠폰이 보이지 않습니다. 대형 운영 상점에서는 보입니다. |
| 비회원이 상품 상세에 들어옴 | 상품 할인·쿠폰·보유 적립금(0원)·대상 결제수단 할인이 보이고, 회원 그룹 할인은 보이지 않습니다. |

## 7. 완료 기준

- 지원 버전 상점이 가상태그를 넣으면 상품 상세에 최대할인가가 보이고, 지원하지 않는 조건에서는 섹션이 보이지 않습니다.
- 최대할인가 금액은 화면에 있는 체크박스 중 선택된 할인만 더한 결과이며, 상점이 지운 영역의 할인은 들어가지 않습니다.
- 노출기간·사용기간이 끝났거나 이미 쓴 쿠폰은 보이지 않습니다(대형 운영 상점 제외).
- 결제수단별 프로모션은 차감액이 가장 큰 1건이 선택되고, 1개만 고를 수 있으며 해제할 수 있습니다.
- 보유 적립금은 진입 시 선택되어 있고, 고객이 해제하면 금액에서 빠집니다. 쿠폰을 바꿔도 고객이 정한 체크 상태는 바뀌지 않습니다.
- 같은 할인을 고르면 상품 상세 금액과 주문서 결제 예정 금액이 같습니다(단일 상품 1개 기준).

화면·상태·동작·권한과 관련 정책 참조를 제공합니다. 화면 원본은 HTML 화면정의서(목업 내장)이며, 브라우저로 열면 왼쪽 목차에서 화면을 골라 볼 수 있습니다.

## 2. 화면별 구조

원본 레이아웃과 영역별 설명은 HTML 화면정의서에서 화면 번호로 확인합니다. 아래는 디자인·개발 인계를 위한 구조 요약입니다.

### WF-001 통합 현황 (1-1부터 1-3)

- 목적: 채널별 계정·상품 피드·광고 연결 상태와 채널 등록 상품 수를 한 화면에서 확인합니다.
- 진입점·이전 화면: GNB 마케팅 > 마케팅 채널 관리
- 완료 후 이동: [관리하기]·[바로가기] → 채널 홈 / [연동하기] → 채널 연결관리
- 관련 요구사항·정책: MKT-REQ-009부터 017 · FR-004, FR-005 · POL-013부터 POL-022

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 1단 탭 → 채널 연결 현황 카드(Meta·Google·TikTok) → 채널별 운영 현황 표(Meta·Google) | WF-001 |
| 노출·활성 | 카드: 로고·채널명·제공 기능·계정 연결 상태·버튼. 표: 채널 / 계정 연결 상태 / 상품 피드 연결 상태 / 광고 연결 상태 / 채널 등록 상품 수 / 관리. 합산 박스·광고 성과 없음 | POL-013, POL-017, POL-018, POL-019 |
| 안내·실패 | 상품 피드 미연결이면 채널 등록 상품 수 '-'. 외부 API를 호출하지 않고 저장값 표시 | POL-020, POL-021 |

### WF-002 통합 상품 피드 (2-1부터 2-3)

- 목적: 같은 상품의 채널별 상태를 한 행에서 비교합니다.
- 진입점·이전 화면: 1단 탭 통합 상품 피드
- 완료 후 이동: [Meta 관리 ↗]·[Google 관리 ↗] → 채널 상품피드
- 관련 요구사항·정책: MKT-REQ-018부터 025 · FR-006, FR-007 · POL-023부터 POL-029

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 검색(상품명·상품번호·연동 상태) → 목록 헤더(총 건수·개수) → 상품 목록 → 페이지네이션 | WF-002 |
| 노출·활성 | 상품정보 / Meta 상태 / Google 상태 / 관리. 상품 피드 미연동 채널은 선택 불가·'-'·버튼 미표시 | POL-024, POL-025, POL-026, POL-028 |
| 안내·실패 | 결과 없음 '조회된 상품이 없습니다.' 채널 상태는 저장값 표시 | POL-021, POL-029 |

### WF-003 Meta 탭 (3-1)

- 목적: 개발 완료된 Meta 화면을 새 메뉴에서 그대로 제공합니다.
- 진입점·이전 화면: 1단 탭 Meta, 기존 Meta 메뉴 URL
- 완료 후 이동: Meta 하위 탭
- 관련 요구사항·정책: MKT-REQ-026, 027 · FR-008 · POL-030, POL-071

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | Meta 하위 탭(홈 / 연결 관리 / 상품 피드 / 광고 관리 / Shops 관리) | 와이어프레임 초안 |
| 노출·활성 | 진입 경로·브레드크럼만 변경. GPC는 Google과 공통값 | POL-030, POL-071 |
| 안내·실패 | Meta 화면 기준을 따릅니다. | FR-008 |

### WF-004 TikTok 탭 (4-1)

- 목적: 준비 중인 채널을 안내합니다.
- 관련 요구사항·정책: MKT-REQ-040, 041 · FR-009 · POL-031

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조·노출 | 준비 중 안내 문구만 표시, 버튼·일정 안내 없음 | POL-031 |

### WF-005 Google 홈 (5-1, 5-2)

- 목적: Google 하위 기능으로 들어가는 시작 화면입니다.
- 진입점·이전 화면: 1단 탭 Google
- 완료 후 이동: 카드 버튼 → 연결관리·상품피드·구글애즈
- 관련 요구사항·정책: MKT-REQ-028부터 031 · FR-010 · POL-032, POL-033, POL-034

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 하위 탭(홈 / 연결관리 / 상품피드 / 구글애즈) → 카드 3개 | POL-032 |
| 노출·활성 | 카드별 연동 여부를 따로 판정해 [설정하기] 또는 [자세히 보기] 1개만 표시 | POL-033 |
| 안내·실패 | 연동 상태 조회 실패 시 [자세히 보기], 하위 탭에서 다시 확인 | FR-010 |

### WF-006 Google 연결관리 (6-1부터 6-12, 7-1, 7-2)

- 목적: Google 계정을 연결하고 Merchant Center·Google Ads를 각각 연결·관리합니다.
- 진입점·이전 화면: 하위 탭 연결관리, 홈·상품피드·구글애즈의 미연동 안내
- 완료 후 이동: Merchant Center 후속 설정 완료 → 카테고리 매칭 모달(7-1) 1회 자동
- 관련 요구사항·정책: MKT-REQ-032, 035, 038, 049 · FR-011부터 FR-014, FR-017, FR-018 · POL-035부터 POL-051, POL-063부터 POL-073 · CON-001, CON-002, CON-004

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 미연결 시작 화면 → 동의 → Google 로그인 / 연결 후 Google 계정 → Merchant Center → 상품 피드(MC 연결 후) → Google Ads | WF-006 |
| 노출·활성 | Merchant Center 연결 마법사(준비사항·계정 선택·사업자 정보 동의·전화번호 인증·약관), 도메인 인증, 판매국가·배송, Google Ads 연결(약관·계정 선택·10개 항목 확인), 계정 변경·연결 해제·전체 연결 해제 | POL-035, POL-042부터 POL-050 |
| 안내·실패 | 재인증 필요(계정·MC·Ads 범위 구분), 계정 정지 표시, 단계별 실패 안내와 [다시 시도], 원본 오류 미노출, 전화번호 마스킹 | POL-037, POL-038, POL-039, POL-051, CON-002 |

### WF-007 Google 상품피드 (8-1부터 8-9)

- 목적: Merchant Center로 보내는 상품의 상태와 전송 결과를 확인하고 상품 단위로 수정합니다.
- 진입점·이전 화면: 하위 탭 상품피드, 기존 구글 상품 피드 메뉴 URL, 통합 상품 피드 [Google 관리 ↗]
- 완료 후 이동: [상세]·[선택 수정] → 모달 → 목록
- 관련 요구사항·정책: MKT-REQ-034부터 037, 049 · FR-015, FR-016, FR-018, FR-019 · POL-052부터 POL-076

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 운영 현황 → 상품 피드 등록 현황 → 프로그램별 피드 → 상태 탭·검색·목록 | WF-007 |
| 노출·활성 | 상태 탭 7개, 탭별 컬럼, 노출제한·미승인 사유, [상세]·[선택 수정], [동기화 이력]·[다시 동기화] | POL-052, POL-053, POL-055, POL-060, POL-075 |
| 안내·실패 | Merchant Center 미연결 안내, 재인증 중 전송 중단 안내, 동기화 실패 상세(재시도 버튼 없음) | POL-034, POL-059, POL-076 |

### WF-008 Google 구글애즈 (9-1부터 9-8)

- 목적: Google Ads 광고 측정 상태와 광고·상품 성과를 확인합니다.
- 진입점·이전 화면: 하위 탭 구글애즈
- 완료 후 이동: [광고 운영 상태] → 모달 / 외부 바로가기 → Google Ads 새 창
- 관련 요구사항·정책: MKT-REQ-039 · FR-020부터 FR-022 · POL-077부터 POL-089

| 영역 | 구성·표현 | 기준 |
| --- | --- | --- |
| 구조 | 계정 정보 → 광고 측정 → 광고 성과(광고 기준 / 상품 기준, 기간, 서브탭, 요약, 목록) | WF-008 |
| 노출·활성 | MC 연결 단계 3종, 상품 기준 탭 노출 조건, 쇼핑 서브탭 비활성, 항목 설정은 v0.1 화면설계서 6-6·6-7 | POL-077, POL-080, POL-083, POL-085 |

# [CS 운영·응대 가이드] 구글 채널 연동

이 문서는 사양 정의서 14장 정책(POL)을 고객 응대에 필요한 쉬운 말로 요약합니다. 새로운 조건·예외·보상을 만들지 않으며, 판단 기준은 항상 원본 POL·CON입니다.

## 1. 변경사항 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 변경 목적 | 광고 채널 연동 기능을 마케팅 > 마케팅 채널 관리 한 메뉴로 모으고, 채널 현황을 한 화면에서 보게 하며, Google 채널을 Meta 채널과 같은 화면·운영 방식으로 맞춥니다. |
| 적용 대상 | Meta·Google 채널을 쓰거나 쓰려는 쇼핑몰 운영자(대표 운영자, 부운영자) |
| 적용 시점 | 배포일(미정) |
| 고객 영향 | 운영자: 메뉴 위치 변경, 통합 현황·통합 상품 피드 추가, Google 화면·상품 전송 방식 변경 / 쇼핑몰 구매 고객: 변화 없음 |
| 기존 고객 처리 | 기존 Meta·구글 상품 피드 메뉴는 배포와 함께 없어지고, 북마크한 주소로 들어오면 새 화면으로 이동합니다. 기존 메뉴 권한은 새 메뉴로 옮겨집니다. 연동 정보는 다시 연결하지 않아도 됩니다. |
| 상담 핵심 포인트 | 메뉴는 마케팅 > 마케팅 채널 관리에 있습니다. Google 상품은 카테고리를 매칭해야 전송됩니다. 상품 전송은 자동이며 직접 보내는 버튼은 없습니다. Google 카테고리는 Meta와 같은 값을 씁니다. Google 화면 안의 문제는 Google 고객센터 영역입니다. |

## 6. 상담원 확인 체크리스트

- [ ] 쇼핑몰 아이디 확인

## 10. 공지 및 운영 준비

- 고객 공지 필요 여부와 시점: 배포 전 공지 필요(메뉴 위치 변경, 기존 메뉴 삭제와 주소 이동, Google 카테고리 매칭 필수, 반영대기 상태 추가)
- 도움말·매뉴얼 수정: Meta·Google 채널 매뉴얼의 메뉴 경로, Google 연결·카테고리 매칭·전화번호 인증 절차
- 상담 도구·관리자 조회 기능: 별도 신규 조회 기능 없음(운영자 화면 기준으로 확인)
- 장애·대량 문의 발생 시 공지 기준: 재인증 필요가 다수 쇼핑몰에서 동시에 발생하면 개발 확인 후 공지
- 알려진 제한사항과 임시 우회 방법: 통합 화면 값이 채널 화면과 다르면 해당 채널 화면에 들어가 갱신

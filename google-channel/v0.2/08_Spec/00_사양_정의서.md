## 1. 문서 개요

| 항목 | 내용 |
| --- | --- |
| 작성 목적 | 광고 채널 연동 메뉴를 마케팅 > 마케팅 채널 관리로 통합하고 통합 현황·통합 상품 피드를 추가하며, Google 채널을 Meta 채널과 같은 화면 구조와 상품 피드 운영 방식으로 정리하기 위한 개발 기준을 정의합니다. |
| 적용 대상 | 메이크샵 쇼핑몰 관리자: 마케팅 > 마케팅 채널 관리(통합 현황, 통합 상품 피드, Meta, Google, TikTok 탭), 부가서비스 > 채널(Meta, 구글 상품 피드) |
| 주요 사용자 | 쇼핑몰 운영자(대표 운영자, 부운영자) |
| 문서 상태 | 초안 |
| 기준일·버전 | 2026-10-26 |

## 2. 배경과 문제

| 항목 | 내용 |
| --- | --- |
| 배경 | Meta·Google 광고 채널 연동 기능이 부가서비스 > 부가서비스 > 채널 아래 채널별 메뉴로 흩어져 있습니다. TikTok 등 광고 채널이 늘어날 예정이고, Epic은 기존 유사 메뉴(구글 상품 피드)의 구좌 재정리를 함께 요구합니다. |
| 해결할 문제 | 광고 채널 메뉴가 일반 부가서비스와 섞여 찾기 어렵습니다.<br>채널별 연결 상태·상품 수·광고 성과를 보려면 채널 화면에 하나씩 들어가야 합니다.<br>같은 상품의 채널별 상태를 한 화면에서 비교할 수 없습니다.<br>Google 화면과 상품 피드 운영 방식이 Meta와 달라 채널마다 사용 방식이 다릅니다. |
| 사용자·운영 영향 | 운영자는 메뉴 위치가 바뀌고, 기존 Meta·구글 상품 피드 메뉴는 배포와 함께 없어집니다. |
| 확인 근거 | Epic 4. 현황 점검 및 구좌 재정리, 기획 Task, 요구사항 정의서 2장 현황 및 문제점 |

## 3. 목표와 범위

### 3.1 목표

- 광고 채널 연동 기능을 마케팅 > 마케팅 채널 관리 한 메뉴에서 제공합니다.
- 채널별 계정·상품 피드·광고 연결 상태와 채널 등록 상품 수, 상품별 채널 상태를 한 화면에서 확인하게 합니다.
- Google 채널을 Meta 채널과 같은 화면 구조와 상품 피드 운영 방식으로 맞추고, GPC를 Meta와 공통값으로 사용합니다.
- 기존 채널 메뉴를 정리하면서 운영자의 기존 설정과 권한을 유지합니다.

### 3.2 포함 범위

- 마케팅 채널 관리 메뉴 신설, 탭 구성, 탭 위치 유지, 브레드크럼, 메뉴 권한
- 기존 Meta·구글 상품 피드 메뉴 삭제, 기존 URL 이동, 메뉴 권한 이관
- 통합 현황, 통합 상품 피드
- Google 탭 전체(홈, 연결관리, 상품피드, 구글애즈)와 Meta 정책 재사용
- Meta·Google GPC 공통값 사용과 Google 택소노미 검증
- TikTok 준비 중 탭

### 3.3 제외 범위

- Meta 탭의 화면·기능 변경(진입 경로 제외)
- 부가서비스 > 채널 > 네트워크 광고 메뉴 변경(Google Ads ID 설정, 카테고리/상품 예외 설정 포함)
- TikTok 연동 기능
- 통합 화면에서의 전송·수정·카테고리 매칭·사용여부 변경
- Google Ads 캠페인 생성·수정, 예산·입찰 변경, 권장사항 적용
- 채널 간 광고 성과 합산

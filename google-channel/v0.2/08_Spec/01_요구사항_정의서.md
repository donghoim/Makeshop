# [요구사항 정의서] 구글 채널 연동


## 1. 개요

### 1-1. 프로젝트 배경

메이크샵은 Meta·Google 광고 채널 연동 기능을 **부가서비스 > 부가서비스 > 채널** 아래에 채널별로 따로 제공하고 있습니다.
상품 피드 연동과 광고 성과 확인은 마케팅 업무인데, 이미지호스팅·모바일앱 같은 일반 부가서비스와 같은 위치에 있어 운영자가 찾기 어렵습니다. 또 채널별 연동 현황을 보려면 채널 화면에 하나씩 들어가야 하고, 같은 상품이 채널마다 어떤 상태인지 한 화면에서 비교할 수 없습니다. Google 채널 화면은 Meta 채널 화면과 디자인·구성이 달라 채널마다 사용 경험이 다릅니다.
앞으로 TikTok 등 광고 채널이 늘어날 예정이므로, 광고 채널을 **마케팅** 메뉴 아래로 모으고 채널 공통 현황을 보는 통합 대시보드를 만들며, Google 채널 화면을 Meta 채널과 같은 기준으로 정리합니다.

### 1-2. 프로젝트 목적

| 구분 | 개선 목적 |
| --- | --- |
| 메뉴 통합 | 광고 채널 연동 메뉴를 GNB 마케팅 > 마케팅 채널 관리 한곳으로 모음 |
| 통합 현황 | 채널별 계정·상품 피드·광고 연결 상태와 채널 등록 상품 수를 한 화면에서 확인 |
| 통합 상품 피드 | 메이크샵 상품 하나의 채널별 상태를 한 행에서 비교 |
| Google 화면 정리 | Google 채널 화면을 Meta 채널과 같은 디자인·탭 구조(홈 포함)로 정리 |
| 채널 정책 통일 | Meta 연동에서 정한 상품 피드·광고 정책 중 Google에도 맞는 정책을 Google에 같이 적용 |
| 채널 확장 | 신규 채널을 탭과 대시보드 항목 추가만으로 붙일 수 있는 공통 구조 확보 |

## 2. 현황 및 문제점 (AS-IS)

| 구분 | 현황 및 문제점 |
| --- | --- |
| 메뉴 위치 | 광고 채널 연동이 일반 부가서비스와 같은 위치에 있어 마케팅 업무 메뉴로 찾기 어렵습니다. |
| 채널 현황 확인 | 어떤 채널이 연결되어 있는지, 채널마다 상품이 몇 개 연동되어 있는지 보려면 채널 화면에 하나씩 들어가야 합니다. |
| 상품 상태 비교 | 같은 상품이 Meta에서는 활동중이고 Google에서는 미승인인 상황을 한 화면에서 확인할 수 없습니다. |
| 광고 성과 확인 | 채널별 광고 성과를 보려면 각 채널의 광고 화면에 따로 들어가야 합니다. |
| 채널 화면 차이 | Google 채널 화면은 Meta 채널과 디자인·탭 구성이 달라, 채널마다 첫 진입 화면과 사용 방식이 다릅니다. |
| 채널 간 정책 | 상품 피드 전송·상태·카테고리 매칭 정책이 채널별로 따로 정해져 있어, Meta에서 정한 운영 방식과 Google 운영 방식이 다릅니다. |
| 채널 추가 | 신규 채널이 들어올 때 따를 공통 메뉴·화면 구조가 없습니다. |

## 3. 개선 방향 (TO-BE)

### 3-1. 메뉴 구조

```
GNB: 마케팅
└ LNB: 마케팅 채널 관리
   └ 탭: 통합 현황 | 통합 상품 피드 | Meta | Google | TikTok
        ├ Meta   → 개발 완료된 Meta 채널 화면 그대로
        ├ Google → 하위 탭: 홈 | 연결관리 | 상품피드 | 구글애즈 (Meta 디자인 기준)
        └ TikTok → 준비 중 안내

```

### 3-2. 핵심 개선 사항

| 구분 | 개선 방향 |
| --- | --- |
| 메뉴·IA | 마케팅 > 마케팅 채널 관리 단일 메뉴 신설, 채널은 탭으로 구분. 기존 Meta·구글 상품 피드 메뉴는 배포와 함께 삭제 |
| 통합 현황 | 채널 연결 현황 카드와 채널별 운영 현황 표(계정·상품 피드·광고 연결 상태, 채널 등록 상품 수)로 구성 |
| 통합 상품 피드 | 메이크샵 등록 상품 전체를 기준으로 상품 1행에 채널별 상태를 컬럼으로 표시하는 조회 전용 목록 |
| Meta 탭 | 개발 완료된 Meta 화면을 그대로 표시 |
| Google 탭 | Meta 화면 디자인과 탭 구조(홈 포함)를 적용. 연동 프로세스는 Google 계정 연동 후 Merchant Center·Google Ads를 각각 따로 연동하는 방식 유지 |
| Google 정책 정렬 | Meta의 상품 전송·상태·카테고리 매칭·관리 범위·광고 정책 중 Google API로 가능한 정책을 Google에 적용 |
| TikTok 탭 | 준비 중 안내만 표시. 연동 기능은 별도 기획 |

### 3-3. 설계 기본 원칙

- 조회와 작업 분리: 통합 현황과 통합 상품 피드는 조회 전용입니다. 전송, 수정, 카테고리 매칭, 연결·해제 같은 작업은 각 채널 탭에서만 합니다.
- 채널 상태 그대로 표시: 채널 간 상태를 하나로 합치거나 새 공통 상태를 만들지 않고, 각 채널 화면에서 쓰는 상태 라벨을 그대로 보여줍니다.
- 이미 조회하는 값만 사용: 통합 현황의 값은 각 채널 탭이 이미 조회·집계하는 값을 다시 사용하며, 채널 간 새 집계 지표를 만들지 않습니다.
- 채널 원천 데이터 기준: 연결 상태, 상품 상태, 광고 성과는 각 채널 API 값을 기준으로 하고 메이크샵 값으로 대체하거나 추정하지 않습니다.
- 광고 성과는 채널별로 표시: 채널마다 지표 정의와 전환 기여 측정 방식이 달라 채널 간 합산 수치를 만들지 않습니다.
- 장애 격리: 한 채널 조회가 실패해도 다른 채널 정보는 정상 표시합니다.
- 채널별 연동 방식 유지: 화면 디자인은 채널 간에 맞추되, 연동 절차는 각 채널 방식을 따릅니다. Meta는 한 번에 연동(FBE), Google은 계정 연동 후 서비스별 개별 연동입니다.

## 4. 기능별 요구사항 정의

요구사항 ID는 `MKT-REQ-001` 형식입니다.

### 4-1. 메뉴·IA 개편

| 요구사항 ID | 요구사항명 | 요구사항 정의 |
| --- | --- | --- |
| MKT-REQ-001 | 마케팅 채널 관리 메뉴 신설 | GNB 마케팅 아래 LNB에 마케팅 채널 관리 메뉴 추가 |
| MKT-REQ-002 | 탭 구성 | 통합 현황 / 통합 상품 피드 / Meta / Google / TikTok 순서의 탭 제공 |
| MKT-REQ-003 | 기본 진입 화면 | 마케팅 채널 관리 메뉴 클릭 시 통합 현황 탭 노출 |
| MKT-REQ-004 | 탭 위치 유지 | 현재 탭과 채널 하위 탭을 URL에 남겨 새로고침·뒤로가기·다른 화면에서 이동할 때 같은 화면이 열림 |
| MKT-REQ-005 | 브레드크럼 | 마케팅 > 마케팅 채널 관리 > {탭명} > {채널 하위 탭명} 형식으로 표시 |
| MKT-REQ-006 | 기존 메뉴 삭제 | 부가서비스 > 부가서비스 > 채널 아래의 Meta 메뉴와 구글 상품 피드 메뉴를 배포 시점에 삭제(안내 기간 없음) |
| MKT-REQ-007 | 기존 URL 이동 | 삭제한 메뉴 URL로 접근하면 마케팅 채널 관리의 같은 채널·대응 화면으로 이동. 대응 화면이 없으면 채널 홈으로 이동 |
| MKT-REQ-008 | 메뉴 권한 이관 | 기존 Meta 메뉴 또는 구글 상품 피드 메뉴 중 하나라도 권한이 있던 운영자(부운영자 포함)에게 마케팅 채널 관리 메뉴 권한 부여 |

### 4-2. 통합 현황(대시보드)

통합 현황은 채널 연결 현황(카드)과 채널별 운영 현황(표) 2개 영역으로 구성합니다. 메이크샵 전체 등록 상품 수, 연동 확인 필요 건수, 전송 대기 건수처럼 채널을 넘나드는 합산 박스는 두지 않습니다.

| 요구사항 ID | 요구사항명 | 요구사항 정의 |
| --- | --- | --- |
| MKT-REQ-009 | 채널 연결 현황 | Meta, Google, TikTok 채널별 카드에 로고, 채널명, 제공 기능, 연결 상태, 버튼 표시 |
| MKT-REQ-010 | 채널 연결 상태 | Meta·Google은 각 채널 연결관리 화면에서 확인해 저장한 연결 상태 값을 표시(카드는 계정 연결 상태). TikTok은 '준비 중' 표시 |
| MKT-REQ-011 | 카드 버튼 | 연결된 채널은 [관리하기] → 해당 채널 탭의 첫 화면으로 이동<br>연결되지 않은 채널은 [연동하기] → 해당 채널 탭의 연결관리 화면으로 이동<br>TikTok은 버튼 없음 |
| MKT-REQ-012 | 채널별 운영 현황 | 표 컬럼: 채널 / 계정 연결 상태 / 상품 피드 연결 상태 / 광고 연결 상태 / 채널 등록 상품 수 / 관리. 연동 기능을 제공하는 채널(Meta, Google)만 행으로 표시 |
| MKT-REQ-013 | 채널 등록 상품 수 | 채널에 전송되어 채널에 등록된 메이크샵 상품 수(아래 집계 기준). 각 채널 상품피드 화면의 상태별 집계를 그대로 사용 |
| MKT-REQ-014 | 연결 상태 3종 | 계정(Meta 비즈니스 / Google 계정), 상품 피드(Meta 카탈로그 / Merchant Center), 광고(Meta 광고 계정 / Google Ads) 연결 상태를 연결됨 / 재인증 필요 / 미연결로 표시. 광고비·ROAS 등 광고 성과는 통합 현황에 두지 않음 |
| MKT-REQ-015 | 미연동 채널 행 | 연결 상태는 미연결, 채널 등록 상품 수는 '-', 관리 컬럼에 [연동하기] 표시. 클릭 시 해당 채널 탭의 연결관리 화면으로 이동. 상품 피드만 미연결이면 채널 등록 상품 수만 '-' |
| MKT-REQ-016 | 연동 채널 행 | 관리 컬럼에 [바로가기] 표시. 클릭 시 해당 채널 탭의 첫 화면으로 이동 |
| MKT-REQ-017 | 저장값 기준 표시 | 통합 현황·통합 상품 피드는 외부 API를 호출하지 않고, 각 채널 화면에서 확인·판정해 메이크샵에 저장한 값을 표시 |

채널 등록 상품 수 집계 기준

| 채널 | 집계에 포함 | 집계에서 제외 | 값 출처 |
| --- | --- | --- | --- |
| Meta | 활동중, 검토중, 미승인 | 반영대기, 노출제한, 사용안함 | Meta 카탈로그 |
| Google | Merchant Center에 등록된 메이크샵 상품 전체(심사 결과와 무관) | Merchant Center에 전송되지 않은 상품 | Google Merchant API |

채널에서 직접 등록한 상품은 두 채널 모두 집계하지 않습니다. Google은 Merchant Center가 연동되지 않았으면 채널 등록 상품 수를 '-'로 표시합니다.

| MKT-REQ-024 | 페이지네이션 | 페이지당 20 / 50 / 100개 선택 |
| MKT-REQ-025 | 조회 전용 | 전송, 수정, 카테고리 매칭, 사용여부 변경 기능을 두지 않음. 작업은 각 채널 상품피드 화면에서 처리 |

TikTok은 연동 기능이 생기기 전까지 상태 컬럼을 두지 않습니다. 채널 컬럼이 늘어나 화면 폭을 넘으면 표를 가로 스크롤로 표시하고, 상품 정보 컬럼은 고정합니다.

# Google Channel v0.2 — 마케팅 채널 관리 통합

메이크샵 관리자의 Meta·Google 광고 채널 연동 메뉴를 **마케팅 > 마케팅 채널 관리** 한곳으로 모으고, 채널 공통 현황을 보는 통합 화면을 만들며, Google 탭을 Meta 탭과 같은 디자인·운영 방식으로 정리하는 기획입니다. 사양 정의서·요구사항 정의서·정책서·와이어프레임 초안·CS 운영 가이드·HTML 화면정의서·목업까지 완료했고, 이 폴더에는 사내 정보(이슈 번호, 사내 문서 링크, 작성자·부서)를 뺀 공개본을 둡니다.

v0.1(Google 채널 단독 기획)은 상위 폴더 [`../`](../)에 그대로 있습니다.

## 핵심 정책

- 통합 현황은 외부 API를 호출하지 않고, 각 채널 화면에서 확인해 메이크샵에 저장한 값을 보여줍니다. 컬럼은 채널 / 계정 연결 상태 / 상품 피드 연결 상태 / 광고 연결 상태 / 채널 등록 상품 수 / 관리입니다. 광고비·ROAS 같은 성과는 각 채널 광고 화면에서 확인합니다.
- 채널 등록 상품 수는 메이크샵이 전송해 채널에 등록된 상품(활동중·검토중·미승인)만 세고, 상품 피드가 연결되지 않았으면 `-`로 표시합니다. 채널 간 상품 수는 더하지 않습니다.
- 통합 상품 피드는 조회 전용입니다. 상품 1개를 1행으로, 채널별 상태를 합치지 않고 각각 표시합니다.
- 메뉴 권한이 없는 운영자에게는 메뉴를 숨기지 않고 비활성화로 표시합니다.
- Merchant Center 대표 전화번호 인증은 운영자가 Google 화면에서 직접 합니다. 메이크샵은 [Google에서 인증하기]로 Google 화면을 열고, [인증 확인]을 누를 때만 인증 상태를 조회해 미인증·인증 완료를 표시합니다.
- Google 상품 분류(GPC)는 Meta·Google이 같은 값을 공유하고, 카테고리를 매칭한 상품만 전송합니다.

## 실행 방법

순수 HTML/CSS/JS이며 백엔드·DB를 쓰지 않습니다. `index.html` 또는 `screen-spec.html`을 브라우저로 바로 열면 됩니다(외부 의존: Pretendard 웹폰트 CDN). 목업 상태는 `localStorage`에 저장되며, 시나리오 패널 > 저장 데이터 전체 초기화로 처음 상태로 되돌립니다.

## 알려진 한계

- Google 로그인·Merchant Center 연결·Google Ads 연결은 단계만 시뮬레이션합니다. 외부 링크는 실제로 이동하지 않고 토스트로 대상 URL을 보여줍니다.
- 상품명·수치·계정 번호 등 화면 예시값은 Mock 데이터이며 정책 값이 아닙니다.

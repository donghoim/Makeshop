## 실행 방법

순수 HTML/CSS/JS이며 백엔드·DB를 사용하지 않는다. Mock 데이터는 `src/data/*.js`에 전역 변수(`window.MOCK_*`)로 로드되므로 **더블클릭으로 바로 열어도(file://) 정상 동작**한다. 로컬 정적 서버로 띄워도 동일하게 동작한다(예: `npx serve` 등).

- 진입점: `index.html` (부가서비스 메뉴 → "구글 쇼핑" 카드 클릭)
- Google 채널 메인: `src/html/google-channel.html` (연결 관리 / 상품 피드 / Google Ads 3탭)

## 화면 하단 QA 툴바 안내

화면 최하단 검정 바는 **프로토타입 전용 리뷰 도구**이며 실제 서비스에는 없다. 탭별로 화면 상태(미연동/연동완료 조합/각종 Empty·에러 상태 등)를 즉시 전환해 모든 케이스를 빠르게 검토할 수 있도록 추가했다.

## 실동작 컴포넌트 체크리스트

Modal · Drawer(동기화 실패 상세) · Tab/Subtab · Dropdown(정렬) · Toast · Pagination · Validation(필수 체크박스) — CLAUDE.md Prototype 작성 규칙 요구 항목을 모두 실제로 클릭 가능한 형태로 구현했다.

## 알려진 단순화 사항 (프로토타입 한계)

- Mock 데이터는 새로고침 시 초기화된다(서버/스토리지 없음).
- 일부 비동기 처리(도메인 인증, 전화번호 인증, 동기화 등)는 실제 API 대신 `setTimeout` 기반 시뮬레이션이다.
- 상세 필드 값(광고 목표 컬럼 등)은 05_Policy 미결정사항으로 남아있는 항목을 프로토타입에서는 화면에서 제외하거나 [확인 필요] 상태 그대로 두었다.

## 업데이트 이력

### 2026-08-27

사용자가 `05_Policy`·`03_Wireframe`·`04_Screen-Spec`를 전량 신규 파일로 교체(정책은 PDF 포맷으로 전환)함에 따라, 신규 정책 기준으로 프로토타입을 재정합화했다.

- 연결 관리: Merchant Center 계정 상태에 "확인 필요"·"연결 오류" 2종을 추가(기존 연결됨/재인증 필요/정지됨 3종과 합쳐 5종, 결정 주체는 항상 Google), 상태별 사유 배너 추가. 쇼핑몰 도메인 인증에 "인증 실패" 상태와 재시도 버튼 추가. Google Ads 연결 실패 화면 신규 추가(대표 오류 코드 4종 — 재인증/계정 확인/권한 확인/다시 시도 후속 조치 분기). Google 계정 자체 재인증 필요 시 Merchant Center·Google Ads 상태가 함께 전환되는 전파 시나리오를 dev 툴바에 추가.
- 상품 피드: 상품별 카테고리 매칭 화면의 성별·연령대 입력 항목을 매칭된 Google 카테고리가 "의류 및 액세서리(GPC 166)" 하위인 경우에만 노출하도록 수정(그 외 카테고리는 "해당없음" 처리, 사용여부 OFF 시 선택란 비활성화). 이 과정에서 상품 상세 모달이 `apparel` 필드를 전달하지 않아 전 상품에 성별·연령대가 노출되던 버그를 함께 수정.
- Google Ads: 계정 정보 영역에 연결 상태 배지(연결됨/재인증 필요) 신규 추가, 재인증 필요 시 "마지막으로 확인된 정보" 안내 배너 추가.
- 코드 내 정책 근거 주석을 신규 PDF 파일명 기준으로 갱신(`GMC-Ads-Independence-Policy.md` 등 삭제된 구 파일명 참조 제거).
- `07_QA/`에 정책 기반 QA 테스트케이스 신규 작성(정상/예외/Boundary/Permission/Regression 5유형).
- Google Ads: "이 Google Ads 계정에 이미 연결된 Merchant Center 계정이 있어요" 배너(`mcLink`)가 상품피드(Merchant Center) 연동 여부와 무관하게 항상 노출되던 버그 수정. 이 배너는 Merchant Center가 메이크샵에 아직 연동되지 않은 경우에만 나타나는 별도 화면 상태(04_Screen-Spec 6-4)이므로, 기본값을 노출 안 함으로 바꾸고 dev 툴바에 "연동완료 — MC 계정 감지(상품피드 미연동)" 상태를 별도로 추가해 그 상태에서만 노출되도록 분리.
